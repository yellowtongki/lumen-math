## 루멘수학은 이렇게 공부합니다

학원을 오래 다녀도 성적이 오르지 않는 아이들은, 어디가 구멍인지 스스로도 모르는 경우가 많습니다.
루멘수학은 그 구멍을 **매주 재서 찾아내고, 메워질 때까지** 봅니다.

- 수업 시간에 푼 문제, 집에서 푼 교재, 주간테스트까지 **문항 하나하나의 정답·오답이 기록**됩니다.
- 그 기록으로 아이마다 약한 단원을 찾고, **틀린 문제와 같은 원리의 문제(쌍둥이 문제)**를 다시 풀게 합니다.
- 한 번 보충하고 끝내지 않습니다. 다시 풀었을 때 맞히는지까지 확인합니다.

## 한 주의 흐름

| 언제 | 무엇을 | 설명 |
|---|---|---|
| 수업 날 | 수업 + 숙제 | 숙제는 **풀이 → 채점 → 오답 → 아하노트** 4단계로 합니다 |
| 수·목 | 주간테스트 | 이번 주 배운 내용을 확인합니다 |
| 토요일 | 리커버리 수업 | 주간테스트 점수가 기준에 못 미치거나, 교재에서 특정 단원 정답률이 낮은 학생을 부릅니다. 아이 오답으로 만든 1인 학습지를 풉니다 |
| 금·토 아침 | 오답 쌍둥이 숙제 | 한 주 동안 틀린 문제의 쌍둥이 문제가 매쓰플랫 «숙제»로 자동으로 나갑니다 (월수금 반 금요일, 화목토 반 토요일) |
| 매일 | 플래너 | 하루 공부를 계획하고 기록해 사진으로 냅니다 |
| 일요일 밤 | 주간계획 · 순공피드백 | 다음 주 계획과 이번 주 순공 시간을 정리해 냅니다 |

리커버리 수업은 벌이 아닙니다. **놓친 부분을 그 주 안에 메우는 시간**입니다. 대상이 되면 미리 안내드리고, 네이버 예약으로 시간을 고르실 수 있습니다.

## 아이가 쓰는 기록

**아하노트** — 막힌 문제나 틀린 문제를 사진과 함께 남기고, 왜 틀렸는지 이유까지 적는 노트입니다. 질문이 올라오면 제가 확인하고 해결까지 챙깁니다.

**하브루타 녹음** — 배운 개념을 아이가 자기 말로 설명해 녹음합니다. 설명할 수 있어야 아는 것이라고 봅니다.
녹음은 학부모앱에서 **재생되지 않습니다.** 누가 듣는지 의식하면 아이들이 솔직하게 말하기 어렵기 때문입니다. 대신 제출했는지, 얼마나 꾸준한지는 언제든 보실 수 있습니다.

## 학부모님이 받으시는 것

- **수업 후 피드백 (Ultra Feedback)** — 매 수업이 끝나면 그날 아이의 수업 내용과 상태를 따로 정리해 보내 드립니다.

- **진학 나침반** (중학생) — 지금 성적이면 관심 고등학교에서 몇 등급쯤인지 보여 드립니다. 제가 직접 확인하고 올린 것만 공개됩니다.
