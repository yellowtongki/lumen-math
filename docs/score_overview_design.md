## 3. 제안 — «📈 성적 한눈에»

### 3-1. 화면 (원장님용)
- **새 메뉴 「📈 성적 한눈에」** (성적·분석 묶음): 반·학년 고르기 → 학생 한 줄씩
  - 최근 전국주간: 점수 · **378/823명(등급 색)** · 최근 6회 미니 막대(등급 색)
  - 최근 학교 시험: «2학기 중간 수학 84점 · 3등급 · 석차 45/270» · 직전 대비 ↑↓
  - 일일: 최근 8회 중 학원 평균 이상 n회
  - 정렬: 이름 / 전국 등수 / «최근 하락 큰 순»(챙길 학생 먼저)
- **학생을 누르면 오른쪽(또는 학생 프로필 새 탭 «📈 성적»)**:
  1. 🌐 전국주간 추이 — 학부모앱 시안과 **같은 그림**(점수 + 전국 평균 점선 · 회차별 378/823명 · 시험지 제목)
  2. 🎓 학교 시험 타임라인 — 학기별 중간·기말 수학 점수·등급·석차·학교 평균, 다른 과목은 펼치기
  3. 📝 일일 — 학원 평균과의 차이 막대
- 학생 프로필은 리포트가 없어도 열리게 고친다.

### 3-2. 자료 묶기
- **전국 등수 보존(서버)**: 새벽 수집기가 `mf_ws_behaviors` 의 nat{rank,n,avg} 를 `mf_weekly` 학생 칸(natRank·natN·natAvg)에 채워 **영구 보존**. 이미 지난 회차는 리포트 값으로 채운다.
- **한 학생 성적표 만들기(학원앱 함수 하나)**: 주간 = mf_weekly(점수·제목·전국 등수) + 리포트(옛 전국 등수 보충) · 일일 = 리포트(class) · 학교 = school_scores. 짝짓기는 등록부 id ↔ 학습코드 ↔ 매쓰플랫 sid(`mf_students`)로 통일, 이름은 마지막 수단.
- **학부모앱과 같은 자료**: 리포트 발행 때 이 성적표를 짧게 줄여 `pub_reports_<코드>.hist` 로 함께 올린다 → 원장이 보는 그림 = 학부모가 보는 그림.

### 3-3. 단계
1. 서버 수집기 전국 등수 보존 + 학원앱 «📈 성적 한눈에»(주간 + 학교) + 학생 프로필 열림 고침
2. 학부모앱 성적 추이(시안) — 같은 자료(hist)
3. 일일·기출모의·자체모의 줄 더하기

## 4. 원장님께 여쭐 것
1. **등급 색 기준**: (가) 지금처럼 점수 기준(90·80·70·60) / (나) 전국주간은 **전국 상위 %** 기준(예: 상위 10% · 30% · 50% · 70% · 그 아래 → 1~5). 추천 (나) — 주간도 회차마다 난이도가 달라 점수보다 전국 위치가 공정.
2. **자리**: 새 메뉴 + 학생 프로필 새 탭 둘 다(같은 그림) — 추천.
3. **학교 성적 과목**: 수학 기본 + 다른 과목 펼치기 — 추천. 아니면 전 과목 표.
4. **학부모앱 성적 추이에 학교 성적도?** 1단계는 주간·일일만, 학교 성적은 나중(원장 확인 후).
