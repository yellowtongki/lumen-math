👨‍👩‍👧 학부모앱 「과제 완성도」 — 미리보기

학원앱에 새로 들어간 단계별 퍼센트(풀이·채점·오답·아하노트)를 학부모님께 어떻게 보여드릴지입니다.
아래 학생 예시를 눌러 바꿔가며 세 가지 상황을 다 보실 수 있습니다.

① 학부모님께 보여드릴 때의 원칙
같은 숫자라도 학부모가 보면 의미가 달라집니다
⚠️
그냥 퍼센트만 보여주면 「점수표」가 됩니다

“오답 30%”만 보이면 학부모님은 혼내야 할 일로 받아들이십니다. 우리가 알려드리고 싶은 건 “어느 단계에서 멈췄는지, 집에서 뭘 도와주면 되는지”입니다.

✅
그래서 세 가지를 함께 담습니다

1. 네 단계를 그림으로 — 어디까지 갔고 어디서 멈췄는지 한눈에
2. 한 줄 코칭 — “집에서 이것만 봐주세요” 한 문장 (자동 생성)
3. 아하노트는 특별 설명 — 학부모님은 이 말을 모르십니다

🛡️
아하노트는 「해당 없음」을 반드시 밝힙니다

막힌 문제가 없어서 질문할 게 없던 날은 “질문할 문제가 없었어요 — 아주 좋습니다”로 표시합니다. 0%가 아닙니다. 잘한 아이가 못한 것처럼 보이면 안 됩니다.

② 화면 디자인 눌러서 학생 전환
학부모앱 홈의 「오늘 플래너 / 녹음 숙제」 카드 바로 아래에 들어갑니다
🗣️ 말투를 골라 주세요 — 누르면 아래 화면이 바로 바뀝니다
전부 학원이 책임진다는 뉘앙스로 다시 썼습니다 — 학부모님께 일을 드리지 않습니다
오늘 (홈 화면)
이번 주 (리포트 안)
③ 학부모님께는 이렇게 풀어서 씁니다
학원에서 쓰는 말과 학부모님이 이해하는 말이 다릅니다
학원 용어학부모앱 표기설명 문구 (물음표를 누르면 나옴)
풀이① 문제 풀기내준 숙제 분량 중 실제로 푼 비율입니다
채점② 채점하기푼 문제를 답과 맞춰 보고 O·X를 표시한 비율입니다
오답③ 틀린 문제 정리틀린 문제를 다시 풀어보고 왜 틀렸는지 정리한 비율입니다
아하노트④ 모르는 문제 질문 혼자 다시 풀어봐도 끝내 안 풀린 문제를 사진 찍어 선생님께 질문하는 것입니다.
막힌 문제가 없었던 날은 「해당 없음」으로 표시되고 점수에 들어가지 않습니다.
④ 말투 4안 — 상황별 전체 문장 골라주세요
위에서 고르신 안이 파랗게 표시됩니다. 문장은 아이 이름·퍼센트만 바뀌고 나머지는 그대로 나갑니다
공통 규칙 (어느 안을 고르셔도 지킵니다)
· 아이를 탓하는 말(게으르다·안 했다·문제다)은 쓰지 않습니다
· 학부모님께 지시하지 않습니다 — 남은 것은 학원이 맡는다고 씁니다
· 아하노트가 「해당 없음」인 날은 문장에서 아예 언급하지 않습니다
· 섞어 쓰기도 가능합니다 — 예: 잘한 날만 T3, 나머지는 T1
⑤ 어디에 들어가나
두 군데에 같은 데이터로 들어갑니다
1. 홈 화면 — 「오늘 플래너 / 녹음 숙제」 카드 바로 아래에 오늘 과제 완성도 카드
숙제 기록이 없는 날은 카드가 아예 안 뜹니다(빈 카드로 불안하게 만들지 않음)

2. 학습 리포트 안 — 총평 위에 이번 주 7일 막대 + 주간 평균
리포트를 발행할 때 그 시점 값이 함께 저장되어, 나중에 열어도 그날 숫자가 그대로 남습니다

3. 학원앱과 같은 데이터 — 원장님이 숙제체크 그리드에서 찍으신 값이 그대로 나갑니다. 따로 입력하실 것은 없습니다.
이 화면은 미리보기(목업)입니다 — 학부모앱에는 아직 반영되지 않았습니다
