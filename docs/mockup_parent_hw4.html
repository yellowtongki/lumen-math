① 홈 카드는 총합 바로 아래에 4칸을 항상 펼쳐 보여 줍니다(접기 없음). 눈금은 학원앱 체크와 같은 0 · 30 · 60 · 100 을 ○ ◔ ◐ ✓ 로. ② 숙제 탭에 «최근 7일 단계 표»가 새로 생깁니다(학원앱 숙제체크 표와 같은 모양, 아하노트는 질문/막힘 수). ③ 월 기록은 총합 막대 대신 단계별 평균 4개와 달력 점 4개. 자료는 이미 학부모앱이 받는 `lumen_hw`(p·c·w)와 아하노트 수라 서버 변경이 없습니다.

배포는 하지 않고 새 버전 파일(v1-37)까지만 만듭니다. 녹음 v1-36 위에 얹습니다.

클로드 대시보드 — 세 앱에 어떻게 쓸까 원장 질문

학원앱(원장님) → 클로드 대시보드 그대로 ✅

claude.ai 에 「루멘 운영 대시보드」 한 장. 출석·숙제·플래너·녹음·리커버리·수강료·새벽 작업 상태를 숫자와 그래프로, 숫자마다 어디서 온 것인지가 붙습니다(Sources). 폰 Claude 앱에서도 열리고, 배우자와 공유할 수 있습니다.

미리보기(예시 숫자): https://claude.ai/artifact/7r8nW5sV5geeK8nuKrBYWZ
실제 숫자를 넣는 길 두 가지 — ㉠ Supabase(포스트그레스) 연결기를 claude.ai 에 읽기 전용으로 달면 대시보드가 열 때마다 서버에서 바로 셈(가장 깔끔) ㉡ 연결기 없이 새벽 Actions 가 숫자 JSON 을 만들고 Claude 예약 작업이 올림. 추천은 ㉠.

학생앱 → 앱 안에 「내 대시보드」 홈

학생은 Claude 계정이 없고 30명 각자 자료라 claude.ai 대시보드를 줄 수 없습니다. 대신 같은 설계를 학생앱 홈에: 한 줄 요약 → 숫자 4개 → 작은 추세 → «어디서 온 숫자» 표시.

정해 주실 것

A. 학부모앱 숙제 4단계 — 위 ①②③ 모양으로 v1-37 만들지(배포 없음). B. 원장 운영 대시보드 — 실제 숫자로 연결할지, 연결한다면 ㉠ Supabase 연결기(원장님이 claude.ai 설정에서 읽기 전용 계정으로 추가) 또는 ㉡ 새벽 JSON. C. 학생앱·학부모앱 홈 대시보드화는 숙제 4단계 뒤 다음 판으로.
