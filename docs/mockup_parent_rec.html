학부모에게 나가는 규칙

주제그날 배정된 주제(개인 > 학년 > 미션). 없으면 학생이 적은 제출 제목을 「자유 제출」로. ✓ 선생님 확인원장님이 훑어보기 화면에서 「✓ 확인」을 누른 것만. 누르기 전엔 「확인 전」으로만 보이고, AI 판정(⚠️ ❌)은 학부모에게 절대 안 나갑니다. 💬 한마디「✓ 확인」 때 고른 문구. 안 고르면 한마디 없이 확인 표시만. 학생앱에는 1단계에서 안 보냅니다. 소리·전문학부모앱·학생앱 어디에도 없음. 지금 규칙 그대로.
원장님 쪽 「✓ 확인」 단추 옆에 기본 한마디 칩을 둡니다. 판정에 따라 어울리는 칩이 먼저 나옵니다. 누르면 바로 저장되니 녹음 하나에 2초면 됩니다.
주제대로 잘 설명했어요예시까지 들어 좋았어요다음엔 ○○도 같이조금 더 길게, 예를 하나 들어 보자오늘 주제로 다시 한 번!✏️ 직접 쓰기
「다음엔 ○○도 같이」의 ○○은 AI 가 찾은 빠진 개념이 자동으로 들어가고, 원장님이 고쳐 쓸 수 있습니다.
