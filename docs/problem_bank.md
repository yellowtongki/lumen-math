## 정한 것 (2026-10-20 ~ 27 상의)

| 항목 | 정한 것 |
|---|---|
| 문항 경계 찾기 | **매쓰플랫 AI 문항 인식** (적중 분석과 같은 길). 못 자른 쪽만 원장님 손보기 |
| 번호·단원·유형·정답 | **매쓰플랫 교재 목록**에서 받는다 — AI 없이 정확. 유형 이름까지 대단원 → 중단원 → 소단원 → 유형 4단계 |
| 그림 | **책 PDF 에서 자른다.** 매쓰플랫 그림은 숫자를 바꾼 비슷한 문제라 쓰지 않는다 (`docs/solution_note.md` 와 같은 결정) |
| 저장 | **맥미니 외장 SSD** = 작업용 DB(`lumen_bank/`). **외장하드 5TB** = 교재 원본 PDF + 매일 밤 백업 |
| 화면 | 시범은 맥미니에서 여는 `bank.html` (인터넷 필요 없음). 학원앱 연결은 시범 뒤 — 글자 목록만 Supabase 에 올리고 그림은 맥미니에 둔다 |
| 클래스아이큐·수작 | 사지 않는다. 채점·오답·리포트는 이미 매쓰플랫+학원앱이 하고, 빠진 칸은 «기존 문제집 자르기» 하나뿐 |
| 저작권 | 교재 그림·완성 학습지는 **저장소·공개 서버에 올리지 않는다**. 매쓰플랫에는 인식할 쪽만 잠깐 올라가고 학습자료로 등록하지 않는다 |

## 도구 (`sync/`)

| 순서 | 도구 | 하는 일 |
|---|---|---|
| ① | `bank_meta.js` | 매쓰플랫 교재 → 쪽·번호·단계(A/B/C)·문항 형태·난이도·정답·유형·단원 목록 (meta.json) |
| ② | `bank_detect.js` | 책 PDF 의 고른 쪽 → 매쓰플랫 AI 문항 인식(10쪽씩) → 상자 좌표 (boxes.json). `--match` 를 주면 상자마다 유형 번호도 받아 번호 맞추기 검산에 쓴다 |
| ③ | `bank_build.py build` | PDF + 상자 + 목록 → 문항 그림 자르기 · `bank.sqlite` 저장 · 확인 그림 · 화면 파일 |
| ④ | `bank.html` (원본 `bank_viewer.html`) | 교재 → 대단원 → 중단원 → 소단원 → 유형 체크 / 번호로 고르기(`547 553 560-565`) → A4 2단 학습지 + 정답지 출력(PDF 저장) |

번호 맞추기: 쪽마다 상자를 «왼쪽 단 위→아래, 오른쪽 단 위→아래» 순서로 세워 책 번호와 짝짓는다.
상자 수 = 번호 수면 그대로(유형 번호가 1/3 넘게 어긋나면 「확인 필요」), 다르면 유형 번호로 최대한 맞추고 「확인 필요」.
`528.(1)`·`528.(2)` 같은 작은 문항은 그림 한 장(528)으로 묶고 정답만 나눠 적는다.

## 맥미니에서 처음 돌리기 (쎈 중1-2 다각형 = 책 83~103쪽 · 150문항 · 그림 146장)

```
cd ~/lumen-math && git pull && npm install
# sync/.env.local 에 MATHFLAT_ID=… / MATHFLAT_PASSWORD=… (이미 있으면 그대로)
B=/Volumes/SSD/lumen_bank            # 외장 SSD 이름에 맞게
PDF="/Volumes/외장하드/문제집/쎈 중1-2 [2022개정].pdf"
mkdir -p $B/meta
node sync/bank_meta.js --bid 2129121 --short "쎈 중1-2" --pages 83-103 --out $B/meta/ssen12_poly.json
node sync/bank_detect.js "$PDF" --pdf-pages 85-105 --out $B/meta/ssen12_poly_boxes.json --match 1.4.4146.4154.4170
python3 sync/bank_build.py build --meta $B/meta/ssen12_poly.json --boxes $B/meta/ssen12_poly_boxes.json \
  --pdf "$PDF" --offset 2 --bank $B
open $B/bank.html
```
- `--pdf-pages` 와 `--offset` 은 «책 83쪽이 PDF 몇 쪽인가»로 정한다(위는 PDF 85쪽이라고 가정한 예). `check/` 그림의 번호가 책과 맞으면 맞은 것.
- 교재 번호는 `node sync/mf_workbook_list.js --find 블랙라벨 중등수학1`. 교육과정 키(`--match`)는 중1-1 `1.4.4146.4154.4169` · 중1-2 `…4170` · 중2-1 `1.4.4146.4155.4171` · 중2-2 `…4172` · 중3-1 `1.4.4146.4156.4173` · 중3-2 `…4174` (`sync/exam_twin_pipeline.js` `TRIE_22`)
- 「확인 필요」 쪽 손보기: `fix.json` 에 `{ "93": ["547","548","549","","550"] }` (상자 순서대로 번호, `""` = 버릴 상자) → `build … --fix fix.json`
- 다시 돌려도 된다 (같은 문항은 덮어쓴다). 다른 교재를 더하면 같은 `bank.sqlite` 에 쌓인다.

## 매일 밤 백업 (외장 SSD → 외장하드)

```
crontab -e
15 3 * * * rsync -a /Volumes/SSD/lumen_bank/ "/Volumes/외장하드/lumen_bank_backup/"
```
- `--delete` 는 넣지 않는다 (SSD 에서 실수로 지운 것이 백업에서도 지워지지 않게).
- SSD 포맷이 exFAT 이면 `bank.sqlite` 가 깨질 수 있다 → APFS 권장. 윈도우와 같이 쓰는 SSD 면 DB 는 맥 내장 디스크에, SSD 는 백업으로.
- 시스템 설정 → 에너지 → 「가능할 때 하드 디스크 잠자기」 끄기.
