# 루멘 자체 블로그·인스타 도구 설계

**작성일**: 2026-09-20 · **결정**: 클래스바이 도구에 의존하지 않고 **맥미니에서 도는 자체 도구**를 만든다

> 참고: 클래스바이 도구 구조는 `docs/blog_automation_overview.md`에 분석돼 있다.
> **그 코드를 베끼거나 역난독화하지 않는다** (라이선스 위반). 개념만 참고하고 처음부터 새로 만든다.

---

## 1. 블로그 한 편은 5조각이다 — 난이도가 극과 극

| # | 조각 | 난이도 | 가치 | 판단 |
|---|---|---|---|---|
| 1 | **글감 뽑기** (학원 데이터 → 주제·수치) | 낮음 | ⭐⭐⭐ 최고 | 먼저 만든다 |
| 2 | **글쓰기** (루멘 말투, 1,500자) | 낮음 | ⭐⭐ | Claude가 직접 |
| 3 | **카드 6장** (HTML → PNG, 1080×1350) | 중간 | ⭐⭐⭐ 인스타와 공유 | 만든다 |
| 4 | **검사** (글자수·해시태그·카드 수 등) | 낮음 | ⭐ | 만든다 |
| 5 | **네이버 임시저장** (크롬 자동 조종) | **매우 높음** | ⭐ 낮음 | **뒤로 미룬다** |
| 6 | **인스타 업로드** (공식 API) | 중간 | ⭐⭐⭐ | 만든다 |

**5번만 어렵습니다.** 나머지는 맥미니에서 충분히 만들 수 있습니다.

---

## 2. 5번(네이버 자동 저장)을 미루는 이유 — 계산해보면 이득이 없다

클래스바이 도구는 네이버에 **8~14분** 동안 사람 타자 속도로 칩니다. 빨리 치면 기계로 들키니까요.

그런데 원장님이 손으로 붙여넣으면 얼마나 걸릴까요? 본문 붙여넣기 1분, 카드 6장 올리기 3분,
실사진 3장 3분, 지도·해시태그 2분 — **약 10분**입니다.

> **자동 8~14분 vs 수동 10분.** 시간 차이가 거의 없습니다.
> 자동화의 진짜 가치는 타자를 대신 쳐주는 게 아니라 **글과 카드를 만들어주는 것**입니다.

게다가 5번은 대가가 큽니다.

- 네이버 스마트에디터는 구조가 복잡하고 **수시로 바뀝니다.** 바뀔 때마다 도구가 깨집니다
- 자동 조종이 감지되면 **캡차**가 뜨고, 반복되면 **블로그가 저품질 처리**됩니다
- 학원 블로그 계정은 잃으면 복구가 어렵습니다

**그래서 1~4, 6번을 먼저 만들고, 5번은 나중에 판단합니다.**
급하면 윈도우의 클래스바이 도구를 그대로 쓰면 됩니다 (이미 작동 중).

---

## 3. 만들 파일 (전부 맥미니에서 실행)

```
sync/blog_topics.js      ① 글감 생성기 — Supabase 집계 → docs/blog_topics_latest.md
sync/card_render.js      ③ 카드 생성기 — HTML → PNG (Playwright 캡처)
sync/card_templates/     ③ 카드 디자인 (표지·수치·비교·질문답변·마무리)
sync/post_check.js       ④ 검사기 — 글자수·해시태그·카드 수·개인정보
sync/insta_upload.js     ⑥ 인스타 업로드 (Graph API)
docs/lumen_blog_profile.md  학원 정보·말투 (클래스바이 profile.json에 해당하는 우리 원본)
```

글쓰기(②)는 파일이 아니라 **Claude가 직접** 합니다. 말투는 `docs/blog_writing_context.md` 기준.

### 한 편 만드는 흐름
```
① 글감 생성기 실행  → 이번 주 주제·수치 목록
② Claude가 본문 작성 (루멘 말투) + 카드 문구 작성
③ 카드 생성기 → PNG 6장
④ 검사기 → 통과
⑤ 원장님이 네이버에 붙여넣고 발행  ← 당분간 수동 (10분)
⑥ 같은 카드로 인스타 캐러셀 자동 게시
```

---

## 4. 왜 이게 클래스바이보다 나은가

| | 클래스바이 | 자체 도구 |
|---|---|---|
| 글감 | 시험 D-day 기준 일반 주제 | **학원앱 실제 데이터** (오답 유형, 질문 통계) |
| 카드 디자인 | 17종 고정 | 루멘 브랜드에 맞춰 자유 |
| 하루 제한 | 1편 | 없음 |
| 컴퓨터 | 윈도우 전용 | **맥미니** |
| 수정 | 불가 (난독화) | 언제든 |
| 인스타 | 없음 | 포함 |
| 네이버 저장 | 자동 8~14분 | 수동 10분 (당분간) |

바꿔 말하면 **네이버 자동 타자 하나를 포기하고 나머지를 전부 얻는** 거래입니다.

## 5. 순서

| 단계 | 내용 | 규모 |
|---|---|---|
| 1 | `docs/lumen_blog_profile.md` — 학원 정보·말투 원본 정리 | 30분 |
| 2 | `sync/blog_topics.js` — 글감 생성기 | 반나절 |
| 3 | `sync/card_render.js` + 템플릿 5종 | 1~2일 |
| 4 | 시범: 블로그 한 편 + 카드 6장 끝까지 만들어보기 | 반나절 |
| 5 | `sync/insta_upload.js` — 인스타 게시 | 1일 |
| 6 | (선택) 네이버 저장 자동화 재검토 | 미정 |

**1~4단계는 맥미니 없이 이 클라우드 채팅에서도 만들 수 있습니다.** 저장소에 올라가니
맥미니에서 `git pull`만 하면 바로 씁니다. 맥미니가 꼭 필요한 건 5단계(인스타)부터입니다.

---

## 6. 지켜야 할 선

- **클래스바이 코드를 베끼거나 역난독화하지 않는다.** 개념만 참고하고 직접 짠다
- **네이버 자동 발행은 하지 않는다.** 임시저장까지만, 발행은 사람이
- **학생 이름·개별 점수·얼굴은 콘텐츠에 넣지 않는다.** 집계·익명 수치만
- **AI로 학원 내부 사진을 지어내지 않는다** (실사진 자리에 가짜 = 허위 광고)
- **학원법**: 모집 목적 글에는 교습비·등록번호·학원명·교습과목 표시 (과태료 300만원 이하).
  교습비는 등록 금액이 아니라 학생이 실제 내는 금전 일체(교재비 포함)
- 카드에 넣은 질문은 **본문에도 글자로** 넣는다 (카드는 그림이라 검색엔진이 못 읽음)

---

## 7. 필요한 준비물

| 항목 | 용도 | 상태 |
|---|---|---|
| Node.js + Playwright | 카드 캡처 | 맥미니에 설치 필요 |
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` | 글감 집계 | 이미 있음 |
| 인스타 비즈니스/크리에이터 계정 | 자동 게시 | **원장님 작업** |
| 한글 폰트 (Pretendard 등) | 카드 글자 | 무료, 내려받으면 됨 |
| 힉스필드 (선택) | 영상·삽화 | 크레딧 과금 |

OpenAI 이미지 API는 **필수가 아닙니다.** 카드는 HTML로 그리는 게 한글이 안 깨져서 더 낫습니다.
