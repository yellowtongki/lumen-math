교재·교과서 손풀이

첫 교재는 비상 미적분 교과서(원장님 PDF). 학생은 손풀이 → 교과서 → 페이지·번호를 눌러 선생님 필기 풀이를 보고, 원장님은 교과서 PDF를 한 번 올린 뒤 페이지마다 문제 사각형에 수업 필기를 잘라 붙인다. 아이디어 1~4(풀이 빈 곳 큐 · 아하노트 자동 첨부 · 내 오답만 보기 · 복습 연결)를 두 앱에 넣은 모양이다.

Q1 답PDF를 주시면 되는가 — 된다. 이렇게

① 학원앱 교재 목록 → 「📄 교과서 PDF 올리기」→ ② 인쇄 쪽 번호 맞추기 (PDF 12쪽 = 인쇄 p.10, 한 번만)→ ③ 쪽마다 번호 글자 좌표로 문항 사각형 자동 배치→ ④ 자신 없는 자리는 「확인 필요」 노란 점선 → 원장님이 끌어 고침
  • PDF에 글자층이 있으면(출판사 PDF는 대부분 있다) 번호 글자 1. (2) 위치로 사각형을 자동으로 잡는다. 스캔본(그림만)이면 ③ 대신 AI 눈 → 상자 끌기.
  • 사각형 하나 = 매쓰플랫 문항 id 하나. 498개를 한 번 맞춰 두면 학생 채점(O/X)·아하노트·복습이 모두 같은 id로 연결된다.
  • PDF는 우리 저장소(school_pdfs) 비공개 칸에 두고, 학생앱에는 문항 사각형 조각만 나간다. 교재 전체는 학생앱에서 못 본다(등록 학생 학습용 범위).
  • 쪽 번호 맞추기는 학원앱이 PDF 아래쪽 쪽 번호 글자를 읽어 제안하고, 원장님은 「맞다」만 누르면 된다.

실측보내 주신 비상 교과서 PDF로 자동 배치를 돌려 봤다

  • 파일: 비상 「미적분」(2015 개정판) Ⅰ. 수열의 극한 — 인쇄 p.8~45 + 수학 익힘책 p.170~173, 총 43쪽. 글자층 있음, 손글씨 없음(깨끗한 교과서).
  • 쪽 번호 자동 읽기: 43쪽 중 41쪽에서 아래쪽 「24 Ⅰ. 수열의 극한」 같은 글자를 읽어 인쇄 쪽을 잡았다. 못 읽은 2쪽은 표지·간지(문제 없음). → 풀이에 쪽을 적지 않으셔도 된다는 방식이 그대로 통한다.
  • 문항 사각형 자동 배치: 문제 번호가 굵은 글꼴(16pt)로만 쓰여 있어 이것을 닻으로 삼았더니 109문항이 잡혔다. 「문제 01·02」(본문), 연습문제 5~16, 중단원 점검 1~16, 익힘책 1~25.
  • 같은 쪽에 같은 번호가 두 묶음(p.22 「1,2 / 1,3」, p.34 「1,1,2,2」)인 것은 교과서의 「문제 / 스스로 확인하기 / 생각 넓히기」 구분. 매쓰플랫 자료와 같은 현상이라 순서 + 문항 id로 구분한다.
  • ⚠️ 교재 짝: 매쓰플랫에 등록된 학생 3명의 「교과서_비상교육 미적분1」은 22개정(p.10이 함수의 극한)이고, 이 PDF는 15개정 미적분(p.10이 수열의 극한)이라 다른 책이다. 매쓰플랫 목록에는 이 책이 「교과서 (미적분) - 비상」(15개정)으로 따로 있다. 이 책을 쓰는 학생을 매쓰플랫에서 그 교재로 등록해 주시면 O/X·오답 표시가 연결된다. 등록 없이도 풀이 보기는 된다(오답 표시만 빠짐).
인쇄 p.24 중단원 점검 — 5·6·7(왼쪽 열)과 8~11(오른쪽 열)이 열별로 정확히 잡혔다. 파란 상자 하나 = 문항 하나.
인쇄 p.12 본문 — 「문제 01」 「문제 02」. 상자 아래쪽 여백은 다음 닻까지라 조금 넉넉하다. 어긋나면 끌어 고친다.
인쇄 p.171 익힘책 — 8~13. 익힘책은 글꼴이 달라도(Helvetica 굵은체) 같은 규칙으로 잡힌다.

필기 PDF가 오면 이렇게 처리한다 (쪽을 안 적어도 되는 이유)

① 필기 PDF 업로드 (굿노트, 교과서 쪽 위에 쓴 것)→ ② 쪽마다 아래 인쇄 쪽 번호 읽기 → 「이 장 = p.24」→ ③ 그 쪽의 문항 사각형(교과서 PDF에서 이미 만든 것)과 펜 자국 겹치기→ ④ 사각형 + 그 문항 근처 잉크를 한 장으로 잘라 붙임 (문제+풀이)→ ⑤ 애매한 것만 「확인 1/5」로 원장님이 고름
  • 굿노트가 교과서 PDF 위에 필기한 것을 내보내면 보통 글자층이 남아 쪽 번호를 바로 읽는다. 사진·스캔이면 아래쪽 띠만 AI 눈으로 읽는다(쪽당 몇 원).
  • 잉크가 두 문항에 걸치면 더 많이 겹친 쪽에 붙이고 「확인」 표시. 여백에 따로 쓴 풀이는 가장 가까운 문항.
  • 한 문항에 방법이 둘이면(이정민 화면의 「1 무게중심 / 2 직접 증명」) 잘린 조각을 두 장으로 두고 제목만 붙인다.
