## 1. 규칙 칸 (rc_ws_rule 에 더하는 칸 · 기본값)
| 칸 | 기본 | 뜻 |
|---|---|---|
| `recent` | `{ on:true, days:28 }` | 테스트 범위와 상관없이 최근 N일 «문제별 마지막 결과가 아직 X» 인 문제(교재 `workbook_problem_id`, 학습지 `problem_id` 단위 — 다시 풀어 맞힌 것은 뺌)를 재료에 넣는다. 테스트 오답·범위 안 교재 오답과 겹치면 한 번만. |
| `perType` | `true` | 최근 오답·교재 오답은 **유형(concept)마다 1개**로 묶는다 — 같은 유형을 2번 이상 틀렸으면 그 유형만 2개. 테스트 오답 쌍둥이는 묶지 않는다. |
| `max` | `40` | 학생 한 명 문항 상한. 넘으면 우선순위대로 남긴다: 테스트 오답 쌍둥이 첫째 → 최근 오답(새것 먼저) → 교과서 같은 유형 → 쌍둥이 둘째 → 보강 → 범위 안 교재 오답. |
| `min` | `30` | 하한. 모자라면 ① 최근 오답 기간을 56일까지 넓혀 다시 찾고 ② 그래도 모자라면 테스트·최근 오답 유형의 같은 유형 문제로 채운다(보강으로 셈). |
| `exclude` | `''` | 뺄 유형 이름 정규식(예 `농도`) — mf_concept_names 이름이 맞는 유형은 모든 재료와 쌍둥이 고르기에서 뺀다. |
- `per[학생키]` 에 학생별로 `recent:false` · `max` · `min` 을 덮어쓸 수 있다(학원앱 설계 팝업에서).
- 서버판 `rcws_make.js`: 위 값을 `rc_ws_rule` 에서 기본으로 읽는다(명령줄 옵션이 있으면 그것이 이긴다). 옛 기본(쌍둥이 2·교과서 1·교재 1·보강)은 그대로 — 새 칸은 위 기본값.
