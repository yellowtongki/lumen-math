# ✍️ 아하노트 종이 전용 입력 + 종합리그 잠금·설명 + 루멘스피치 이름 (원장 결정 2026-09-17)

원장: 「앱에 적는 것을 없애고, 노트에 적고, 노트에서 글씨를 읽은 것을 학생앱에서 수정해서 올리는 것으로 바꾼다. 안내는 『노트에 적고 사진 찍으세요. AI가 글씨를 제대로 읽었는지 확인하고 수정해 주세요』」
설계서 `docs/aha_journey_spec.md` D7(입력 경로 = 사진 한 장, 앱에 LAMP textarea를 두지 않는다)을 실제로 지키는 판. 말하기 리그 이름은 **「루멘스피치」**(🎤)로 바꾼다.

## 1. 학생앱 (v2-88) — 아하노트 확인 화면
- 사진 단계 안내(기존 `#aha-paper-first` 교체): 「✍️ **노트에 적고 사진 찍으세요.** AI가 글씨를 제대로 읽었는지 확인하고 고쳐 주세요. 점수는 종이에 쓴 것만 매겨요.」
- 확인 단계 안내(`#aha-read-msg`): 「AI가 읽은 글이에요. 잘못 읽은 곳만 **✏️ 고치기**로 바로잡아 주세요. 종이에 없는 칸은 점수에 안 들어가요.」
- L·A·M·P 네 칸: **읽기 전용 상자**로 보인다(글·줄바꿈 그대로). 상자 오른쪽 위 「✏️ 고치기」를 누르면 그 칸만 textarea로 바뀌어 고칠 수 있고, 「완료」로 닫힌다. 처음부터 textarea가 열려 있지 않다.
- AI가 **빈칸으로 읽은 칸**(`unread`): 잠긴 상자 + 「종이에 안 적었어요 → 종이에 쓰고 📷 다시 찍기」(v2-84 안내 줄 재사용). 고치기 단추 없음. **타이핑 불가.**
  - 예외 **P칸만**: P는 노트의 핵심(막힌 곳·질문)이라 비면 보낼 수 없다. AI가 P를 못 읽었으면 「📷 다시 찍기」를 먼저 권하고, 그 아래 작은 글 「그래도 사진이 잘 안 읽히면 → ✏️ 직접 적기」를 두어 적을 수 있게 한다. 이때 `lamp_ai.edits.P.typed=true`로 표시(점수 규칙은 그대로 0점, 학원앱에 「직접 적음」 배지).
- **고친 정도 저장**: 보낼 때 `lamp_ai.edits = { L:{changed:true|false, ratio:0.0~1.0}, A:{…}, M:{…}, P:{…, typed?} }` — ratio = 고친 뒤 글과 AI 원문의 글자 편집 거리 ÷ 둘 중 긴 길이(간단한 레벤슈타인, ES5 함수 `ahaEditRatio(a,b)`). AI 원문은 `lamp_ai.L/A/M/P`에 이미 있으니 그대로 둔다.
- 틀린 이유 칩: AI가 읽은 `reason`으로 미리 고르고, 학생이 바꿀 수 있음(그대로). 관련 개념 칩·자기평가·지시어·노트 종류: 그대로.
- 노트 고치기 화면(`ahaEdit`)도 같은 규칙(읽기 전용 + 고치기).
- 질문력 미터(`ahaMeter`)는 v2-84 규칙 그대로.

## 2. 학생앱 (v2-88) — 리그
- 「🎙 말하기」 → **「🎤 루멘스피치」** (탭·홈 배너·상금 한눈에·종합 표·설명 문구 모두). 준비 중 표시는 「11월 시작」.
- **종합 탭 설명**을 아래 글로 바꾼다(`lgTotalHtml` 머리, 점수표는 발행된 `champion.points`로 그림):
  「👑 종합 챔피언은 이렇게 정해요 ① 종목(🏁 진도 · 💡 IB아하 · 📔 플래너 · 🎤 루멘스피치)마다 순위가 나오면 점수로 바꿔요: 1위 25점 · 2위 18점 · 3위 15점 · 4위 12점 · 5위 10점 · 6위 8점 · 7위 6점 · 8위 4점 · 9위 2점 · 10위 1점 (11위부터 0점이지만 참여한 걸로 쳐요) ② 종목 점수를 다 더해요. **두 종목 이상** 참여한 사람만 순위에 들어요. ③ 시즌이 끝나면 1등이 종합 챔피언이에요. 예) 진도 3위(15) + IB아하 9위(2) + 플래너 1위(25) = 42점. 📔 플래너는 달마다 순위가 새로 나와서 달마다 점수를 받아요.」
  내 줄: 종목마다 「진도 3위 → 15점」 꼴로, 그리고 「한 계단 오르면 +n점」(다음 순위 점수 − 지금 점수).
- **종합 상 비공개**: 발행에 `champion.prize`가 없으면(학원앱이 뺐으면) 상금 한눈에 줄은 「비공개」, 종합 탭의 상 카드는 숨긴다.
- `STU_VER='v2-88'` + 버전 메모.

## 3. 학원앱 (v19-11)
- 리그 설정 「👑 종합 챔피언 상」 칸에 **「학생앱에 보이기」 스위치**(`champion.showPrize`, 기본 true). 발행(`lgPublishBoard` 등 champion을 싣는 두 곳)에서 false면 `prize`를 아예 싣지 않는다. `ibqCfgFill`에 기본값.
- 「🎙 말하기」 → **「🎤 루멘스피치」**(설정 칸 이름·리그 화면·발행 문구). `speaking` 저장 키는 그대로.
- 채점 작업대: 가운데 줄(`wbMiniRow`)과 오른쪽 칸에 `lamp_ai.edits` 기준 배지 — 「✏️ 고침 n칸」(회색), 어느 칸이든 `ratio ≥ 0.5`면 「✏️ 많이 고침 · 사진 확인」(주황), `P.typed`면 「직접 적음」(주황). 오른쪽 「앱에 적힌 글」 칸에서 고친 칸은 AI 원문을 회색 작은 글로 함께 보여 준다(원장이 대조).
- `APP_VER='v19-11'` + 버전 메모.
