# 블로그·인스타 자동화 — 설계와 작업 분담

**작성일**: 2026-09-20 · 배경 자료: `docs/blog_automation_overview.md`(도구 구조), `docs/ideas.md` 2번

이 문서는 **원장님 컴퓨터의 Claude Code가 읽고 이어받는 용도**입니다.
클라우드 채팅(학원앱 개발)과 컴퓨터 채팅(블로그 실무)이 서로 기억을 공유하지 않으므로,
이 파일이 두 곳을 잇는 다리 역할을 합니다.

---

## 1. 목표

1. 블로그 글의 **글감을 학원앱 데이터에서** 뽑는다 (다른 학원이 못 따라 하는 부분)
2. 블로그 글을 쓰면 **인스타 캐러셀이 자동으로 따라 올라간다**

---

## 2. 왜 채팅을 나누나 — 파일이 있는 곳이 다르다

| 일 | 어디서 | 이유 |
|---|---|---|
| 학원앱 개발, 글감 뽑기 | **클라우드 채팅** (claude.ai/code) | Supabase·저장소에 붙어 있음. 컴퓨터 필요 없음 |
| 블로그 글쓰기·네이버 임시저장 | **컴퓨터 Claude** | 블로그 도구가 컴퓨터에 깔려 있음 |
| 인스타 업로드 | **컴퓨터 Claude Code** | 카드 PNG가 컴퓨터 `out` 폴더에 있음 |

> 컴퓨터의 Claude Code에서 이 저장소를 클론해두면 **저장소 + 컴퓨터 파일 + 블로그 도구**를
> 한자리에서 다룰 수 있다. 이것이 "다리"다.

---

## 3. 다리가 되는 파일 3개

```
sync/blog_topics.js          글감 생성기 — Supabase 집계 → 아래 파일 출력
docs/blog_topics_latest.md   이번 주 글감 (숫자 포함, 익명 집계만)   ← 컴퓨터 채팅이 읽는다
sync/insta_upload.js         out 폴더 카드 → 인스타 캐러셀 업로드
```

흐름:

```
[클라우드] sync/blog_topics.js 실행 (주 1회 자동)
    → docs/blog_topics_latest.md 갱신 → git push
                    ↓
[컴퓨터] git pull → Claude가 그 파일을 읽고 블로그 도구에 글감 전달
    → 네이버 임시저장 → 원장님이 발행
    → out 폴더에 카드 6장 생성됨
                    ↓
[컴퓨터] sync/insta_upload.js → 인스타 캐러셀 게시
```

**자동 실행**: `.github/workflows/`에 매쓰플랫 수집 예약이 이미 있으므로 같은 방식으로
주 1회 글감 생성을 걸 수 있다 (컴퓨터를 켜둘 필요 없음).

---

## 4. 글감으로 쓸 수 있는 학원앱 데이터

블로그 도구의 카드 종류 중 **"수치" 카드**가 있다. 우리 앱은 수치가 넘친다.

| 출처 | 글감 |
|---|---|
| 매쓰플랫 정오답(`mf_answer_records`) + 유형DB | "이번 주 가장 많이 틀린 유형 TOP3" |
| 아하노트(`aha_notes`) | "학생들이 가장 많이 물어본 질문" |
| 진학 나침반(`compass_hs_db`) | 부천 고교별 입시 정보 시리즈 → 지역 검색 유입 |
| 리커버리 선발 기준(`RC.cfg`) | 시스템 소개 (기존 블로그 글 톤 그대로) |
| 주간테스트 결과 | "시험 3주 전, 우리 학생들 점수 변화" |

### 🔒 개인정보 규칙 (반드시 지킬 것)
- 학생 **이름·개별 점수·사진은 글감 파일에 넣지 않는다.** 집계 수치와 익명 문장만.
- `docs/blog_topics_latest.md`는 커밋되는 공개 파일이다. 개인정보가 들어가면 안 된다.
- 실사진은 학생 얼굴·이름이 없는 것만, 원장님이 한 장씩 확인 후 사용.
- **AI로 학원 내부 사진을 지어내지 않는다** (실사진 자리에 가짜 = 허위 광고).

---

## 5. 단계별 계획

| 단계 | 내용 | 어디서 | 규모 |
|---|---|---|---|
| 1 | `sync/blog_topics.js` — 글감 생성기 | 클라우드 | 작음 |
| 2 | 주 1회 자동 실행 (GitHub Actions) | 클라우드 | 작음 |
| 3 | 컴퓨터 Claude Code에 저장소 클론 + 블로그 도구 등록 | 컴퓨터 | 설정만 |
| 4 | `sync/insta_upload.js` — 인스타 업로드 | 컴퓨터 | 중간 |

**1단계 전에 손으로 먼저 해보기**: 이번 주 `out` 폴더 카드 6장을 손으로 인스타에 올려
반응을 본다. 콘텐츠가 안 먹히면 자동화는 헛수고다.

## 6. 컴퓨터 Claude Code 첫 프롬프트 (복사해서 쓰기)

```
루멘수학 저장소를 클론하고 docs/blog_insta_automation_plan.md 를 읽어줘.
그다음 docs/blog_automation_overview.md 로 블로그 도구 구조를 파악해줘.
오늘 할 일은 3단계 — 블로그 도구를 Claude Code에도 등록하는 것이다.
%APPDATA%\Claude\claude_desktop_config.json 에 등록된 Classby 블로그 MCP를
claude mcp add --scope user 로 이름 classby-blog 로 등록해줘.
(이름에 한글·띄어쓰기가 들어가면 등록이 거부된다)
```

## 7. 인스타 게시에 필요한 준비

- 인스타 계정을 **비즈니스 또는 크리에이터**로 전환 (필수)
- 가장 쉬운 시작: **메타 비즈니스 스위트** (무료, 공식, 예약 게시). 컴퓨터 불필요
- 완전 자동화는 Instagram Graph API 또는 중개 서비스(Blotato, Markifact 등, 유료)
- 카드가 공개 URL에 있어야 API가 가져갈 수 있음 → GitHub Pages 활용 가능

---

## 8. 주의사항

- 네이버는 공식 글쓰기 API가 2020년 종료 → 브라우저 조종 방식뿐. **자동 발행은 하지 않는다**
  (기계가 쏟아내는 블로그는 저품질 처리됨). 임시저장까지만, 발행은 원장님이.
- 블로그 도구는 난독화돼 있고 **수정은 라이선스 위반**. 바깥에서 연결만 한다.
- `profile.json`(학원 정보·말투) 폴더는 지우면 안 된다.
- **학원법**: 모집 목적 글에는 교습비·등록번호·학원명·교습과목 표시 의무.
- 말투 자료가 `profile.json`과 `docs/blog_writing_context.md` 두 군데 있다.
  **한쪽을 원본으로 정할 것** (어긋나면 글 톤이 흔들림).
