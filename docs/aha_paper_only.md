# 아하노트 「종이에 쓴 것만 매긴다」 (원장 결정 2026-09-15)

## 배경 (실측: 김예성 9/14 22:35 노트, 610번)
- 활동지 사진에는 P칸만 「옳은 게 없는 것 같아요」, L·A·M은 빈칸. 번호는 670인데 AI가 610으로 읽음.
- 학생앱은 AI가 못 읽은 칸(`lamp_ai.unread` = L,A,M)을 노란 칸으로 보여 주고, 학생이 그 칸에 문제 지문·이론을 **타이핑**해 채웠다.
- 학원앱은 그 타이핑 글을 「📝 활동지에 쓴 글」이라 보여 주고, AI 초안도 그 글로 5/10을 매겼다 → 원장 「사진과 채점이 다르다」.

## 규칙
1. **점수는 종이에 쓴 것만.** `lamp_ai`가 있고 `lamp_ai.unread`에 든 칸(L·A·M·P)은 「종이에 없는 칸」으로 보고, 앱에 글이 있어도 **점수 0, AI 초안 프롬프트에는 「(종이에 없음)」**으로 보낸다. `lamp_ai`가 없는 옛 노트(사진 읽기 전)는 지금처럼 매긴다.
   - 사진 읽기 함수(엣지 `aha-read`)는 빈칸으로 읽힌 칸을 반드시 `unread`에 넣는다(이미 그렇게 함). 학원앱 「📷 사진 읽기」(`ibqReadPhoto`)도 같은 규칙으로 `unread`를 다시 쓴다 — 원장이 다시 읽히면 판정이 바뀐다.
   - AHA(7단계)·자기평가·경로 보너스는 그대로.
2. **학원앱 표시**: 오른쪽 칸 제목 「📝 활동지에 쓴 글」 → 「📝 앱에 적힌 글」. `unread`인데 글이 있는 칸에 배지 「✍️ 앱에서 직접 적음 · 점수 제외」(주황). 점수 칸(L·A·M·P 0/1/2)도 그 칸은 회색+「종이에 없음」 표시하고 0 고정(원장이 눌러도 안 바뀜; 「📷 사진 읽기」로 다시 읽으면 풀림). 가운데 줄에도 작은 표시 「✍️2」(앱에서 적은 칸 수).
3. **학생앱 안내**:
   - 사진 단계 위 안내 한 줄: 「✍️ 점수는 **종이에 쓴 것만** 매겨요. 앱에서 적어 넣은 글은 점수에 들어가지 않아요.」
   - 확인 화면에서 못 읽은(노란) 칸 밑에: 「종이에 없는 칸이에요 → 점수에 안 들어가요. 종이에 쓰고 **📷 다시 찍기**」(다시 찍기 링크). 칸은 여전히 고칠 수 있게 둔다(AI가 잘못 읽은 글 고치기용).
   - AI가 읽은 **쪽·번호** 칸을 파랗게 강조하고 「AI가 읽은 번호예요 — 맞는지 확인」 한 줄.
   - 「다시 찍기」 뒤 AI 읽기가 실패하면 L·A·M·P 칸을 **비운다**(앞 사진에서 읽은 글이 남지 않게).
4. 버전: 학원앱 v19-4, 학생앱 v2-84.
