# 📄 수학비서 학습지 — 루멘이 자동채점한다 (원장 결정 2026-09-17)

원장님 목표: **「자동채점 학습지로 만드는 것」**.
매쓰플랫은 **객관식만** 자동채점한다(단답은 답이 숫자 하나여도 안 한다 — 2026-09-17 실측).
그래서 **못 하는 부분은 루멘이 채점하고, 결과를 매쓰플랫에 써 넣는다.**

## 1. 정답 대장 — `mf_wsans_<학습지id>` (만들어 둠)

`sync/mf_answerkey.js` 가 **수학비서 원본**에서 뽑아 저장한다.
`sync/mypaper_to_mathflat.js` 는 학습지를 만든 직후 이 스크립트를 자동으로 돌린다.

```js
{ wid, title, msPaperId, n, range:"1~108", updated, source:'mathsecr',
  autoFlag:false,        // 매쓰플랫이 「자동채점 학습지」로 보는가 (모든 문항이 객관식일 때만 참)
  mfAuto:29,             // 매쓰플랫이 채점하는 문항 수
  lumenAuto:94,          // 루멘이 채점할 수 있는 문항 수
  selfN:14,              // 학생이 스스로 ◯✗ 하는 문항 수
  items:[ {
    no:1,                // 원본 프린트 번호
    wpIndex:1,           // 학습지 안 순서 (배정마다 바뀌는 wpId 대신 «순서»로 잇는다)
    pid:2995707,         // 문제은행 문항 id (순서가 어긋났는지 확인용)
    cnt:3,               // 답 칸 수
    kind:'ox',           // choice | ox | num | text | latex | mixed
    shape:'ox',          // 학생앱 입력 모양 (엔진 shape 과 같은 말)
    self:false,          // 스스로 채점으로 넘길 문항인가
    gradable:true,
    unit:'개',           // 있을 때만
    parts:[ { seq:1, t:'boolean_choice', v:'X', tex:'X', disp:'O/X',
              img:'https://cdn.mathsecr.com/…png' } ],   // img = 그 칸의 정답 그림
    mfType:'SHORT_ANSWER', mfAnswer:'False, False, True', mfAuto:false   // 매쓰플랫 쪽 값(참고)
  } ] }
```

- `parts[].t`: `single_choice` · `multiple_choice` · `boolean_choice` · `integer_answer` · `short_answer` · `latex_answer`
- 참거짓은 `v` 가 **`O` / `X`** 로 들어 있다(수학비서의 True/False 를 바꿔 담았다).
- 개인정보 없음(문제지 정답만).

**현재 저장된 것** — 6장 509문항: 매쓰플랫 163 · 루멘 480 · 스스로 29.
그 중 「[비상] 중등수학 1-2 중간 (위치,작도)」(`mf_wsans_82557472`) 108문항 = 매쓰플랫 29 · 루멘 94 · 스스로 14.

## 2. 학생앱 (v2-89) — 대장이 있으면 그것으로 받고 채점한다

**바꿀 곳은 학습지 경로뿐이다. 교재 채점은 건드리지 않는다.**

1. `bkOpenWs(swId)` 에서 그 학습지의 대장을 읽는다 — `mf_wsans_<w.wid>` (`bkFetchStore` 로 한 번에).
   없으면 지금과 똑같이 동작한다(옛 학습지·매쓰플랫 자체 학습지).
2. 대장이 있으면 문항마다 `wpIndex`(=문항 순서) 로 이어 붙인다. `p.key = 대장 items[i]`.
   순서가 어긋나면(문항 수가 다르면) 대장을 **쓰지 않는다**(안전).
3. `bkShape(p)` 가 **대장을 가장 먼저** 본다 (엔진보다 앞).
   - `kind:'ox'` → 칸마다 **O / X 단추** (`shape:'ox'`), 전부 맞아야 ◯
   - `kind:'choice'` → 지금과 같은 ①~⑤ 단추 (복수 정답이면 여러 개 고르기)
   - `kind:'num'` → 숫자 칸 (`cnt` 만큼)
   - 여러 칸(`cnt>1`) → **칸마다 입력칸**을 그리고 칸별로 견준다 (모두 맞아야 ◯, 부분 맞음은 ✗)
   - `self:true` → 자기채점. 이때 **정답 그림(`parts[].img`)을 칸 번호와 함께** 보여 준다
     (지금은 매쓰플랫 정답 그림 한 장만 나온다 — 대장 그림이 칸마다 있어 더 정확하다)
4. 채점 비교는 엔진(`HWGrade.grade`)을 그대로 쓰되, **칸마다 따로** 부른다.
   한 칸이라도 틀리면 ✗. 엔진이 못 견주는 칸이 하나라도 있으면 그 문항은 자기채점으로 돌린다.
5. 저장·되돌려쓰기는 **지금 그대로** (`hw_scores_<code>` 키 `ws_<swId>_<wpId>` → 워커 → 매쓰플랫).
6. 학습지 목록 줄에 **「루멘 자동채점 n문항」** 을 작게 보여 준다 (대장이 있을 때만).
7. 안내 문구: 「문제는 종이 학습지로 풀고, 여기서는 답만 넣어요」 아래에
   「**매쓰플랫이 못 채점하는 문항도 루멘이 채점해 선생님께 보냅니다**」 한 줄 추가.

**손대지 말 것**: 채점 엔진 인라인 블록(`★ v2-82: 아래 블록은 sync/hw_grade_engine.js 를 그대로 복사` ~ `})(typeof globalThis…);`), 교재 채점 경로, 다른 탭.

## 3. 학원앱 (v19-14) — 「📄 학습지 채점」 현황

「오늘의 확인」 그룹에 화면 하나를 더한다(기존 화면은 건드리지 않는다).

- **목록**: 대장이 있는 학습지부터, 줄마다
  제목 · 문항 수 · **매쓰플랫 n / 루멘 n / 스스로 n** 칩 · 배정 학생 수 · 푼 학생 수 · 평균 점수.
- **학습지 하나를 누르면**: 학생별 표(진행·점수·◯✗ 수), 문항별 칸(◯✗·미채점),
  **스스로 채점으로 넘어간 문항 번호**를 따로 모아 보여 준다(원장님이 눈으로 확인할 것).
- **되돌려쓰기 상태**: `hw_sync_<code>` 대기열에 남은 건수를 보여 준다(매쓰플랫에 아직 못 보낸 것).
- 자료: `mf_wsans_<wid>`(대장) · `mf_wsq_<code>`(학생별 목록·문항) · `hw_scores_<code>` · `hw_sync_<code>`.
  전부 이미 서버에 있고, 학원앱은 읽기만 한다.
