## 1. 초등에서 더 읽어야 하는 답 모양 (실제 정답 예)
| 모양 | 정답 예 | 규칙 |
|---|---|---|
| geo (한글 점 이름) | `점 ㄱ` `선분 ㄱㄴ, 선분 ㄹㄷ` `변 ㄹㄴ` `면 ㅁㅂㅅㅇ` `각 ㄹㄴㄷ` `직선 ㄱㄴ` `반직선 ㄴㄱ` | 점 이름이 **한글 자모 ㄱ~ㅎ**. 영문 A~Z와 같은 규칙(선분·변·면·호는 순서 무관, 각은 가운데 글자 기준 대칭, 반직선은 순서 유지). 「점」「변」「면」「각」 낱말은 학생이 안 써도 정답 |
| mark (원문자 확장) | `㈏` `㉮` `㉠` | `㈎~㈛`·`㉮~㉻`·`㉠~㉭` 을 순서 번호로(㈎=㉮=㉠=1). 기존 ㄱ~ㅎ·①~⑮·(1)~ 과 같은 묶음 |
| pick (○표 자리) | `( )( ○ )` `[ ][○]` `( )( ○ )( )` `(\ \ \ \ )(\ ○\ )(\ \ \ \ )` | 괄호/대괄호 칸 n개 중 ○가 있는 칸의 **번호**(1부터)로 정규화. `parts=[{kind:'pick', n:3}]`. 학생앱은 칸 n개를 그려 누르게 한다. ○가 여러 칸이면 번호 여러 개(순서 무관) |
| choice (낱말 중 고르기) | `십에 ○표 / 백에 ○표` `이상에 ○표 / 이하에 ○표` `초과에 ○표 / 미만에 ○표` | `/` 로 나뉜 각 조각에서 「X에 ○표」의 X를 답으로. `parts=[{kind:'choice', options:['십','백']}, …]` 처럼 **보기 낱말을 함께** 준다(정답 낱말 + 그 문항에 나오는 다른 낱말; 없으면 흔한 짝: 십/백/천, 이상/이하, 초과/미만, 크다/작다, 예/아니요). 학생앱은 칩으로 보인다 |
| op (연산 기호) | `\times, -, \div, +` `(\times)` `+, -` | `\times`→`×`, `\div`→`÷`, `(×)`→`×`. 기호 나열은 **순서 유지** 비교. `parts` 는 기호 칸 n개, kind `op`. 학생앱 자판에 `+ − × ÷ =` |
| unit 낱말 답 | `㎢` `㎡` `cm` `L` | 단위 **자체가 답**인 문항(값 없이 단위만). shape `word`로, 학생앱은 단위 칩(㎟ ㎠ ㎡ ㎢ / mm cm m km / mL L / g kg t)을 보인다 |
| 각도 표기 | `40^{\circ}` `90^{\circ}` | `^{\circ}`·`^\circ`·`°`·`˚` 를 모두 `°` 로 |
| 접두 안내문 | `(위에서부터)\frac{1}{8}, \frac{3}{8}` `(왼쪽부터) 3, 5` | 괄호 안내문 `(위에서부터)`·`(왼쪽부터)`·`(왼쪽에서부터)`·`(위에서부터 차례로)` 는 떼고 나머지를 읽는다. **순서 유지** 복수답 |
| 시각·시간 | `3시 20분` `1시간 30분` `2시 15분 30초` | 시·분·초 낱말 단위를 이름표로 본 여러 칸(`parts=[{label:'시'},{label:'분'}]`, 학생은 숫자만). 값은 초 단위로 환산해 비교 |
| 여러 단위 길이·무게 | `3m 20cm` `1kg 300g` `2L 500mL` | 위와 같은 방식. 칸마다 단위 이름표. `320cm`=`3m 20cm` 처럼 환산 같으면 정답 |
| 어림 | `약 1600` `약 3000원` | 「약」은 떼고 값 비교 |
| 비교 기호 답 | `>` `<` `=` | 기존 mark의 부등호 한 글자 규칙 그대로 |

원칙 그대로: **정답 원문 그대로 → 반드시 correct**. 조금이라도 못 읽으면 `self:true`.

## 3. 학생앱 (v2-82)
- 도형 자판에 **한글 자모 줄** 추가: `ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ` + `점 선분 직선 반직선 변 면 각`. 학생 학년이 초등이면(학생 정보 `grade`가 「초」로 시작) 도형 자판이 **한글 자모 줄을 먼저** 보인다.
- `parts[i].kind==='pick'` → 칸 n개(빈 상자)를 그려 누르면 ○, 여러 개 가능. `choice` → `options` 칩. `op` → `+ − × ÷ =` 단추 칸. 시각·단위 여러 칸 → 기존 이름표 칸(라벨 「시」「분」「m」「cm」) 재사용.
- 단위만 답인 word 문항은 단위 칩 묶음을 보인다.
- 그 밖은 v2-81 그대로. `STU_VER='v2-82'`, 버전 메모.
