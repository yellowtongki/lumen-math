만드는 순서 상의 후

1
틀 먼저 (학원앱 v19-104)3분할 격자와 「탭마다 왼쪽·오른쪽 내용」을 끼우는 자리만 만듭니다. 아직 아무 탭도 안 옮긴 상태라 홈은 지금과 같고, 다른 탭은 왼쪽에 「공용 메뉴 ▸」(접힘)만 보입니다. 폰에서는 변화 없음.
2
적중 분석부터 옮기기 (v19-105)원장님이 지금 제일 많이 쓰는 화면. 오른쪽에 우리 자료 3종·다시 판정·카드뉴스·보고서·블로그 폴더를 모읍니다. 가운데 화면의 같은 단추는 그대로 두어 어느 쪽을 눌러도 됩니다.
3
백지테스트 · 리커버리 (v19-106)학생 목록을 왼쪽으로, 트리·규칙·인쇄를 오른쪽으로. 가운데가 넓어져 A4 미리보기가 커집니다.
4
나머지 탭은 쓰시면서 하나씩수업·출결, 진도·리포트, 운영은 지금 화면이 불편한 것부터.
여쭐 것
  1. 공용 항목(진도 현황·리커버리·명예의 전당 …)을 홈이 아닌 탭에서 「공용 메뉴 ▸」로 접어 두는 것 괜찮으신가요? 늘 보이길 원하는 항목이 있으면 말씀해 주세요(예: 리커버리는 항상).
  2. 옮기는 순서를 적중 분석 → 백지테스트·리커버리 → 나머지로 해도 될까요?
  3. 괜찮으면 먼저 결과 화면의 「📂 우리 자료 고르기 → 다시 판정」 단추(v19-103)를 넣고, 이어서 1·2단계를 Opus로 만들겠습니다.
