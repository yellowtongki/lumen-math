속에서 일어나는 일 만들 때 이렇게

교과서 은행 자동 만들기학생별 교과서 지정(mf_textbooks)에서 그 학교·학년 책을 찾고, 은행(mf_textbook_<책>)이 없으면 새벽 수집에서 만듭니다(지금 교과서 은행 만드는 도구 그대로). 문항마다 유형 번호가 있어 판정에 바로 씁니다.
수학비서 학습지 → 문항 단위폴더 목록(올린 날짜 · 문항 수 · PDF 있음)은 수학비서가 줍니다. 문항 그림은 기출 DB 받기와 같은 길로 받고, 매쓰플랫 AI 인식(기출 쌍둥이 파이프라인)으로 유형·원본 번호를 붙여 ms_paper_<id> 에 저장합니다. 한 장 2~5분이라 새벽에 학년 폴더를 미리 돌려 둡니다.
PDF 자료함올린 파일은 비공개 자리(exam_images/lib)에, 목록은 exam_lib 키에 (제목 · 학교 · 학년 · 학기 · 올린 날 · 인식 상태). 인식은 수학비서 학습지와 같은 길. 학생앱·학부모앱에는 아무것도 안 갑니다.
판정은 그대로네 출처가 한 자료 목록(kind: textbook · ms · upload · ws/book)으로 합쳐져 지금 엔진(원본 번호 같음 → 같은 문제, 쌍둥이 → 변형, 유형 번호 → 유형)을 탑니다. 결과에 kind 별 집계만 더합니다.
즉시 처리GitHub 토큰을 학원앱 설정에 넣으면 요청을 남길 때 서버 작업을 바로 깨워 1분 안에 시작합니다(지금은 예약 실행이 몇 시간씩 늦음). 토큰은 원장님 브라우저에만.

만드는 순서 상의 후

1
서버 — 수학비서 학년 폴더 새벽 인식 + 교과서 은행 자동 (sync/exam_hit_worker.js · mathflat_collector.js)학년 폴더(고1·고2·중1~3)에서 기간 안에 올린 학습지를 찾아 문항을 받고 매쓰플랫 AI 로 인식 → ms_paper_<id>. 지정 교과서 은행이 없으면 만들기. 둘 다 새벽 4시 회차.
2
워커 — 우리 자료 모으기를 4출처로 (loadMaterials)교과서 전체(또는 범위 단원) + 체크한 수학비서 학습지 + 자료함 PDF + 매쓰플랫 기록. 결과에 자료별 집계.
3
학원앱 — 요청 화면·자료함·결과 막대 (v19-99)위 시안 화면. 「이 구성 기억」으로 학교·학년마다 폴더·체크를 저장. 결과 화면과 보고서·블로그 .md 에 자료별 적중.
4
즉시 처리 (토큰 받으면 같이)학원앱 설정에 GitHub 토큰 칸. 적중 분석 · 지금 가져오기 · 기출 DB 목록 새로 받기가 요청 즉시 시작.
