## 2. 이미 정해진 것 — 다시 논의하지 마세요

### ① 네이버 자동 저장도 만든다 — 단, 발행은 사람 (2026-09-20 원장 결정)
처음엔 "네이버 저장은 미루자"였으나 **원장님이 전부 자체 제작으로 결정**했습니다.
기술적으로 못 할 이유가 없습니다 — `sync/mathflat_collector.js`가 이미 같은 Playwright로 매쓰플랫을 조종합니다.

지킬 선 (클래스바이도 같은 선을 지킵니다):
- **맥미니에서만** 실행. 클라우드에서 돌리면 데이터센터 IP로 캡차
- **사람 타자 속도**(8~14분). 빨리 치면 기계로 잡힘
- **임시저장까지만.** 발행 버튼은 원장님이 직접 — 저품질 처리는 되돌릴 수 없음
- 네이버 비밀번호는 코드·환경변수에 두지 않음. 원장님이 창에 직접 입력, 쿠키만 저장

→ 순서는 **마지막(6단계)**. 글감·카드·검사·인스타를 먼저 만든 뒤 붙입니다.
→ 새 채팅은 "자동 발행까지 해드릴까요?"라고 제안하지 않습니다. 발행은 사람이라는 선은 유지.

### ② 클래스바이 코드를 베끼지 않는다
윈도우 데스크탑에 `classby-blog`라는 상용 도구가 설치돼 있고, 그 구조 분석이
`docs/blog_automation_overview.md`에 있습니다. **난독화돼 있고 수정·역난독화는 라이선스 위반**입니다.
개념만 참고하고 코드는 처음부터 새로 짭니다.

### ③ 카드는 AI 그림이 아니라 HTML을 캡처해서 만든다
생성형 AI는 한글 글자를 깨뜨립니다. HTML로 그려 Playwright로 찍으면 글자가 정확합니다.
크기는 **1080×1350**(인스타 세로 규격) — 블로그 카드와 인스타 캐러셀을 **같은 파일로** 씁니다.

## 5. 하지 말 것

- ❌ **네이버 자동 "발행"** — 임시저장까지만 자동. 발행 버튼은 원장님 (위 2-①)
- ❌ **클라우드 서버에서 네이버 조종** — 데이터센터 IP 감지 + 캡차. `naver_draft.js`는 맥미니에서만
- ❌ **클래스바이 코드 복사·역난독화** — 라이선스 위반
- ❌ **학생 이름·개별 점수·얼굴을 콘텐츠에 사용** — 집계·익명 수치만.
  `docs/blog_topics_latest.md`는 공개 저장소에 커밋되는 파일임
- ❌ **AI로 학원 내부 사진 생성** — 실사진 자리에 가짜 = 허위 광고.
  힉스필드는 개념 삽화·배경에만
- ❌ **비밀번호·API 키 커밋** — 환경변수만

## 6. 콘텐츠 규칙 (블로그 글에 반드시 반영)

- **학원법**: 모집 목적 글에는 **교습비·등록번호·학원명·교습과목** 표시 의무
  (학원법 제15조제3항, 과태료 300만원 이하).
  교습비는 교육청 등록 금액이 아니라 **학생이 실제 내는 금전 일체**(교재비 포함)
- **카드에 넣은 질문은 본문에도 글자로** 넣는다 (카드는 그림이라 검색엔진이 못 읽음)
- 지도에 쓰는 이름은 **"루멘수학교습소"** (블로그 표기는 "루멘수학" — 플레이스 등록명이 다름)
- 확인 안 된 숫자·연도는 지어내지 말고 비워둔 뒤 원장님께 확인
