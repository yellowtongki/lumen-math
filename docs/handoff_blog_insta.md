# 📮 전달사항 — 블로그·인스타 자동화 (새 채팅용 인수인계)

**작성일**: 2026-09-20 · **작성**: 클라우드 채팅(학원앱 저장소)
**읽는 사람**: 원장님 컴퓨터의 Claude Code (블로그·인스타 실무 담당)

---

## 🔄 2026-09-20 방향 전환 — 자체 도구를 만든다

원장님 결정: 클래스바이 도구에 의존하지 않고 **맥미니에서 도는 자체 도구를 새로 만든다.**
설계는 **`docs/lumen_blog_tool_design.md`** 를 보라 (이 문서보다 우선).

핵심 판단: 블로그 한 편은 5조각인데 **네이버 자동 저장만 어렵고 나머지는 쉽다.**
자동 저장(8~14분)과 수동 붙여넣기(10분)는 시간 차이가 거의 없으므로
**네이버 저장은 당분간 사람이 하고** 글감·글·카드·인스타를 자동화한다.

아래 내용은 클래스바이 도구를 쓰던 시점의 기록이다 (참고용).

---

## ⚠️ 참고 — 컴퓨터가 2대이고, 클래스바이 도구는 한 대에만 있습니다

| 컴퓨터 | 있는 것 | 할 수 있는 일 |
|---|---|---|
| **윈도우 데스크탑** | `classby-blog` 도구, 크롬, `out` 폴더(카드 PNG) | **네이버 블로그 임시저장** — 여기서만 가능 |
| **맥미니** | (도구 없음) | 저장소 작업, 글감 생성기, 인스타 업로드, 힉스필드 영상 |

> **맥미니에서는 네이버 블로그 저장을 할 수 없습니다.** 도구가 윈도우에 깔려 있고,
> 크롬을 직접 조종하는 방식이라 원격으로도 안 됩니다.
> 맥미니에 도구를 설치하려면 **설치 키가 2대까지 되는지 클래스바이 확인이 먼저**입니다.

### 카드 PNG를 맥미니로 가져오는 법 (인스타 작업용)
윈도우의 `~/.classby-blog-studio/out` 폴더를 **구글 드라이브나 원드라이브로 동기화**해두면
맥미니에서 자동으로 보입니다. 그러면 인스타 업로드를 맥미니가 맡을 수 있습니다.
(수동으로는 USB·카톡·드라이브 업로드도 가능하지만 매번 번거롭습니다)

### 관련 문서 (모두 main 브랜치에 있음)
| 파일 | 내용 |
|---|---|
| `docs/blog_insta_automation_plan.md` | **설계 본문** — 역할 분담, 단계별 계획 |
| `docs/blog_automation_overview.md` | 클래스바이 도구 구조 (39쪽 분석) |

## 1. 상황 한 장 요약

루멘수학(부천 수학학원) 원장님이 **블로그·인스타 자동화**를 하려고 합니다.

- **블로그 도구는 이미 있습니다** — 클래스바이 스튜디오B가 만든 `classby-blog` MCP.
  원장님 컴퓨터에 설치돼 있고 Claude 데스크톱 앱에 등록돼 있습니다.
- **하는 일**: 글쓰기 → 카드 6장 생성 → 크롬을 조종해 네이버 블로그에 **임시저장**까지.
  발행 버튼은 원장님이 직접 누릅니다. 하루 1개 제한, 저장에 8~14분.
- **건드리면 안 되는 것**: 도구는 난독화돼 있고 수정은 라이선스 위반입니다.
  **바깥에서 연결만** 하세요. `~/.classby-blog-studio/profile.json`은 학원 정보·말투 원본이라 지우면 안 됩니다.

---

## 2. 핵심 발견 — 인스타 콘텐츠가 이미 만들어지고 있습니다

블로그 도구가 만드는 카드는 **1080×1350 / 1080×1080**, 정확히 인스타 규격입니다.
`~/.classby-blog-studio/out/<글별 폴더>`에 글마다 6장씩 쌓입니다.
**카드+실사진 무음 슬라이드쇼 영상**도 이미 만들어집니다 (릴스 원본으로 전용 가능).

> 즉 인스타 자동화의 남은 일은 "만들기"가 아니라 **그 폴더의 PNG를 올리는 것**뿐입니다.

---

## 3. 남은 빈칸 3개

1. **인스타 게시** — out 폴더 → 캐러셀 업로드
2. **글감(학원 데이터)** — 학원앱 집계 수치를 블로그 주제·카드에 넣기
3. **실사진 3장** — 도구의 필수 검사 항목. 안 주면 자리만 비어 손으로 끼워야 함

## 4. 할 일 — 어느 컴퓨터에서 하는지가 정해져 있습니다

### 맥미니에서 (도구 없이 가능)
| 순서 | 할 일 | 비고 |
|---|---|---|
| 1 | `sync/blog_topics.js` — 글감 생성기 | Supabase 집계 → `docs/blog_topics_latest.md` |
| 2 | `sync/insta_upload.js` — 인스타 업로드 | 카드 PNG를 드라이브 동기화로 받아온 뒤 |
| 3 | 힉스필드 MCP 연결 | `claude mcp add higgsfield …` (영상 15초) |

### 윈도우 데스크탑에서만
| 순서 | 할 일 | 비고 |
|---|---|---|
| 0 | **카드 6장을 손으로 인스타에 올려 반응 보기** | 설치 불필요. 이것부터 |
| 1 | 블로그 도구를 Claude Code에도 등록 | 아래 명령 |
| 2 | `out` 폴더를 구글 드라이브에 동기화 | 맥미니가 카드를 받게 |

#### 윈도우 등록 명령
`claude mcp add-from-claude-desktop`은 **맥·WSL에서만** 됩니다. 윈도우는 손으로 등록하세요.

```
%APPDATA%\Claude\claude_desktop_config.json 의 mcpServers에서
Classby 블로그 MCP 설정을 읽어 claude mcp add --scope user 로 등록.
이름은 classby-blog (한글·띄어쓰기 들어가면 거부됨)
```
등록 후 `claude mcp list`로 확인. **설치 키(STUDIOB_KEY)는 화면 공유·캡처 금지.**

## 5. 하지 말 것

- ❌ **네이버 자동 발행** — 기계가 쏟아내는 블로그는 저품질 처리됨. 임시저장까지만
- ❌ **클라우드 서버에서 네이버 조종** — 데이터센터 IP 감지 + 캡차 → 계정 위험
- ❌ **학생 이름·개별 점수·얼굴을 콘텐츠에 사용** — 집계·익명 수치만
- ❌ **AI로 학원 내부 사진 생성** — 실사진 자리에 가짜 = 허위 광고.
  힉스필드는 개념 삽화·배경에만
- ❌ **도구 내부 수정·역난독화** — 라이선스 위반
- ❌ **`등록하기.bat`을 Claude 켜둔 채 실행** — 앱이 설정을 덮어씀. 완전히 끄고 할 것

## 6. 알아두면 좋은 함정 (실제로 겪은 것)

- **검색 질문은 글자 하나까지 그대로.** 도구가 주는 `"옥길중 내신 수학는"`은 맞춤법이 틀렸지만
  `"수학은"`으로 고치면 인식이 안 돼 저장이 막힙니다. → 클래스바이에 수정 요청할 항목
- **카드에 넣은 질문은 본문에도 글자로** 있어야 합니다 (카드는 그림이라 검색엔진이 못 읽음)
- **학원법**: 모집 목적 글에는 교습비·등록번호·학원명·교습과목 표시 의무 (과태료 300만원 이하).
  교습비는 등록 금액이 아니라 **학생이 실제 내는 금전 일체**(교재비 포함)
- **말투 자료가 두 군데** — `profile.json`과 `docs/blog_writing_context.md`.
  어긋나면 톤이 흔들리니 한쪽을 원본으로 정할 것
