# 고등부 주간테스트 학습지 만들기 (매쓰플랫)

2026-11-06 원장님 지시로 만든 도구와, 그날 겪은 실수들을 적어 둔다.
다음 시험 때는 **범위만 바꿔서 바로 돌릴 수 있다.**

| 파일 | 역할 |
|---|---|
| `sync/mf_weekly_test.js` | 교과서 학습지 찾기 → 20문항 한 장 만들기 → 학생 배정 |
| `sync/mf_progress_by_unit.js` | 학생이 실제로 어디까지 채점했나 (소단원별) — **범위를 정하는 근거** |
| `sync/weekly_plans/*.json` | 반별 교과서·시험범위·회차 계획 |

## 왜 직접 만들어야 하나

매쓰플랫 「주간TEST」 보관함에는 **초1~중3 것만** 있다(1,500여 회분). 고등부는 한 장도 없다.
그래서 **「내신대비 교과서 학습지」를 재료로** 20문항 한 장을 조립한다.

## 순서

### ① 범위를 «채점 기록»으로 확인한다 — 이걸 건너뛰면 틀린다

```bash
# 그 과목 교과서 학습지 번호 찾기
node sync/mf_weekly_test.js --scan 미적분1 --publisher 비상

# 학생들이 소단원별로 어디까지 채점했나
node sync/mf_progress_by_unit.js \
  --books 67899131,67899132,...,67707308 \
  --codes 1CIMK7,HEQR3U --since 2026-08-01
```

출력은 소단원별 **문항 수 + 마지막 채점일**이다. 읽는 법:

- 문항이 **0개**면 → 아직 안 나간 단원. 범위에서 뺀다.
- 문항이 **1~3개인데 날짜가 두 달 전**이면 → 선행 때 흘러든 것. 역시 뺀다.
- 최근 1~2주 날짜로 수십 문항이면 → 지금 하는 단원.

> ⚠ **교재 「최근 쪽수(recentPageNumber)」로 범위를 잡지 말 것.**
> 2026-11-06 그렇게 잡았다가 두 반 다 틀렸다.
> 소사고는 「속도와 가속도까지」로 잡았는데 한 명은 0문항, 한 명은 8월에 푼 3문항뿐이었다.
> 범박고는 「넓이」를 넣었는데 두 명 다 0문항이었다.

### ② 계획 파일을 쓴다

`sync/weekly_plans/2026-11_고1고2_기말.json` 을 베껴 고치면 된다.

```jsonc
{
  "count": 20,
  "quota": { "4": 2, "3": 9, "2": 7, "1": 2 },   // 상2 / 중9 / 하7 / 최하2
  "design": 46163,                               // 원장님 「주간테스트」 서식
  "groups": [{
    "name": "고2 범박고",
    "grade": "미적분1",
    "books": [67899135, 67899137, ...],          // 재료 교과서 학습지
    "scope": ["방정식과 부등식에의 활용", "속도와 가속도", ...],   // 시험범위 소단원
    "rounds": [
      { "no": 1, "date": "11.06", "name": "방부등식~정적분",
        "units": ["방정식과 부등식에의 활용", "속도와 가속도", "부정적분", "정적분"] },
      { "no": 4, "date": "11.27", "name": "전범위", "units": null,
        "add": [52624019, ...] }                 // 그 회차에만 다른 출판사 섞기
    ]
  }]
}
```

- `scope` / `units` 는 **소단원 이름(littleChapterName)** 을 그대로 쓴다.
  이름은 `--units 67899135,67899137` 로 확인한다.
- `units: null` 이면 그 반 시험범위 전체에서 고르게 뽑는다 (전범위 복습용).
- `add` 는 그 회차에만 재료를 더하는 것. 한 출판사 교과서만으로 중·상 문항이
  모자랄 때 쓴다.
- `keepOut: [학습지번호들]` 을 넣으면 그 학습지에 이미 쓴 문항을 피한다
  (일부만 다시 만들 때).

### ③ 만들고 배정한다

```bash
node sync/mf_weekly_test.js --plan sync/weekly_plans/....json --dry   # 계획만
node sync/mf_weekly_test.js --plan sync/weekly_plans/....json         # 다 만들기
node sync/mf_weekly_test.js --plan sync/weekly_plans/....json --round 2  # 2회차만

node sync/mf_weekly_test.js --assign 85441865 --students I2038512,I2375052
node sync/mf_weekly_test.js --delete 85437086,85437091
```

## 문항을 뽑는 규칙

1. 재료 교과서 학습지의 문항을 **소단원별로** 나눈다 (범위 밖은 버린다)
2. 회차의 소단원들에 20문항을 **고르게** 배분한다 (나머지는 문항이 많은 소단원에)
3. 각 소단원 안에서 **어려운 것부터** 난이도 쿼타를 채운다
4. **한 반의 회차끼리 문항이 겹치지 않는다**

## 알아 둘 것 (실측)

- **문제 출처(교과서) 인쇄**는 `relationWorkbookFlag: true` 와 문항의 `tagTop` 둘 다 있어야
  찍힌다. 플래그를 빼면 `tagTop` 이 있어도 안 나온다.
  찍히는 모양: `교과서 (미적분Ⅰ) - 비상교육, 98p 중단원 학습 점검 13`
- **학습지 제목은 45자까지**. 넘으면 `title size must be between 1 and 45` 로 거절된다.
- **태그만 고치는 API 는 없다.** `PATCH/PUT /worksheet/{id}` 는 `NOT_ALLOW_NULL`.
  태그를 바꾸려면 **다시 만들고 옛것을 지운다**.
- **배정**: `POST /student-worksheet` 에 `{ worksheetIdList, studentIdList }`.
  (`studentIds`·`worksheetId` 같은 다른 이름은 다 `NOT_ALLOW_NULL`)
- **지우기**: `DELETE /worksheet` 에 번호 배열.
- `GET /worksheet/weekly` 는 **매쓰플랫이 만든 보관함만** 보여 준다. 내가 만든 학습지는
  여기 안 나온다 — 번호를 따로 적어 둬야 한다.
- 2022 개정 **공통수학2 는 「도형의 방정식 / 집합과 명제 / 함수와 그래프」 3단원으로 끝**이다.
  경우의 수·행렬은 공통수학1 로 갔다. (매쓰플랫 커리큘럼에도 경우의 수가 없다)

## 2026-11-06 기말 대비 — 만든 것

금요일마다 1~4회. 반마다 4회 80문항이 **모두 다른 문제**다.

| 반 | 교과서 | 시험범위 | 1회 (11.06) | 2회 (11.13) | 3회 (11.20) | 4회 (11.27) |
|---|---|---|---|---|---|---|
| 고1 | 비상 공통수학2 | 명제~무리함수 (99문항) | 명제 | 함수·합성·역함수 | 유리·무리함수 | 전범위(+미래엔) |
| 고2 범박고 | 비상 미적분Ⅰ | 방부등식 활용~속도와 거리 (90문항) | 방부등식~정적분 | 부정적분·정적분 | 넓이·속도와 거리 | 전범위 |
| 고2 소사고 | 미래엔 미적분Ⅰ | 증가와 감소~속도와 거리 (104문항) | 증가와감소~방부등식 | 속도와 가속도·부정적분(+비상) | 정적분 | 넓이·속도와 거리 |

- **고1·범박고는 3회차에 범위를 한 바퀴 돈다.** 4회차는 전범위 복습.
- **소사고는 4회차까지 써야 범위가 끝난다** — 1회차에 미분 활용 3단원을 다 썼기 때문.
- 고1 4회차와 소사고 2회차는 **다른 출판사 교과서를 섞었다**. 한 출판사만으로는
  중·상 문항이 바닥나서 쉬운 문제 모음이 돼 버린다.
