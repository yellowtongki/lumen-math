## 2-1. 📅 주간계획표 (학생앱 v2-112 — 달력)

- 들어가는 곳: 학생앱 **플래너 › 「📅 주간계획표」 탭** (홈 카드는 없음 — 원장 지시). 코디 화면의 「주간 계획 ›」도 이 달력.
- 모양: 월~일 × 아침 7시~밤 12시, 30분 칸. **고정 일정이 먼저 칠해진다** — 학원·운동은 「📌 고정 일정」에서 한 번만 넣고, 루멘 수업은 반 요일로 자동.
- **🏫 학교 시간 (v2-113)**: 학생이 「📌 고정 일정」 맨 위에서 등교 시각 하나 + 월~금 끝나는 시간(30분 단위, 안 가는 날 「없음」)을 **직접** 맞춘다. 같은 시간끼리 묶어 `type:'school'` 덩어리로 저장하고 `schoolSet`을 적는다. 안 맞춘 학생은 달력 위에 「학교 끝나는 시간을 맞춰 주세요」 띠가 뜨고, 학교 칸을 눌러도 열린다.
  - 안 맞췄을 때 기본값(`PW.schoolDef`, 두 앱 공용): 초1·2 09:00~13:00 · 초3·4 09:00~14:00 · 초5·6 09:00~14:30 · 중·고 08:30~15:30
- 원장님 보기 (학원앱 v19-56): 「📅 주간 점수」 표에서 학생 이름(또는 📅) → 같은 모양의 달력 창(보기만). 할 일 수·공부 시간·계획 제출·실천 확인, 주 고르기, ‹ › 다음 학생.
- 빈칸을 누르면 과목·할 일·시작 시각·길이(30분~2시간)를 써서 넣는다. 할 일을 누르면 고치거나 지운다. 지나간 날은 못 고친다. 고정 일정·다른 할 일과 겹치면 안 들어간다.
- **스터디 코디와 하나** (원장 결정: 「달력 하나로 합치기」)
  - 고정 일정 = `codi_fixed_<코드>` 하나 (코디의 「내 고정 시간표」와 같은 것)
  - 코디 대상 학생은 「🧭 코디가 채워 주기」 → 코디가 빈칸에 수학 할 일(교재 다음 몫·학습지·오답·아하노트·다른 과목 목표)을 넣고, 학생이 옮기고·지우고·더한 뒤 「계획 내기」
  - 이번 주 달력은 `codi_plan_<코드>`로 그대로 비친다(`fromWplan: true`) → 학원앱 코디 현황판·플래너 코칭(codiCheck)·코디 화면이 그대로 돈다. 학생이 지운 코디 칸은 「뺐음」으로 남는다
  - 코디 화면에서 짜거나 옮기거나 뺀 것은 달력으로 돌아온다
  - 플래너 분석 때 코디 계획으로 비친 칸은 코디 대조(codiCheck)만 묻고, 주간계획 대조(planCheck)에서는 뺀다(두 번 묻지 않음). 실천은 두 확인을 합쳐 센다

## 2-2. 🏆 월 랭킹 = 매일 점수 + 주간 점수 (학원앱 v19-62 · 학생앱 v2-115 · 원장 결정 2026-09-29 「한 랭킹으로 합치기」)

- 월 랭킹(학생앱 「🏆 이번 달 Top 5」 · 📔 플래너 리그 상금 후보)의 점수 = **그 달 매일 점수 합 + 그 달 주간 점수 합**.
- 주간 점수는 **그 주 일요일이 든 달**에 넣는다 (9/28~10/4 시범 주 → 10월). **발표된 주**(일요일 밤이 지난 주)만 더한다.
- 지각·종이 가져옴으로 주간 점수가 바뀌면 다시 계산한다: 원장님이 플래너를 승인할 때 · 「📅 주간 점수」 판을 열거나 🔄 할 때 · 「📔 가져옴 ✓」을 누를 때.
- 리그의 「최소 제출일」은 그대로 **매일 제출일**로 센다.
- 학생앱 내 점수 카드: 「매일 X + 주간 Y」, 「📅 이번 달 주간 점수」 줄(계획·실천·순공 사진·종이 점수). 학원앱이 `student_planner_<코드>.weekly = { '<월요일>': {t, plan, prac, photo, paper} }` 로 보낸다.

## 3-1. 📅 날짜 필수 · 같은 쪽 다시 내기 = 그날 0점 (원장 결정 2026-09-30 「다진행 그날0점 경고3일」 · 학원앱 v19-66 · 학생앱 v2-117 · 새벽 채점기)

같은 플래너 쪽을 날짜 없이 여러 날 되풀이 제출한 사례(9/15·9/18)가 확인되어 규칙을 더했다.

| 판정 | 뜻 |
|------|-----|
| `noDate` 날짜 없음 | AI 분석에서 플래너 날짜를 못 읽음. 세트 날짜(제출한 날)를 «추정 날짜»로 적어 두고(`dateGuess: true`) 그날 0점 |
| ~~`wrongDate` 날짜가 다름~~ → **v19-68(10/1)에서 폐지** | 적힌 날짜가 제출한 날보다 **앞**이면 `dateFlag:'late'` **지각 제출**(0점 아님 · 적힌 날짜로 들어가고 제출 점수 1점 — 마감 = 플래너 날짜 다음날 새벽 3시, `calcPlannerScoreByPlannerDate`) · **뒤(미래)**면 `dateFlag:'future'` 확인 띠만 |
| `sameDate` 같은 날짜 또 냄 (v19-68) | **거짓 제출.** 먼저 낸 다른 날의 세트(분석 날짜 · 9월 유령 세트는 제출 날)와 플래너 날짜가 같음. 같은 날 다시 올린 것(사진 다시 찍음)은 제외. 그날 0점 + 카드에 먼저 낸 세트 사진 + 위험 신호 ⑧ 「📛 플래너 거짓 제출 N건(30일)」 |
| `dup` 같은 플래너 다시 냄 | 최근 14일 안의 다른 세트와 할 일 글이 80% 이상 같거나(2글자 조각 비교), 사진 지문(dHash 8×8, 거리 ≤ 8)이 같음. 사진 지문 비교는 학원앱에서만, 새벽 채점기는 글 비교만 |

- **기간**: 10/1~10/3은 **경고만**(`zeroWarn`, 점수 그대로 · 카드에 노란 띠). **10/4부터** 0점 판정(날짜 없음·같은 날짜 또 냄·같은 쪽 다시 냄) 중 하나라도 걸리면 **그날 0점**(`zeroDay`, 공부·실천·구체·피드백 네 칸 0 · 제출 점수까지 총점 0). 9/30 이전 세트는 손대지 않는다.
- **손 점수가 우선**: 원장이 손으로 적은 점수(`plManualOf`)가 있으면 그 점수가 그대로 쓰인다.
- **자동 승인 안 함**: 0점·경고 세트는 `_plHasFlag`에 걸려 반드시 원장이 카드에서 본다. 카드에 ⛔ 빨간 띠(까닭 + 같은 세트의 사진 썸네일)와 **「↩ 다른 날 맞음 — 점수 되살리기」** 단추. 누르면 `zeroBak`에 넣어 둔 원점수를 되살리고 `zeroCleared: true`로 다시 0점이 되지 않는다.
- **학생앱**: 학원앱이 `student_planner_<코드>`에 `flags: { '2026.10.06': 'dup' }`를 함께 보내고, 학생앱 「최근 점수 기록」에 「🔁 같은 플래너 다시 냄 → 0점」처럼 까닭이 보인다. 제출 화면 맨 위에 「두 장 모두 맨 위에 오늘 날짜」 안내 띠.
- **위험 신호** ⑦ `plz` 「플래너 0점 N건 — 날짜 없음·같은 쪽」(최근 7일 · 되살린 것은 제외).
- 분석 항목: `zeroReason`('' \| noDate \| wrongDate \| dup), `zeroDup {setId, day, sim, hd}`, `zeroWarn`, `zeroDay`, `zeroBak {s,p,sp,f}`, `zeroCleared`, `imgHash [16진수 16자리 ×2]`, `dateGuess`.
- **9월 소급 (학원앱 v19-67 · 원장 지시 2026-09-30 「9월 플래너 날짜 없는 거 전부 영 점 처리」)**: 플래너 사진검토 도구줄 「📅 9월 날짜 검사 → 0점」. 9/27 사고로 9/23 이전 세트의 분석이 사라져 ① 앱 분석 → ② 새벽 채점 결과(`planner_ai_results`) → ③ 사진을 AI로 날짜만 읽어(원장 기기의 열쇠) 판정한다. **두 장 모두 날짜 없음**이면 그 세트 점수(세트 날짜, 없으면 전날)를 0으로, 세트에 `zeroSept: true` + `zeroBak.total/key`(원점수), 학생 점수표·9월 랭킹 다시 올림. v19-68: 적힌 날짜가 앞이면 「⏰ 지각 제출」, 뒤면 「미래 날짜」(둘 다 목록만). 맨 위에 **「📛 같은 날짜를 다른 날 또 낸 학생」** 목록(날짜·제출 시각·횟수 — 같은 날 다시 올린 것은 제외, 0점 처리는 안 함 · 원장이 확인). 되살리기(`plzClear`)는 원점수까지 되돌린다. 검사 결과는 기기 `lumen_pls9_scan`에 남는다.
- **학생앱 v2-118**: 제출 화면에 지난 날짜(지각) 제출 안내 — 날짜 고르는 칸은 없고 필요 없다(그 쪽을 오늘 찍어 올리면 AI가 적힌 날짜를 읽는다). 「최근 점수 기록」 까닭에 「📛 같은 날짜 또 냄」.
