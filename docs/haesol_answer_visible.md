# 기출 해설집 — 정답 보이기 (학원앱 v19-12)

원장님 지적 (2026-09-17): **「기출 해설지에서 학원앱도 그렇고 정답이 안 보인다」**
(인쇄 미리보기 화면 제보 — 옥길중 중1 2024 2학기 중간 해설집, 표지에 문항 번호만 있고 정답이 없음)

## 왜 안 보였나

정답 값은 **이미 서버에 다 들어 있었다.** `lumen_haesol_catalog` 의 `items[].qs[].ans` 에
8권 전부 문항별 정답이 채워져 있다(20~22문항 × 8권, 빠진 값 0개). 문제는 **보여 주는 자리**였다.

| 자리 | v19-11까지 | 문제 |
|---|---|---|
| 화면 문항 그리드 | `q.warn?'확인':(q.killer?'킬러':(q.ans\|\|''))` | 킬러·확인 문항은 **정답 자리를 배지가 차지**해 정답이 아예 안 나왔다 |
| 인쇄·미리보기 표지 | 해설집 원본 표지 그대로 | 표지에 **정답표가 없다** (번호 바로가기 칸만 있음) |
| 인쇄·미리보기 본문 | `<div class="result">정답 …</div>` | 각 문항 **해설 맨 끝 줄**에만 있어 훑어볼 수 없다 |

## v19-12에서 한 것

1. **문항 그리드** — 번호(작게) 아래 **정답(19px)**, 그 아래 킬러·확인 표시(9px)를 따로 둔다.
   색: 초록 `#15803d`(보통) · 보라 `#7e22ce`(킬러) · 빨강 `#dc2626`(확인). 서술형은 「서술」 11px.
2. **「📋 정답 한눈에」 표** — `hsAnsTableHtml(it)` 이 카탈로그의 `qs` 로 10열 표를 만들어
   `hsFullHtml()` 에서 **표지와 첫 문항 사이**에 넣는다. 확인 문항이 있으면 「학교 정답표와 꼭 대조」 안내가 함께 뜬다.
3. **문항별 정답 칩** — `hsAnsChipInto(html,q)` 가 각 문항의 **첫 `<div class="sol-title">` 뒤**에
   「정답 ④」 칩을 하나 끼운다(문항당 1개). 8권 전부 `sol-title` 이 문항마다 정확히 하나씩 있어 안전하다.
4. **📄 정답 복사** — `hsCopyAns()` 가 「1. ⑤   2. ④ …」 한 줄로 복사한다(확인 문항은 `(확인)` 표시).

### 원칙
- **해설집 원본 파일·서버 본문은 고치지 않는다.** 앱이 화면에 띄우거나 인쇄 HTML을 만들 때만 끼워 넣는다.
  → 이미 올라와 있는 **8권 전부에 즉시 적용**되고, 나중에 올라올 해설집도 그대로 된다.
- 끼워 넣는 조각은 **전부 인라인 스타일** — 해설집마다 다른 자체 CSS와 섞이지 않는다.
- 한 문항만 볼 때(앱 안 iframe·문항 인쇄)는 **정답표 없이 칩만** 넣는다.
