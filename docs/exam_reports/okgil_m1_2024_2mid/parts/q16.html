평행선 작도 = 각을 그대로 복사하기
6점 · 고난도 작도 · 평행선
그림에서 ㉠~㉥은 직선 \(l\) 밖의 한 점 P를 지나고 직선 \(l\)에 평행한 직선을 작도하는 과정을 나타낸 것이다. 설명 중 옳지 않은 것은?
① \(\overline{\mathrm{AB}}=\overline{\mathrm{PQ}}\)   ② \(\overline{\mathrm{AC}}=\overline{\mathrm{QR}}\)   ③ \(\overline{\mathrm{BC}}=\overline{\mathrm{QR}}\)   ④ \(\angle\mathrm{BAC}=\angle\mathrm{QPR}\)   ⑤ 작도 순서는 ㉠ → ㉡ → ㉣ → ㉢ → ㉤ → ㉥
A 중심 호는 B·C를, P 중심 호는 Q·R을 만든다 — 같은 반지름으로 그린다
0단계 — 왜 이렇게 작도하면 평행선이 되나

평행선을 직접 그릴 방법은 없다. 대신 동위각이 같으면 평행이라는 성질을 거꾸로 이용한다. 즉 직선 \(l\)이 만드는 각 \(\angle\mathrm{BAC}\)를 점 P 자리에 똑같이 복사해 놓는 것이다.

$$\angle\mathrm{BAC}=\angle\mathrm{QPR}\ \Longrightarrow\ (\text{동위각이 같다})\ \Longrightarrow\ l\parallel \overleftrightarrow{\mathrm{PR}}$$
1단계 — 각 복사에서 「같아야 하는 길이」는 무엇인가

각을 복사할 때 쓰는 것은 두 개의 호다. 어떤 길이가 같아지는지 정확히 알아 두자.

구분무엇을 그리나같아지는 길이
첫째 호A 중심, 반지름 \(r\) → B, C가 생김\(\overline{\mathrm{AB}}=\overline{\mathrm{AC}}=r\)
둘째 호P 중심, 같은 반지름 \(r\) → Q, R이 생김\(\overline{\mathrm{PQ}}=\overline{\mathrm{PR}}=r\)
셋째 호Q 중심, 반지름 \(\overline{\mathrm{BC}}\) → R이 정해짐\(\overline{\mathrm{QR}}=\overline{\mathrm{BC}}\)

정리하면 네 길이 \(\overline{\mathrm{AB}},\overline{\mathrm{AC}},\overline{\mathrm{PQ}},\overline{\mathrm{PR}}\)가 모두 \(r\)로 같고, 그와 별개로 \(\overline{\mathrm{BC}}=\overline{\mathrm{QR}}\)이다.

2단계 — 선지 판정
①\(\overline{\mathrm{AB}}=\overline{\mathrm{PQ}}\) — 둘 다 반지름 \(r\) ✓ 옳다
②\(\overline{\mathrm{AC}}=\overline{\mathrm{QR}}\) — \(\overline{\mathrm{AC}}=r\)(반지름)인데 \(\overline{\mathrm{QR}}\)은 호의 현이다. 서로 다른 것 → 옳지 않다
③\(\overline{\mathrm{BC}}=\overline{\mathrm{QR}}\) — 셋째 호가 바로 이걸 옮긴 것 ✓ 옳다
④\(\angle\mathrm{BAC}=\angle\mathrm{QPR}\) — 작도의 목적 자체 ✓ 옳다
⑤순서 ㉠(직선 긋기) → ㉡·㉢(A 중심 호와 교점) → ㉣·㉤(P 중심 호와 교점) → ㉥(평행선) ✓ 옳다
정답② (옳지 않은 것)
②가 왜 틀렸는지 한 번 더

\(\overline{\mathrm{AC}}\)는 A에서 C까지의 반지름이고, \(\overline{\mathrm{QR}}\)은 호 위의 두 점을 잇는 현이다. 이 둘이 같아지려면 \(\angle\mathrm{QPR}=60^\circ\)여야 하는데(정삼각형이 될 때), 그림의 각은 \(60^\circ\)가 아니다.

가장 잦은 실수 ③과 ②를 헷갈리는 것. \(\overline{\mathrm{BC}}\)(현) ↔ \(\overline{\mathrm{QR}}\)(현)이 짝이고, 반지름끼리가 또 다른 짝이다. 「현은 현끼리, 반지름은 반지름끼리」로 기억하자.
