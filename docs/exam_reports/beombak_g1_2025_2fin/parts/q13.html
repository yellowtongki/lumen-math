추론 문제 — A를 가정해 보면 바로 모순
난이도 5 · 4.4점 명제 · 문장에서 추론
수학교과실에 놓아 두었던 스티커 두 장이 사라졌다. 학생 A, B, C, D에게 물어본 결과 다음 사실을 알았다. (가) A가 가져갔다면 C도 가져갔다. (나) 정확히 두 명의 학생이 함께 가져갔다. (다) A가 가져가지 않았다면 B도 가져가지 않았다. (라) D가 가져가지 않았다면 C도 가져가지 않았다. 스티커를 가져간 사람은?
① A, B ② A, C ③ B, C ④ B, D ⑤ C, D
1단계 — 대우로 화살표 정리
(가)A → C
(다)대우: B → A
(라)대우: C → D
2단계 — A가 가져갔다면?

A → C → D로 A, C, D 세 명이 된다. (나) 「정확히 두 명」에 모순. 따라서 A는 아니다.

3단계 — 나머지

A가 아니면 (다)로 B도 아니다. 남은 두 명은 C, D. C → D도 만족한다.

정답C, D \(\Rightarrow\) ⑤
가장 잦은 실수 (다)를 「A가 안 가져갔으면 B가 가져갔다」로 잘못 읽는 것. 문장 그대로 화살표로 옮기고, 대우로 바꿔 「B → A」처럼 쓰면 꼬이지 않는다.
