마름모의 대각선 — 수직이등분 + 각 이등분 두 성질을 한 번씩
4점 마름모의 뜻과 성질
그림과 같이 마름모 ABCD에서 \(\overline{\mathrm{AC}}\)와 \(\overline{\mathrm{DB}}\)의 교점을 O라 하자. \(\overline{\mathrm{AO}}=5\,\mathrm{cm}\), \(\overline{\mathrm{DO}}=3\,\mathrm{cm}\), \(\angle\mathrm{OBC}=59^\circ\), \(\angle\mathrm{OCD}=x^\circ\), 마름모 ABCD의 넓이가 \(y\,\mathrm{cm}^2\)일 때, \(x+y\)의 값은?
마름모의 두 대각선은 서로 수직이등분하고, 각 꼭짓점의 각을 이등분한다
1단계 — \(y\) (넓이) : 대각선이 서로 수직이등분

마름모의 두 대각선은 서로를 수직이등분하므로 O는 두 대각선의 중점이다.

\(\overline{\mathrm{AC}}\)\(=2\times\overline{\mathrm{AO}}=2\times5=10\,\mathrm{cm}\)
\(\overline{\mathrm{BD}}\)\(=2\times\overline{\mathrm{DO}}=2\times3=6\,\mathrm{cm}\)

두 대각선이 수직인 사각형의 넓이는 (대각선)\(\times\)(대각선)\(\div 2\)다.

$$y=\frac12\times10\times6=30$$

공식을 잊었다면 마름모가 직각삼각형 4개로 쪼개진다고 보면 된다. \(4\times\left(\frac12\times5\times3\right)=30\) ✓

2단계 — \(x\) (각) : 대각선이 꼭짓점의 각을 이등분

\(\triangle\mathrm{OBC}\)는 \(\angle\mathrm{BOC}=90^\circ\)인 직각삼각형이므로

$$\angle\mathrm{OCB}=180^\circ-90^\circ-59^\circ=31^\circ$$

마름모의 대각선 \(\overline{\mathrm{AC}}\)는 꼭짓점 C의 각 \(\angle\mathrm{BCD}\)를 이등분한다.

$$x=\angle\mathrm{OCD}=\angle\mathrm{OCB}=31$$

「대각선이 각을 이등분한다」는 마름모(와 정사각형)만의 성질이다. 일반 평행사변형에서는 성립하지 않는다.

3단계 — 더한다
$$x+y=31+30=61$$
정답\(61\ \Rightarrow\) ④
가장 잦은 실수 \(\overline{\mathrm{AO}}=5\), \(\overline{\mathrm{DO}}=3\)을 그대로 넣어 넓이를 \(\frac12\times5\times3=7.5\)나 \(5\times3=15\)로 쓰는 것. 주어진 것은 대각선의 절반이므로 반드시 2배 해서 \(10\)과 \(6\)으로 바꾼 뒤 공식을 쓰자.
