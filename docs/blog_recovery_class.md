# "80점 밑으로 떨어지면, 우리는 압니다" — 루멘수학 리커버리 수업

학원을 오래 다녀도 성적이 안 오르는 아이들에게는 공통점이 있습니다.
**어디가 구멍인지 스스로도 모른다**는 것입니다. 루멘수학은 이 구멍을
감(느낌)이 아니라 데이터로 찾아서, 주말 리커버리 수업으로 메웁니다.

---

## 두 가지 신호로 "누가 보충이 필요한지" 자동으로 찾습니다

매주 보는 주간테스트와, 평소 풀고 있는 교재의 단원별 정답률. 이 두 가지를
같이 봅니다.

- **① 주간테스트 80점 미만** — 최근 시험에서 기준 점수를 못 넘긴 학생
- **② 교재 단원 정답률 60% 미만** — 지금 풀고 있는 교재에서, 특정 단원만
  유독 정답률이 낮게 나오는 학생

둘 중 하나라도 걸리면 리커버리 대상으로 자동으로 올라옵니다. 원장님이
일일이 성적표를 넘겨보며 "이 학생 좀 챙겨야겠다"를 기억해 둘 필요가
없습니다. 시스템이 매주 자동으로 찾아냅니다.

## 핵심은 "왜 틀렸는지"까지 구분한다는 것

여기서 끝나지 않습니다. 시험에서 틀린 문제의 단원을, 그 학생이 최근 풀어온
교재의 같은 단원 정답률과 맞대어 봅니다. 그러면 같은 "오답"이라도
성격이 완전히 다르다는 게 드러납니다.

- 🔴 **진짜 구멍** — 시험도 틀리고, 교재에서도 그 단원 정답률이 낮은 경우.
  → 개념부터 다시 잡아야 합니다.
- 🟡 **실전만 약함** — 교재에서는 그 단원을 잘 풀어왔는데 시험에서만 틀린 경우.
  → 개념은 있는데 실전 응용·시험 감각이 부족한 것 → 유형 문제 위주로 처방합니다.
- ⚪ **예전에 배운 내용** — 지금 교재 범위에는 없는, 예전 단원에서 틀린 경우.
  → 개념 요약 복습으로 가볍게 짚어줍니다.

같은 "오답"을 두고 무작정 다시 풀리는 게 아니라, **원인에 맞는 처방**을
자동으로 만들어 준다는 점이 다른 곳과 다른 부분입니다.

## 학생별 맞춤 학습지 — 종이로 바로 인쇄

리커버리 수업 날, 학생마다 다른 "1인 맞춤 학습지"가 인쇄됩니다.

> 📌 「이차방정식」 ○○교재 p.34~40 재풀이 + 시험 틀린 3문항 다시
> 📌 「일차부등식」 실전 유형 연습 (교재는 82% 통과 — 개념은 OK)

이런 식으로, 어떤 단원을 왜 다시 풀어야 하는지까지 학습지 위에 그대로
찍혀 나옵니다. 선생님도, 학생도 "오늘 뭘 보충해야 하는지" 헷갈릴 일이
없습니다.

## 보충했다고 끝이 아니라, "메워졌는지"까지 추적합니다

리커버리를 한 번 했다고 다가 아닙니다. 보충 이후 그 단원을 다시 풀었을 때
정답률이 기준을 넘었는지 시스템이 계속 지켜봅니다.

- ✅ **메워짐** — 이후 같은 단원에서 정답률이 기준을 넘음
- 🔁 **재보충 필요** — 아직 기준 미만 → 다음 주 리커버리에도 다시 잡힘
- ⏳ **확인 중** — 보충 이후 아직 그 단원을 다시 풀지 않아 데이터 없음

한 번의 보충으로 끝내는 게 아니라, **실제로 나아졌는지 데이터로 확인할
때까지** 관리가 이어집니다.

## 출결과도 자동으로 연결

리커버리 완료 처리를 하면 학생의 출결 기록에도 자동으로 남습니다.
따로 이중 기록할 필요 없이, "이 학생이 이번 달 보충을 몇 번 왔는지"가
출결 통계에 그대로 반영됩니다.

---

## 정리하면

| 구분 | 내용 |
|---|---|
| 자동 선발 | 주간테스트 80점 미만 + 교재 단원 정답률 60% 미만 (기준은 조정 가능) |
| 원인 구분 | 진짜 구멍(개념) vs 실전만 약함(응용) vs 예전 내용(가벼운 복습) |
| 맞춤 처방 | 학생별 1인 학습지 자동 생성 — 어떤 단원을 왜 다시 풀어야 하는지까지 인쇄 |
| 사후 추적 | 보충 후 실제로 정답률이 회복됐는지("메워짐") 계속 확인 |
| 연동 | 완료 처리 시 출결 기록 자동 반영 |

느낌이 아니라 데이터로 구멍을 찾고, 그 구멍의 원인까지 구분해서 처방하고,
메워졌는지 끝까지 확인하는 것 — 이것이 루멘수학이 성적을 관리하는 방식입니다.
