숙제체크 칸 2판 — 색 = 숙제 이행도

원장님 의견(11/5) 「색깔은 숙제 이행도를 볼 수 있게」. 칸 색은 이행도(종합 %)만 말하고, 누가 매긴 값인지는 칸 모양(꽉 채움 / 점선 / 점점선)으로 나눴습니다. 이름·숫자는 예시입니다.

① 생각한 것 · 다섯 가지

1색 = 이행도 4단

100 진초록 · 60~99 연두 · 30~59 주황 · 0~29 빨강. 60 은 지금 학부모앱 「미흡」 기준과 같은 선이라, 주황·빨강 칸 = 학부모앱에서 미흡으로 보이는 칸입니다.

2모양 = 누가 매겼나

선생님 확인 = 색을 꽉 채움. 학생 제출(확인 전) = 흰 바탕 + 같은 색 점선 + 「🙋 제출」. 학생 작성 중 = 흐린 점점선 + 「✎」. 색은 둘 다 이행도라, 학생 말만으로도 미리 「오늘 이 아이 숙제가 어떤지」 보입니다.

3칸 아래 4칸 띠 = 어디서 멈췄나

풀이·채점·오답·아하 네 단계를 작은 막대로. 같은 50% 라도 「풀이만 하고 채점 안 함」인지 「오답에서 멈춤」인지 칸만 봐도 압니다(지금 학원앱 칸에 있는 작은 띠를 키움).

4보라 배지 = 학생이 높게 말함

선생님 확인값이 학생 말보다 30 이상 낮을 때만 모서리 보라 「🙋80」. 같거나 비슷하면 아무것도 안 붙여 화면을 조용하게. 보라는 이행도 색과 겹치지 않는 색이라 따로 눈에 띕니다.

5줄 끝 = 최근 흐름

학생 줄 오른쪽에 최근 4번 수업 평균 이행도 + ↗↘. 최근 3번 중 2번 60 미만이면 「🚑 후보」 — 숙제 미흡 리커버리(시안 따로)와 바로 이어집니다. 반 머리에는 그날 반 평균.
