## 만드는 길 (리커버리 학습지와 같은 부품)
```
① 교과서 쪽 → 문항      GET  /workbook/{3129973|3129972}/page/v2
   문항마다 exampleProblem.id = 문제은행 번호 (연결률 91%)
② 유형 필터            POST /worksheet/filter/concept   {conceptIdList, levelWeight…} → filterId
③ 쌍둥이·유사          POST /derivation/problem/{은행번호} {excludedProblemIds, filterId, bookType:'WORKSHEET'}
                       → pairProblemList(쌍둥이) · similarProblemList(유사)
④ 학습지 생성·배정      POST /worksheet {filterId, problemList:[{id,tagTop:null}…], assignStudentIdList:[…]}
```
- 교과서 번호: 비상 공통수학2 **3129973** · 미래엔 공통수학2 **3129972**
