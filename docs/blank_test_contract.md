# 📝 백지테스트 — 계약서

원장 결정 2026-09-20: **발전안 2차 ②, 「개념 백지 + 틀린 유형 재풀이 둘 다」**.
학원앱 **v19-27** 한 버전에 담는다. 시안은 `https://claude.ai/artifact/FZPcEXX6VodVVNHfMa1GsU` ②번 칸.

## 0. 왜 만드는가

원장님이 다니시는 학원(영어)은 **7단계 분석지**에서 백지테스트를 자동으로 뽑는다.
수학에서 그 자리에 오는 재료는 **이미 루멘에 다 있다**:

- 매쓰플랫에서 매일 들어오는 **문항 단위 정오답**(`mf_answer_records` 5만여 건)
- 새벽 수집기가 미리 세어 둔 **막힌 문제**(`mf_stuck` — ❓모름 · 🔁재오답 · 📉유형 3회째)
- 학생이 올린 **아하노트 질문**(교재·쪽·문항번호가 붙어 있다)
- **유형DB**(`lumen_type_db`)의 단원·개념

지금은 원장님이 이것들을 화면마다 따로 보고 **손으로** 시험지를 만든다.
한 장으로 엮는 일만 AI에게 맡긴다.

## 1. 새로 모으는 자료는 없다

| 무엇 | 어디서 | 쓰는 값 |
|---|---|---|
| 최근 틀린 문항 | `mf_stuck` (새벽 수집) | 학생코드 · 교재 · 쪽 · 문항번호 · 막힌 까닭(모름/재오답/유형3회) |
| 단원·유형 정답률 | `typeach_stu_<코드>` (유형성취도) | 약한 유형 이름·정답률 |
| 아하노트 미해결 | `aha_notes` (앱이 이미 들고 있다) | 교재 · 쪽 · 문항번호 · 질문 |
| 개념 목록 | `lumen_type_db` (유형DB) | 학년·학기의 단원 → 개념·유형 이름 |
| 지금 푸는 교재·쪽 | `mf_swb_<코드>` | 교재명 · 최근 쪽 |

## 2. 만드는 순서

```
학생(또는 반) 고르기
   → 재료 자동 채움 (위 다섯 가지, 원장님이 체크로 뺄 수 있다)
   → ⚡ AI 초안 만들기            ← AI 가 하는 일은 «글로 엮는 것»뿐
   → 원장님이 고친다 (글상자 그대로 편집)
   → 🖨️ 인쇄 · PDF  /  📋 할 일 보드에 카드 올리기
```

**AI는 문제를 새로 만들지 않는다.** 2부는 「교재 101쪽 12번을 다시 풀기」처럼 **가리키기만** 한다
(문제 그림·지문을 싣지 않는다 — §6 시험지 규칙). 1부 개념 백지만 AI가 문장을 쓴다.

## 3. 시험지 구성 (원장 결정 — 둘 다)

| 부 | 무엇 | 몇 개 | 재료 |
|---|---|---|---|
| **1부 개념 백지** | 보지 않고 쓰는 빈칸·서술 | 기본 5개 (3~8 조절) | 유형DB 단원 + 약한 유형 |
| **2부 틀린 유형 다시 풀기** | 교재·쪽·번호만 적고 풀 자리 | 기본 4문항 (2~8 조절) | `mf_stuck` + 아하노트 |
| 3부 (선택, 기본 꺼짐) | 비슷한 새 문제 | 2개 | AI 창작 — 원장님이 켤 때만 |

3부는 **기본으로 꺼 둔다**. AI가 만든 수학 문제는 답이 틀릴 수 있어, 켤 때 그 경고를 띄운다.

## 4. 반 전체로 만들 때

- **1부는 같고 2부는 학생마다 다르다.** 단원은 반에서 고르고, 2부의 문항은 그 학생이 틀린 것으로 채운다.
- 한 번에 최대 12명(AI 호출 12번). 진행 막대와 실패한 학생 다시 하기.

## 5. 저장·연동

- 만든 시험지: `lumen_store` 키 **`blank_tests`** = `{ items:[{id, code, name, title, unit, at, by, parts:{p1:[…], p2:[…], p3:[…]}, note}], upd }`
  (최근 200장만 보관. 학생 이름은 화면에서 등록부로 붙이고 **키에는 코드만** 넣는다)
- 인쇄: 새 창 A4 한 장(`@page size:A4`), 머리에 학생·학년·날짜·루멘수학
- **① 할 일 보드 연동**: 「📋 보드에 카드 올리기」 → `kind:'blank'` 카드가 그 학생의 `todo_<코드>` 에 올라간다
  (학생앱에서 「📷 제출」로 사진을 올린다 — `docs/todo_board_contract.md` §4)

## 6. 손대지 않는 것

- 매쓰플랫 수집기·되돌려쓰기·유형성취도·아하노트 화면과 저장 방식 (읽기만 한다)
- 서버 표 구조 (새 표 없음 — `lumen_store` 키 하나만 더)
- `student_v1.html` · `parent.html`
- **시험지 규칙** — 학습지·교재 문제의 그림과 지문은 백지테스트 어디에도 싣지 않는다. 번호로만 가리킨다.

## 7. 확인 방법

실브라우저로 실제 자료를 띄워
① 학생을 고르면 재료(틀린 유형·아하노트·교재)가 그 학생 실제 기록과 **같은지**,
② AI 초안이 1부·2부로 갈라져 들어오는지(2부 문항이 실제 틀린 문항 번호와 맞는지),
③ 원장님이 고친 글이 그대로 저장되고 다시 열리는지,
④ 인쇄 창에 문제 그림이 하나도 없는지(시험지 규칙),
⑤ 「보드에 카드 올리기」가 `todo_<코드>` 에 `kind:'blank'` 카드를 만드는지,
⑥ 기존 화면(유형성취도·아하노트·할 일 보드)이 그대로인지(회귀).
