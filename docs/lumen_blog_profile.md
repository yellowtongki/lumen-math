## 3. 학원 정체성 — 글에 계속 나와야 하는 것

### 한 줄 정의
> 루멘수학은 문제를 많이 풀리는 곳이 아니라, **학생이 스스로 "아하!" 하는 순간을 만드는** 관리형 수학학원입니다.

### 핵심 시스템 5가지 (글감의 뿌리)

| 이름 | 한 줄 설명 |
|---|---|
| **아하노트** | 틀린 문제를 "왜 틀렸는지"까지 학생이 직접 적는 메타인지 오답노트 |

> 이 이야기는 **사실**이므로 써도 됩니다. 대신 **미담처럼 부풀리지 않습니다.**

## 4. 말투 — 기존 글 2편에서 뽑아낸 규칙

원본: `docs/blog_recovery_class.md`, `docs/blog_parent_app_update.md`
**새 글을 쓸 때 이 규칙을 그대로 따릅니다.**

### 4-1. 글의 뼈대 (기존 2편이 똑같이 쓰는 구조)

```
제목      "학부모가 속으로 하는 말" — 루멘수학 ○○
도입 3~4줄  학부모가 겪는 문제 → 굵은 글씨 한 마디 → 루멘은 이렇게 합니다
---
소제목 1   (문장형 소제목)
소제목 2
소제목 3~5
---
## 정리하면
표 (구분 | 내용)
마무리 2~3줄 — 학원 철학 한 문장으로 닫기
```

### 4-2. 제목 만드는 법
- 형식: **`"따옴표 안의 짧은 말" — 루멘수학 ○○○`**
- 실제 예: `"80점 밑으로 떨어지면, 우리는 압니다" — 루멘수학 리커버리 수업`
- 따옴표 안에는 **학부모가 궁금해하는 말**이나 **학원이 하는 약속**을 넣습니다
- 제목에 **지역 키워드**를 넣을 땐 자연스럽게: `옥길동 수학학원`, `부천 수학학원`

### 4-3. 소제목은 "문장"으로 씁니다 (명사 나열 금지)

| ✅ 이렇게 | ❌ 이렇게 말고 |
|---|---|
| 핵심은 "왜 틀렸는지"까지 구분한다는 것 | 오답 원인 분석 기능 |
| 보충했다고 끝이 아니라, "메워졌는지"까지 추적합니다 | 사후 관리 시스템 |
| 두 가지 신호로 "누가 보충이 필요한지" 자동으로 찾습니다 | 자동 선발 로직 소개 |

### 4-4. 문장 규칙
- **높임말** — `~합니다`, `~입니다`. 반말·음슴체 없음
- **한 문단 2~4줄.** 길면 자릅니다. 스마트폰으로 읽는 글입니다
- **굵은 글씨는 한 문단에 1~2곳만.** 여기저기 굵으면 아무 데도 안 보입니다
- 호칭: 학부모 → **학부모님** / 학생 → **아이들, 우리 아이** / 학원 → **루멘수학은**
- 원장을 "저"라고 1인칭으로 내세우기보다 **"루멘수학은"** 으로 주어를 잡습니다
  (단, 원장 개인 이야기를 하는 글에서는 "저"를 써도 됩니다)

### 4-5. 루멘 특유의 표현 — "A가 아니라 B"

기존 글이 가장 많이 쓰는 무기입니다. **새 글에도 최소 2번은 넣습니다.**

- **감(느낌)이 아니라 데이터로** 찾습니다 ← 루멘의 대표 문장
- 무작정 다시 풀리는 게 **아니라**, 원인에 맞는 처방을
- 한 번의 보충으로 끝내는 게 **아니라**, 실제로 나아졌는지 확인할 때까지
- 결과 내용이 아니라 **성실도**를 확인하실 수 있는 방식

### 4-6. 숫자는 반드시 구체적으로
`80점 미만`, `정답률 60%`, `최근 3주`, `4주간 추이` 처럼 **정확한 수**를 씁니다.
"많은", "대부분", "훨씬" 같은 뭉뚱그린 말은 쓰지 않습니다.
**단, 확인 안 된 숫자는 지어내지 말고 비워둡니다.**

### 4-7. 색 신호 불릿 (루멘 글의 시그니처)
개념을 3단계로 나눌 때 이모지로 색을 줍니다.

```
🔴 진짜 구멍 — 시험도 틀리고 교재에서도 정답률이 낮은 경우
🟡 실전만 약함 — 교재는 잘 푸는데 시험에서만 틀린 경우
⚪ 예전에 배운 내용 — 지금 범위 밖에서 틀린 경우
```
```
✅ 메워짐   🔁 재보충 필요   ⏳ 확인 중
```

### 4-8. 인용 블록으로 "실물"을 보여줍니다
설명만 하지 않고, **실제 화면·학습지에 찍히는 문구**를 그대로 인용합니다.

> 📌 「이차방정식」 ○○교재 p.34~40 재풀이 + 시험 틀린 3문항 다시
> 📌 「일차부등식」 실전 유형 연습 (교재는 82% 통과 — 개념은 OK)

### 4-9. 마무리 문장
마지막은 **학원 철학을 한 문장으로** 닫습니다. 영업 멘트로 끝내지 않습니다.

> 느낌이 아니라 데이터로 구멍을 찾고, 그 구멍의 원인까지 구분해서 처방하고,
> 메워졌는지 끝까지 확인하는 것 — 이것이 루멘수학이 성적을 관리하는 방식입니다.

## 5. 쓰지 않는 말 (AI 티 / 과장 광고)

### 5-1. AI 티가 나서 안 쓰는 표현
- `여러분`, `~하시기 바랍니다`, `~에 대해 알아보겠습니다`
- `놀랍게도`, `바로 그것입니다`, `~라고 할 수 있습니다`
- `첫째, 둘째, 셋째` 나열식 — 루멘은 **소제목으로** 나눕니다
- 모든 문단을 이모지로 시작하기 (이모지는 **색 신호와 표에만**)
- 느낌표 남발 — 한 편에 **0~2개**

### 5-2. 법·윤리상 못 쓰는 말
- `최고`, `1등`, `유일한`, `100%`, `보장`, `반드시 오릅니다` → **과장 광고**
- **특정 학생의 이름·점수·등수·얼굴** → 절대 금지. 집계된 익명 수치만
  (예: "이번 주 가장 많이 틀린 유형 TOP3" ✅ / "○○이가 92점" ❌)
- 다른 학원 깎아내리기
- 확인 안 된 입시 제도·연도 (예: 제도 도입 시점은 확정 전이면 쓰지 않음)
- **AI로 만든 학원 내부 사진** → 실사진 자리에 가짜를 넣으면 허위 광고입니다
