덧붙임 — 손풀이 타일도 다시 볼까요

지금 손풀이 타일은 풀이가 하나도 없는데 2칸을 씁니다. 원장님이 굿노트 PDF를 아직 안 올리셨으니 당분간 「아직 올라온 풀이가 없어요」가 홈에서 가장 큰 자리를 차지합니다.

제안 — 풀이가 있을 때만 2칸, 없으면 1칸으로. 그러면 지금은 조용히 있다가, 첫 학습지를 올리는 날 커지면서 「오늘 18」 배지가 붙어 학생 눈에 확 들어옵니다.

정해 주실 것
  1. 리그 발행 전 안내 — 새 안(열리는 날 + 채점 방식 + 등수 표시 + 상)을 넣을까요? / 지금처럼 한 줄만
  2. 채점 예시 — 위 시안처럼 9점짜리 예시 한 장으로 / 표로만 간단히 / 원장님이 고른 실제 학생 노트로(이름 가림)
  3. 예시 순위표 — 가짜 이름으로 보여 줄까요(「예시입니다」 표시) / 순위표는 안 보여 주고 규칙만 글로
  4. 글씨 크기 — (나) 머리에 「가」 단추(추천) / (가) 손풀이 1칸 / 지금 그대로
  5. 손풀이 타일 — 풀이 있을 때만 2칸(추천) / 지금처럼 항상 2칸
