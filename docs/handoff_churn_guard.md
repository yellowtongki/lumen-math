# 인수인계: 이탈 방지(위험 신호) 시스템 — 학원앱 세션용

> 2026-11-22 루멘이사회 세션 작성. 근거: `board/decisions/2026-11-22-퇴원신호-대응원칙.md`
> 받는 곳: 학원앱 세션 (`docs/handoff.md` → `python3 sync/appbuild/build_app.py v19-NN` 으로 조립)

## 왜 만드나 (실제 사례)
중1 학생 1명이 2026-11-21 밤 휴원 통보. 복기 결과:
- **손 놓은 학생이 아니었다** — 플래너 11/18까지 꾸준, 진도레이스 31일 1,624문항(같은 학년 9명 중 5번째로 많음)
- **문제는 정답률 66%** — 같은 학년 최저(다른 학생 76~81%)
- 그런데 학부모에게 간 말은 "진도가 늦고 **공부량이 적어서** 더 오래 하겠다" → 사실과 다른 진단
- 중간고사는 잘 봤는데(첫 시험 85~89점) **`school_scores`에 기록조차 없었다** (기록된 학생 전체 3명뿐)

→ **원장이 상담·문자 전에 «이 학생의 진짜 상태»를 한 화면에서 보게 하는 것**이 이 기능의 목적이다.

## 만들 것 1 — 🚨 위험 신호 (학원앱 홈 카드 + 전용 화면)
학생마다 아래를 판정해 걸린 학생만 띄운다. 신호마다 **근거 숫자와 기간**을 함께 보여준다(「정답률 66% · 2주」처럼).

| 신호 | 조건 | 데이터 출처 |
|---|---|---|
| 🔴 정답률 저하 | 최근 2주 정답률 **70% 미만** | `race_board`의 `rate`(또는 `ok`/`n`) |
| 🔴 플래너 끊김 | 플래너 제출 **7일 연속 없음** | `student_planner_<code>`의 `scores` 날짜 |
| 🟡 많이 푸는데 많이 틀림 | 푼 문항은 학년 중앙값 이상인데 정답률은 학년 하위 25% | `race_board` 학년별 비교 |
| 🟡 성적 기록 없음 | 최근 시험 성적이 `school_scores`에 없음 | `school_scores` |
| 🟡 주간 점수 0 | 주간계획·순공 **2주 연속 0점** | 플래너 주간 점수 |

**중요**: 🟡 「많이 푸는데 많이 틀림」이 이번 사례의 학생을 잡아내는 신호다. 분량만 보면 우등생으로 보인다.

## 만들 것 2 — 📞 상담 전 브리핑 (한 화면)
학생 이름을 누르면 상담·문자 전에 볼 요약이 뜬다.
- 최근 4주: 플래너 제출일수·평균점수 / 레이스 푼 문항·정답률 / 같은 학년 중 위치(분량 순위·정답률 순위)
- 최근 시험 성적과 직전 대비 변화
- **「이 학생에게 하면 안 되는 말」 자동 문구**: 분량이 학년 중앙값 이상이면 **«공부량이 적다»고 말하지 말 것** 경고를 띄운다. 대신 «양은 충분, 정답률 ○○% → 푸는 방법» 으로 제안
- 마지막 학부모 문자 보낸 날짜

## 만들 것 3 — 🎉 성과 알림 (문자 전 체크)
- 시험 성적 입력 후 **직전 대비 상승 학생**을 자동 표시 → 48시간 안에 축하 문자 대상
- 축하 문자 작성 화면에 규칙 경고: **«다만» 금지 · 점수 깎는 표현 금지 · 같은 주에 추가 시간·비용 요구 금지** (이사회 결정 9~11번)
- 참고: 향상상(직전 시험 대비 최대 상승자) 신설은 아직 **미정 안건**

## 하지 말 것
- 학생·학부모에게 위험 신호를 보여주지 않는다. **원장 전용 화면**이다
- 자동으로 문자를 보내지 않는다. 원장이 보고 판단한다
- 큰 표(`race_board` 전체 등)를 새 조건으로 읽게 되면 **색인 먼저**(`docs/index_speedup.sql`), 대량 갱신은 새벽에만

## 참고 데이터 구조 (확인 완료, 2026-11-22)
- `race_board` = {mid:[...], elem:[...]}, 각 행에 `code gr pts n ok rate days rank tier`
- `student_planner_<code>.scores` = {"2026.11.18": 9, ...}
- `planner_ranking_YYYY-MM.ranking[]` = `code daily weekly total days`
- `school_scores` = {학생id: {...}} — **지금 3명만 기록돼 있다. 입력을 쉽게 만드는 것도 과제**
