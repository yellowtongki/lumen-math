## 3. 수학 시간 (월별)
- 지금 플래너 AI 는 **전체 TOTAL TIME** 과 TASKS 만 읽는다 → 과목별 시간이 없다.
- 1단계(바로): TASKS 중 수학 과제 비율로 그날 시간을 나눠 **«추정»** 으로 표시(미리보기 방식). 과제를 못 읽은 달은 «기록 부족».
- 2단계(정확히): 플래너 채점 지시문에 `subjects:{수학:분, 영어:분, …}` (TIME TABLE 칸 색·글자로) 추가 → `analysis.mathMin`. 학원앱 «AI 일괄 분석»과 새벽 서버 채점 둘 다 같은 지시문(점수 맞춤 원칙). 비용은 응답 글자 몇 줄 늘어나는 정도.
  - 대안: 학생앱 플래너 제출 때 «오늘 수학 몇 분» 한 칸을 받는다(AI 없이 정확, 학생 손이 한 번 더 감).

## 4. 의견 문장 만드는 규칙 (AI 없이)
- 현행 주간테스트 최근 2회 평균 ≥ 학원 평균 → «현행은 안정적» / 아니면 «현행도 점검 필요»
- 선행·복습 주간테스트가 직전 3회 평균보다 20점 넘게 떨어짐 → 하락 문장 + 반복된 틀린 개념 2~3개
- 교재 월 정답률이 두 달 전보다 15%p 넘게 떨어짐 → 정답률 하락 문장
- 대표 교재 🔴/🟡 (v19-160) → 진도 문장 + 필요 속도
- 숙제 풀이 평균은 50% 이상인데 채점·오답이 40% 미만 → «마무리 단계가 빠진다»
- 아하노트가 직전 두 달 평균의 절반 아래 → «질문이 줄었다»
- 공부 시간이 줄지 않았으면 그렇다고 쓴다(학부모가 가장 먼저 묻는 것)
- (선택) «✨ 문장 다듬기»: 원장 키로 Claude 에 숫자 묶음만 보내 자연스럽게. 학생 이름은 보내지 않는다.

## 5. 화면·저장
- 들어가는 곳: 진도 현황 오른쪽 상세 · 🚨 위험 신호 학생 카드 · 🔔 알림 줄 · 학생관리 학생 상세의 «📋 상담 리포트».
- 기간: 기본 최근 3개월(바꿀 수 있음).
- 내보내기: ① 인쇄/PDF(대면 상담) ② 이미지로 저장(카톡) ③ 학부모앱 발행(진학 나침반과 같은 길 `pub_reports_<코드>`) — 학부모앱은 원장 명령 때만 배포이므로 ③은 학부모앱 새 판이 필요.
- 저장: `lumen_store` `consult_<코드>` = [{ at, from, to, nums(요약 숫자), opinion, plan, sent }] → 다음 상담 때 «지난 계획 대비» 줄(예: 지난번 목표 주 +15쪽 → 실제 +12쪽).
