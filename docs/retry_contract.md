# 🔁 다시 도전 (2차 · 3차) — 계약서

원장 결정 2026-09-18: 시안(`docs/mockup_retry.html`)의 **추천안 그대로** 진행.
**교재와 학습지 둘 다** 적용한다. 채점하는 자리가 같아 한 번 만들면 둘 다 된다.

## 0. 원장님이 고르신 것

| 항목 | 정한 것 |
|---|---|
| 정답 공개 시점 | **2차를 마친 뒤**. 1차에 틀린 문항은 정답을 가리고 「🔁 다시 도전」으로 넘긴다. 「지금 정답 보기」로 건너뛸 수는 있다 |
| 매쓰플랫에 보낼 결과 | **1차 결과**. 2차·3차는 루멘에만 남는다 (매쓰플랫 점수·리포트가 학생 실력을 그대로 나타내게) |
| 몇 차까지 | **3차까지**. 3차에도 틀리면 선생님 확인 목록으로 |
| 3차 시점 | **2차를 마친 날로부터 3일 뒤** |
| 힌트 | **2차에만 한 줄** — 정답이 아니라 **개념 이름**을 짚어 준다 |
| 점수 | 다시 맞히면 **문항당 +1 XP** |

## 1. 저장 — 기존 기록에 「시도」만 덧붙인다

`hw_scores_<학생코드>` 의 항목은 지금 이렇다(교재·학습지 공통, 학습지는 키가 `ws_<swId>_<wpId>`):

```js
{ r:'O|X|?', a:'학생이 쓴 답', at:'시각', self?:true, photo?:'...' }
```

여기에 **`rt` 한 칸만 더한다.**

```js
{ r:'X', a:'변 AD, 변 XY', at:'2026-09-18T…',      // ★ 1차 — 절대 바뀌지 않는다 (이것이 실력)
  rt:[ { n:2, r:'O', a:'변 AD, 변 BC', at:'…' },   // 2차
       { n:3, r:'O', a:'…', at:'…' } ],           // 3차
  seen:'2026-09-18T…' }                            // 「지금 정답 보기」를 누른 시각 (없으면 안 봄)
```

- **`r`·`a`·`at` 은 1차 그대로 둔다.** 기존 화면(정답률·로드맵·아하노트 후보·원장님 훑어보기)이 전부 이 값을 읽고 있으므로 건드리면 숫자가 흔들린다.
- 재도전 결과는 `rt` 에만 쌓는다. **매쓰플랫 되돌려쓰기 대기열(`hw_sync`)에는 넣지 않는다** — 1차 때 이미 보냈다.
- `seen` 이 있으면 그 문항은 정답을 본 것이다 → 다시 도전 대상에서 빼고 「정답 봄」으로 표시한다.

## 2. 학생앱 (v2-91)

### 2-1. 1차 채점 뒤 — 정답을 가린다
- **틀린 문항(`r==='X'`)과 모름(`r==='?'`)**: 정답 상자 자리에
  「🔁 이 문항은 **다시 도전**에서 풀어요 · 정답은 그때 보여 줄게요」 + 작은 **「지금 정답 보기」**.
  「지금 정답 보기」를 누르면 그 문항만 정답을 열고 `seen` 을 남긴다(되돌릴 수 없다고 한 줄 알린다).
- **맞은 문항**: 지금처럼 정답을 바로 보여 준다.
- 쪽(교재)·학습지를 다 채점하면 마무리 카드에
  「🔁 다시 도전할 문항 **n개**」 + 「다시 도전 시작하기」.

### 2-2. 다시 도전 화면 (2차)
- 대상: `rt` 가 없고 `seen` 이 없는 **X·? 문항**만, 번호 순서대로.
- 카드에 담을 것
  - 문항 번호 (**학습지는 「종이 n번 문제를 보세요」 — 문제 그림은 v2-90에서 이미 끊었다**)
  - 「1차에 쓴 답 · **…** → 틀렸어요」 (회색 상자)
  - 새 입력칸 — **1차와 똑같은 입력 방식**(정답 대장이 있으면 O/X 단추·칸별 입력 그대로)
  - 💡 힌트 한 줄 — `problems[].concept`(개념 이름)이 있을 때만.
    「이 문제는 **「평면에서 두 직선의 위치 관계」** 개념이에요」. 없으면 힌트 줄을 숨긴다.
  - 「아직 모르겠어요 · 아하노트에 질문」 (기존 아하노트 흐름으로)
- 제출하면 그 자리에서 채점해 `rt` 에 `{n:2, …}` 를 넣는다. **틀려도 정답을 바로 열지 않는다** — 2차를 다 마친 뒤 연다.

### 2-3. 2차를 마쳤을 때
- 「1차 72 → 2차 91」 **막대 두 줄**과 「26개 중 21개를 다시 맞혔어요」.
- 못 맞힌 문항: 「3일 뒤 한 번 더 물어볼게요」 + **「지금 정답과 해설 보기」**(여기서는 정답을 연다).
- 「🏅 다시 도전으로 맞힌 n문항 · **+n XP**」.

### 2-4. 3차 (3일 뒤 복습)
- 조건: `rt` 의 마지막이 `n:2` 이고 `r==='X'` 이며, **그 시각으로부터 3일이 지났을 때**.
- 학생앱 홈(또는 채점 화면 맨 위)에 「🔔 3일 전에 못 맞힌 문항 n개 · 3차 도전하기」 카드.
- 3차 결과는 `rt` 에 `{n:3, …}`. 3차에도 틀리면 그대로 두고 원장님 화면에 모인다.

### 2-5. 손대지 말 것
- 채점 엔진 인라인 블록, 1차 채점·저장·되돌려쓰기 경로, 매쓰플랫 전송 규칙.
- `r`·`a`·`at` 값. (재도전이 이 값을 덮어쓰면 실력 기록이 사라진다)

## 6. 2026-10-17 변경 — 주관식은 한 차수 안에서 5번까지 (학생앱 v2-140)

원장 결정: 「정답 시도가 2번이라 못 맞췄다는 학생이 있다 · 주관식은 여러 번도 괜찮다」.

| | 다시 도전(2차·3차) 한 차수에서 낼 수 있는 횟수 |
|---|---|
| **주관식** — 숫자·식·분수·낱말을 직접 쓰는 답 | **5번** (`BK_RT_MAX_SUBJ`). 틀리면 바로 「🤔 다시 생각해 보세요 · 남은 기회 n번」, 쓴 답은 칸에 남아 고쳐서 다시 낸다. 개념 힌트는 그대로 |
| **객관식** — 보기 중에서 고르는 문항 | **1번** 그대로 (`BK_RT_MAX_OBJ`). 보기가 5개 이하라 여러 번 주면 찍어서 맞힌다 |
| 스스로 채점(서술형·보기 답·앱이 못 읽은 답) | 지금처럼 다시 도전에서 빠진다(1차에 이미 정답을 봤다). 2차에서 자기채점으로 넘어가면 그 한 번으로 끝 |

- **객관식 판단** (`bkRtIsChoice`): ① 1차 채점과 같은 `bkIsObj` — 정답 대장 `key.kind==='choice'`, 매쓰플랫 `type` `MULTIPLE_CHOICE`/`SINGLE_CHOICE`, `objective:true` ② 채점 엔진 답 모양(`HWGrade.shapeOf`)이 보기 기호 `mark`(ㄱ,ㄷ · ①,③ · (1),(3))·`ox`·`pick`(○표)·`choice`(낱말 고르기)·`op`(연산 기호)이거나 칸이 전부 그런 «누르는 칸» ③ 낱말 칩 4개 가운데 누르는 낱말 문항. 나머지는 주관식.
- **5번째에도 틀리거나 「정답 보기 · 이 문항은 여기까지」를 누르면** 그 문항은 그 차수에서 ✗ 로 끝난다. 「정답 보기」는 그 문항만 정답을 연다(`seen`). 5번을 다 쓴 문항의 정답은 지금처럼 그 차수를 다 마친 뒤 연다. 「모름 ?」도 그 자리에서 끝(`r:'?'`).
- **1차 `r`·`a`·`at` 과 매쓰플랫 되돌려쓰기(`hw_sync`)는 그대로** — 재도전은 몇 번을 내도 `hw_sync` 에 넣지 않는다.
- **XP** 는 다시 맞힌 문항당 +1 한 번 (몇 번째에 맞혔든).

### 6-1. 저장 — `rt` 는 차수마다 «마지막 결과» 한 칸

```js
{ r:'X', a:'5', at:'…',                                   // 1차 — 그대로
  rt:[ { n:2, r:'O', a:'3', at:'…', k:3,                  // k = 이 차수에 낸 횟수 (마지막 포함)
         tries:[ {a:'9', r:'X', at:'…'}, {a:'8', r:'X', at:'…'} ] },   // 앞서 틀린 답
       { n:3, r:'X', a:'…', at:'…', k:1, tries:[], give:true } ],      // give = 「정답 보기」로 끝냄
  rtp:{ n:3, tries:[ {a:'…', r:'X', at:'…'} ] },          // 아직 기회가 남은 «진행 중» 시도 (끝나면 지운다)
  seen:'…' }
```

- `rt` 의 한 칸 모양 `{n, r, a, at}` 은 그대로라 **학원앱 v19-16 이후 읽는 쪽(`wsgTries`, 오늘의 확인 배지)은 바꿀 것이 없다.** `k` 와 `tries` 는 더해진 칸일 뿐이다. 늘 `k === tries.length + 1`.
- 진행 중 시도는 `rt` 가 아니라 **`rtp`** 에 둔다 → 학원앱이 «2차 끝»으로 잘못 읽지 않는다. 앱을 닫았다 열어도 남은 기회가 이어진다(다시 열어서 횟수를 늘릴 수 없다).
- 옛 기록(`k` 없음)은 `k=1` 로 본다.
- 학원앱에서 나중에 「3번 만에 맞힘」을 보여 주려면 `wsgTries(rec).t2.k` 를 읽으면 된다(지금은 바꾸지 않음).
