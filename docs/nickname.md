# 🏷 별명 — 학생앱에 이름 모자이크 대신 별명 (학원앱 v19-72 · 학생앱 v2-122 · 2026-10-01)

**왜**: 학부모 요청 「옥○○은 성이 특정된다」. 재원생 28명 중 성이 1명뿐인 아이가 9명, 가운데 글자만 보여도 17명이 드러난다. 글자를 하나라도 보이면 작은 학원에선 다 안다 → 이름 글자를 아예 내보내지 않고 **별명**을 쓴다.

## 규칙
- 2~8자 · 한글/영문/숫자만 · 실명(성 뺀 이름 포함) × · 금지어 × · 재원생끼리 중복 ×
- 별명이 없으면 학생앱에는 **「○○○」**

## 어디에 쓰이나 (학생앱으로 나가는 이름 전부)
| 발행본 | 필드 | 만드는 곳 |
|---|---|---|
| `planner_ranking_<월>` | `maskedName` | 학원앱 `calcPlannerRankingForMonth` |
| `aha_league_board` · `aha_league_awards` | `name`, `name_masked` | 학원앱 `iblMask`(별명 모드) |
| `league_planner.last` | `who` | 학원앱 `lgPlannerLast` |
| `race_board` rows · `race_awards` | `nm` | 새벽 엔진 `sync/race_engine.js`(nick_<코드> 읽음) · 학원앱 시상 |
| `hall_announce` | `first.masked` | 학원앱 주간테스트 1등 발표 |

학원앱 화면에서는 **「별명 (이름)」**으로 보여 원장님은 구분한다. 리그 설정의 「성+○○」 단추는 「🏷 별명 (기본)」이 됐고 옆에 별명 없는 학생 목록이 뜬다.

## 정하는 곳
- 학원앱: 학생관리 › 편집 › **🏷 학생앱 별명** (기존 「별칭」 칸은 원장님 구분용 그대로 — 실명이 들어가므로 학생앱엔 안 나간다)
- 학생앱: **「나」 탭 › 🏷 내 별명** (별명이 없으면 🔔 알림에 「별명을 정해 주세요」)
- 저장: 서버 `nick_<코드> { nick, at, by }` + 등록부 `st.nick`(학원앱이 비춤). 순위표에는 **선생님이 다음에 발행할 때** 반영된다.

## 2026-10-01 조치
서버에 이미 올라가 있던 「옥○○」·「유OO」식 이름(race_board·hall_announce·aha_league_board·planner_ranking)을 바로 「○○○」으로 지웠다. 별명을 정하고 발행하면 별명으로 바뀐다.
