# 괄호·점 때문에 틀렸다고 나오던 문제 (2026-09-18)

원장님 제보: **「학생앱 채점할 때 괄호랑 점이 없어서 틀렸다고 하는 경우도 있다」**

## 0. 무엇을 확인했나

| 확인한 것 | 결과 |
|---|---|
| **점**(소수점·점 이름) | **멀쩡했다.** `3.5`←`3.5` ◯ · `0.5`←`.5` ◯ · `점 D`←`D` ◯ |
| **괄호** | **여기가 문제였다.** 아래 네 가지가 전부 오답 처리되고 있었다 |

```
정답 "(3, 4)"   학생 "3,4"  → ✗        정답 "(가)"     학생 "가"   → ✗
정답 "(2)"      학생 "2"    → ✗        정답 "(1), (3)" 학생 "1,3"  → ✗
```

게다가 **숫자 자판에 `(` `)` 가 아예 없어서** 학생은 괄호를 칠 방법도 없었다 → 무조건 오답.

## 1. 고친 것 — 채점 엔진 (`sync/hw_grade_engine.js`)

### ① 답을 «통째로 감싼» 괄호는 껍데기로 보고 벗긴다
`stripWrapParen()` 을 새로 만들어 답을 읽기 전에 한 번 벗긴다.
- 짝이 맞고 **처음부터 끝까지 감쌀 때만** 벗긴다 → `2(x+1)` · `f(x)=2x` 의 속 괄호는 그대로 둔다.
- `(` `[` `（` `［` 네 가지 모두 본다.
- **예외**: `(×)` `(○)` 는 괄호까지가 답이다(곱셈 기호·○표 자리) → 벗기지 않는다.
- 수식 글자(`\times`)를 먼저 푼 뒤에 괄호를 본다.

### ② 조각 안의 괄호는 «못 읽었을 때만» 벗긴다
좌표 `(3,6), (-4,-3)` 처럼 **괄호까지가 한 조각의 답**인 것을 지키기 위해,
조각은 먼저 그대로 읽어 보고 **읽히지 않을 때만** 괄호를 벗겨 다시 읽는다.

### ③ 순서쌍은 답 순서를 따진다
답 전체가 괄호에 싸여 있고 칸이 둘 이상이면 **좌표(순서쌍)** 로 보고 순서를 따진다.

```
정답 "(3, 4)" ← 학생 "3,4"  → ◯      정답 "(3, 4)" ← 학생 "4,3"  → ✗  (좌표는 순서가 중요)
정답 "(1), (3)" ← 학생 "3,1" → ◯     (보기 고르기는 조각마다 따로 싸여 있어 지금처럼 순서 무관)
```

### ④ 보기 번호는 숫자로 써도 같은 답
`①` = `1` · `(3)` = `3`. 학생 자판에는 ①②③ 도 괄호도 없어 숫자로 칠 수밖에 없다.

## 2. 고친 것 — 학생앱 자판 (v2-94)

숫자 자판에 한 줄을 더했다: **`(` `)` `·` `°`**
좌표 두 개짜리 답(`(3,6), (-4,-3)`)처럼 **괄호까지가 답**인 문항에서 쓴다.
껍데기 괄호는 엔진이 알아서 벗기므로 학생이 굳이 칠 필요는 없다.
