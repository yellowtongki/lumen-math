## 1. 흐름 — 다섯 단계

```
① 시험 설정      학교 · 학년 · 1/2학기 중간·기말  →  시험 범위 = 표준 단원 체크
② 기출 분석      해설집 있는 해마다  연도 × 표준 단원 × 배점 · 서술형 · 킬러
③ 내 기록 분석   유형 성취도(매쓰플랫 채점)  →  범위 안 단원별 정답률 · 약한 유형
④ 겹치기         예상 실점 = 기출 배점 × 내 오답률  →  위험 단원 순위 · 한 줄 진단
⑤ 문항 + 유사유형  위험 순서대로 기출 문항(해설집 그대로) + 쌍둥이/교재 가리키기  →  인쇄
```

## 3. 저장 — lumen_store 키 하나만 더 쓴다

```js
exam_prep_cfg = {
  map:    { "중2|삼각형의 내심": "삼각형의 성질", … },   // 해설집 단원 → 표준 중단원 (원장 수정분만)
  ranges: { "옥길중학교|중2|2학기 중간": ["삼각형의 성질","사각형의 성질","도형의 닮음"], … },
  upd: "2026-09-23T…"
}
```
- 쓰는 쪽은 학원앱뿐이다. 학생 이름·코드는 넣지 않는다.
- `map`에 없는 단원은 앱이 자동으로 맞춘다(중단원·소단원·유형명과 두 글자 묶음 겹침, 문턱 0.3). 못 맞추면 「기타」.
- `ranges`에 없는 시험은 「그 시험 해설집에 나온 단원 전부」가 범위다.

## 4. 계산 규칙

- **단원 비중** `w[u]` = 해마다 (그 단원 배점 ÷ 그 해 총점 × 100) 의 평균. 배점이 없는 해설집(0점)은 문항 수 비율로 대신한다.
- **내 정답률** = 유형 성취도 최근 4기간(8주) 합. 유형 → `names[cid].m` 으로 중단원에 묶는다. 3문항 미만 유형은 약한 유형 후보에서 뺀다.
- **예상 실점** `loss[u]` = `w[u] × (1 − rate[u])`. 기록이 없는 단원은 범위 전체 평균 정답률로 본다(그리고 「기록 없음」이라고 적는다).
- **예상 점수** = 100 − Σ loss. 근사치라고 인쇄물에도 적는다.
- **문항 고르기**: 점수 = 단원 위험도(loss 비율) 0.6 + 유형 겹침(약한 유형과 dice ≥ 0.16 이면 오답률×믿음) 0.4 + 난도 0.02. **같은 약한 유형은 최대 2문항, 한 단원은 (문항 수 × 위험 비율)+1 까지**. 정렬은 단원 위험 순 → 문항 번호.
- **유사유형**: 그 문항이 맞은 약한 유형 cid(없으면 그 단원 약한 유형 상위 2개)로 `mf_answer_records`에서 학생 기록을 찾아 «교재 · 쪽 · 번호 · O/X» 최대 3개(틀린 것 먼저, 최근 순). 쌍둥이는 같은 학교·학년·연도 시험지가 `twin_done`에 있으면 폴더 이름과 함께 붙인다.

## 5. 인쇄물 (한 학생 한 벌 · 검정 + 붉은 강조)

1부 이 시험은 — 연도 × 단원 배점표 · 서술형 자리 · 한 줄

붉은색: 예상 실점 1위, 정답률 50% 미만 수치, 해설집의 「가장 잦은 실수」.

원장 지시: 「단원 DB가 매쓰플랫에도 수학비서에도 있다. 기출은 수학비서에 많다. 수학비서 기준으로
단원명·분류하고 작업하라. 이미지 넣어도 된다. (매쓰플랫 접속은) 새벽에만. 옥길중부터.
우리 학원이 다루는 학교는 옥길중·범박중·범박고·소사고 — 나중에 늘어난다.」

왜 바꾸나: §3 의 「해설집 단원 이름을 낱말 겹침으로 표준 단원에 맞추기」는 약했다
(옥길중 중1 2학기 중간이 1학기 단원까지 걸쳐 전부 「기타」가 됨 — v19-34 에서 임시로 두 학기를 다 보게 고침).

### 기준 세 겹
| 쪽 | 기준 | 어디서 |
|---|---|---|
| 기출 | **수학비서** 단원 경로 5단계 · 세부유형 · 난이도 · 배점 · 서술형 · 시험 범위(scopes) | `sync/exam_db_collector.js` → `lumen_store ms_exams_<학교>` |
| 학생 | **매쓰플랫 유형(cid)** — 유형 성취도 그대로 | 이미 있음 |
| 다리 | **매쓰플랫이 기출을 인식한 결과** — 원본 학습지 문항별 `conceptId` (twin_done · exam_ws_map) | `--bridge` → `lumen_store ms_exam_bridge` |

이름 맞추기·「단원 설정」 화면은 없앤다. 시험 범위는 수학비서 scopes 를 쓴다.

### 이미지
- 수학비서 문항 이미지는 CDN 서명 쿠키로 내려받아 Supabase Storage **`exam_images`(비공개)** 에 `<시험지id>/<번호>.png` 로 넣는다.
  앱은 인쇄할 때 서명 주소(signed URL)를 만들어 쓴다 — 아무나 열 수 있는 공개 주소는 만들지 않는다.
- 매쓰플랫 원본 학습지가 있는 시험은 문제·정답·풀이 그림 주소(freewheelin CDN)도 다리에 함께 둔다.
- 해설집이 있는 시험은 해설집 풀이를 그대로 쓴다(우선).

### 실행
- `.github/workflows/exam-db.yml` — 일요일 03:30 KST 주 1회 (수학비서 + 매쓰플랫 다리). 손으로 돌릴 때 `mode=collect` 는 수학비서만 접속하므로 낮에도 된다.
- 학교 추가는 워크플로 입력 `schools` 에 수학비서 폴더 이름을 쉼표로 (예 `옥길중,범박고`).

### 앱(v19-35)에서 바뀌는 것
- 📚 기출 분석: `ms_exams_<학교>` 로 연도 × 단원(수학비서 대단원) × 배점, 세부유형 반복, 난이도, 서술형, 시험 범위(scopes).
- 🎯 시험 대비: 기출 문항의 매쓰플랫 유형(다리) ↔ 학생 유형 성취도 — 정확히 같은 번호로 겹친다. 단원 비중은 다리의 유형 → 매쓰플랫 중단원으로 묶는다.
  다리가 없는 시험지는 분석(1부)에는 나오되 「3부 문항」에는 못 들어간다고 화면에 적는다.
