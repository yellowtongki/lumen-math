루멘 학부모앱 · 📑 월간보고서

이렇게 이어집니다

매달 2일 새벽 서버가 매쓰플랫 보고서 만들기(비공개)→원장님 확인·의견→「공개」 한 번→매쓰플랫 학부모앱 + 루멘 학부모앱

루멘 학부모앱에는 학생마다 따로 저장해서 자기 아이 것만 보이게 합니다(서버 보안 2단계와 맞춤). 「공개 취소」를 누르면 두 곳에서 함께 내려갑니다.

정해 주실 것 4가지

  1. ① 「✍ 루멘 데이터로 다시 쓰기」의 재료

    추천우리가 모은 한 달 문항 기록(정답률·틀린 유형) + 숙제 체크 이행도 + 아하노트 질문 수. 원장님 프롬프트(예전 📊 화면에서 쓰시던 것)를 그대로 옮겨 씁니다. AI 비용은 원장님 API 키, 한 명에 몇 원 수준.

  2. ② 루멘 학부모앱 보고서에 «루멘 기록» 칸을 넣을까요?

    추천넣음 — 숙제 이행도·아하노트 질문·플래너 점수 세 줄. 매쓰플랫 보고서에는 없는 우리 학원만의 내용이라 학부모가 차이를 느낍니다.

  3. ③ 루멘 학부모앱 알림

    추천앱을 열면 「📑 10월 보고서가 도착했어요」 카드를 맨 위에 띄움. 문자는 지금처럼 매쓰플랫 문자(고르면)만.

  4. ④ 매쓰플랫 원본 PDF

    추천받을 수 있으면 보고서 맨 아래 「원본 PDF 보기」로 덧붙임. 안 되면 빼고, 루멘 화면만으로 갑니다.
