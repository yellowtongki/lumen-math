④ 아이디어 전체 목록

바로 되는 것 (자료 있음)

  • 기간 자유 설정(이달·지난달·3개월·올해·직접 날짜) — 모든 카드·표·그래프가 같이 바뀜
  • 순이익 = 매출 − 고정비 − 변동비, 손익분기 학생 수, 매출 대비 상금 비율
  • 월 결산표 인쇄·엑셀(세무사 전달용)
  • 청구 누락·이중·금액 오류·파기 재발송·연체 습관 점검
  • 납부 소요일 분포 · 납부일 달력 · 결제수단 비율
  • 학년별·반별 매출 구성, 1인 평균 수강료
필요한 입력: 고정비 6항목, 변동비 2~3항목, 월 목표

자료가 쌓이면 (2~3개월 뒤)

  • 학생 수·매출 추이, 입회·퇴원, 이탈률, 학생 평생 가치
  • 전년 동월 비교, 계절성(방학·시험 기간)
  • 현금흐름 예측(다음 달 예상 순이익, 퇴원·신규 가정 넣기)
  • 수강료·학생 수·비용 시뮬레이션
  • 청구일 실험(25일 vs 1일) 효과 비교

다른 자료와 합치면 (우리만 되는 것)

  • 퇴원 위험: 미납·지각 납부 + 출석 저하 + 아하노트·플래너 끊김이 겹치는 학생
  • 학생 카드에 납부 이력(상담 때 한 화면)
  • 학부모앱 「이달 납부 완료/미납」 한 줄, 결제선생 청구서 링크
  • 영수증 사진 → AI가 비용 항목 자동 입력
  • 매쓰플랫 학습량 대비 수강료(학생당 문제 풀이 원가)
  • 우리 쪽에 납부 이력이 남아 결제선생을 바꿔도 자료가 안 끊김
만드는 순서 제안 ① 고정비·변동비 입력 + 기간 설정 + 순이익·손익분기 카드 + 월별 그래프(학원앱 v19-9) → ② 점검·수납 흐름·학년별 구성 → ③ 학생 경제·세금 준비·시뮬레이션(자료 3개월 뒤). 원장님이 적어 주실 것은 고정비 항목 금액뿐입니다.
