# 🖊 네이버 블로그 임시저장 자동화 — 맥미니에서 쓰는 법

**Claude Code 를 깔지 않아도 됩니다.** 터미널에서 `node` 명령만 쓰면 됩니다.

---

## 준비 (처음 한 번)

```bash
cd ~/lumen-math
git pull
npm install                      # Playwright 포함
npx playwright install chromium
```

## ① 네이버 로그인 (처음 한 번)

```bash
node sync/naver_draft.js --login
```

브라우저 창이 열립니다. **원장님이 직접** 아이디·비밀번호를 넣으세요.
「로그인 상태 유지」를 켜두면 다음부터 안 물어봅니다.

> 🔒 이 프로그램은 **비밀번호를 보지 않습니다.** 로그인 상태(쿠키)만 `sync/_naver_profile/` 에 남고,
> 그 폴더는 저장소에 올라가지 않습니다. 지우면 다시 로그인하면 됩니다.

## ② 글 넣기

```bash
node sync/naver_draft.js blog/2026-10-10-okgil-m1-exam
```

짧게 쓰려면 (같은 뜻):

```bash
npm run blog:naver -- blog/2026-10-10-okgil-m1-exam
```

창이 열리고 제목 → 본문 → 카드 → 해시태그 순으로 들어간 뒤 **임시저장**됩니다.

**발행 버튼은 누르지 않습니다.** 임시저장함에서 확인하고 원장님이 직접 발행하십시오.

### 그 전에 한 번 보고 싶으면

```bash
node sync/naver_draft.js blog/2026-10-10-okgil-m1-exam --dry
```

브라우저를 열지 않고 **무엇을 어떤 순서로 넣을지만** 보여줍니다. 그림 파일이 없는 자리도 알려줍니다.

### 그림이 자꾸 막히면

```bash
node sync/naver_draft.js blog/<폴더> --no-img      # 글자만 넣고 그림은 손으로
```

## 막히면 멈춥니다

화면이 바뀌어 못 찾는 단계가 나오면 **그 자리에서 멈추고** 무엇을 손으로 할지 알려줍니다.
창은 열린 채로 둡니다. 조치하신 뒤 터미널에서 **Enter** 를 치면 이어서 갑니다.

지도와 톡톡 버튼은 **처음부터 손으로** 넣게 되어 있습니다. 자동으로 넣기 어려운 부분입니다.

## ⚠️ 알아두실 것

- **맥미니·학원 컴퓨터에서만** 돌립니다. 클라우드에서 돌리면 데이터센터 IP로 잡혀 캡차가 뜹니다
- **임시저장까지만** 합니다. 자동 발행은 하지 않습니다 (저품질 처리는 되돌릴 수 없습니다)
- 네이버 글쓰기 화면은 **예고 없이 바뀝니다.** 바뀌면 이 프로그램이 멈추고 알려줍니다.
  그때 오류 메시지를 Claude 에게 주시면 고칩니다
- 처음 돌릴 때는 **한가한 시간**에 해보시는 걸 권합니다

## 다시 돌릴 때

중간에 멈춰서 다시 돌리는 경우, 네이버에 **반쯤 쓰다 만 글이 임시저장**되어 있을 수 있습니다.
글쓰기 화면을 열 때 「작성 중인 글이 있습니다」 창이 뜨면 프로그램이 **취소**(새로 쓰기)를 누릅니다.
그래도 지저분하면 네이버 임시저장함에서 반쯤 쓴 글을 먼저 지우고 다시 돌리세요.

## 타자 속도

**기본이 사람 타자 속도입니다** (한 글자 25~70ms). 모니터 한쪽에 띄워 두고 보기 좋은 속도이고,
한 편에 **2분쯤** 걸립니다.

```bash
node sync/naver_draft.js blog/<폴더>            # 기본 — 사람 속도 (약 2분)
node sync/naver_draft.js blog/<폴더> --fast     # 빠르게 (약 1분)
```

**확인된 사실과 추측을 나눠서 말하면 이렇습니다.**

| | |
|---|---|
| ✅ 사실 | 네이버는 **자동 조종 브라우저를 감지**한다. 걸리면 캡차가 뜬다 |
| ✅ 사실 | **저품질**은 실재한다. 다만 주로 **내용**(복붙·중복·과도한 링크)과 **발행 패턴**을 본다 |
| ❓ 확인 안 됨 | 「글쓰기 화면의 타자 속도가 블로그 점수에 반영된다」 — **공식 근거를 찾을 수 없다** |

다른 도구들이 느리게 치는 것은 **근거가 있어서라기보다 조심하는 쪽을 택한 것**으로 보입니다.
확인할 길이 없으니 조심해서 손해 볼 건 없지만, 그것 때문에 10분을 더 쓸 값어치가 있는지는 따로 판단할 일입니다.

> 사람도 글을 쓸 때 **붙여넣기**를 합니다. 한 글자씩만 치지 않습니다.
> 더 중요한 것은 **하루에 몇 편 올리는가**와 **내용이 겹치지 않는가**입니다.

## 돌아가는 동안 다른 일을 해도 되나

**됩니다.** 이 프로그램은 운영체제 키보드를 뺏는 방식이 아니라 **브라우저 안으로 직접** 글자를 보냅니다.
그래서 다른 창에서 일하셔도 글은 제대로 들어갑니다.

다만 두 가지만 지켜주세요.

- 「Google Chrome for Testing」 창을 **닫지 마세요** (최소화도 피하는 게 안전합니다)
- 그 창 **안을 클릭해 커서를 옮기지 마세요** — 글자가 엉뚱한 데 들어갈 수 있습니다
