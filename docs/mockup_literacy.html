학생앱 설계 메모

• 10분 = 지문 1개 + 문항 5개가 기본. 읽기 1분 + 문항당 1.5분 = 8.5분. 남는 시간은 결과 화면 읽기. (지문 2개 3+2 문항은 2차 옵션)
• 문항 순서: 묻는 것 → 어휘 → 조건 → 식 변환 → 검산/바꿔 말하기. 문제를 푸는 순서와 같아서 「읽는 절차」가 몸에 밴다.
• 즉시 채점: 답 내면 바로 ◯/✗. ✗면 사유 A~E 하나 고른 뒤 정답+한 줄 해설. 숙제 4단계(풀이→채점→오답→아하노트)와 같은 리듬.
• 재는 것: 읽기 시간(초) · 문항별 답 시간 · 지문 펼친 횟수 · 사유 · 탭 이탈(이탈하면 그 문항 시간 무효). 전부 객관식·앱 안 계산 → AI 비용 0.
• 서두름 = 읽기 시간이 반 평균의 70% 미만이면서 틀린 문항이 있을 때. 결과 화면에 ⚡ 하나로만 보여주고 잔소리는 안 한다.
• XP: 완료 +10, 5/5 보너스 +5, 연속 출석 🔥. 기존 레벨 체계에 「읽기」 항목 추가.
• 어느 지문이 나오나: 그 학생의 학교 교과서 출판사 + 지금 배우는 단원 우선, 없으면 다른 출판사 같은 단원. 약한 유형은 다음 세트에 비중↑.
