# 🧑‍💼 루멘수학 AI 직원 계획 (2026-10-15 원장 질문 → 정리)

원장 질문: 블로그·마케팅·플레이스/당근·기출분석·학원앱·학부모피드백·인스타·세무 직원을 두고 거의 자동으로 돌리고 싶다. 맥미니로 되나, 이번 주말이면 되나.

## 0. 결론 먼저
- 유튜브의 「에이전트 65명 사무실」은 **지침서(md) 여러 개 + 예약 실행 + 슬랙 보고 채널**에 캐릭터 그림을 입힌 것이다. 루멘수학은 그 뼈대가 **이미 절반 이상 있다**(아래 표).
- 컴퓨터는 **맥미니로 충분**하다. AI 계산은 전부 Anthropic 서버에서 하고 맥미니는 명령만 보낸다. 더 좋은 컴퓨터를 사지 않는다.
- 이번 주말: **직원 명단 확정 + 지침서 8개 + 슬랙 보고 채널 + 새 직원 2명 실제 가동**은 된다. **네이버 플레이스·당근·인스타 자동 게시와 세무 신고 자동화는 안 된다**(API 없음·계정 위험·공동인증서).

## 2. 만드는 법 (Max 요금제 기준)
- **직원 1명 = 지침서 1개**: `.claude/agents/<이름>.md`(역할·말투·절대 하지 말 것·보고 형식). 이사회 4명 파일이 본보기.
- **일 시키기 = 명령어**: `.claude/commands/<일>.md` → `/일 인자`.
- **알아서 돌기 = 예약**: 클라우드 Routine(scheduled task, 채팅에서 「매주 월요일 7시에 …」) 또는 GitHub Actions cron(지금 새벽 작업 방식). Routine 은 Max 구독으로 돌고, Actions 의 AI 호출은 **API 키 과금**(월 $100 크레딧, CLAUDE.md 「API 절약」).
- **직원끼리 회의 = 하위 에이전트**: 한 채팅이 이사회처럼 여러 에이전트를 불러 결과를 모은다. 이미 `/board` 가 그것.
- **보고 받는 곳 = 슬랙**: 무료 워크스페이스 1개, 직원별 채널(#아침브리핑 #세무 #블로그 #학부모피드백 #위험신호). 카카오톡은 안 된다. 메일로 받아도 된다.
- **사무실 그림(에이전트 HQ)**: 보기용 대시보드. 필요하면 학원앱에 「직원 현황」 탭 하나로 만든다. 우선순위 낮음.

## 3. 컴퓨터
- 맥미니로 충분. 성능이 아니라 **켜져 있는 시간**이 문제다. 클라우드(Routine·Actions)로 돌리면 꺼져 있어도 된다. 지금 새벽 작업이 그렇다.
- 로컬이 꼭 필요한 일: 네이버(블로그 임시저장·검색 API), 인스타 Graph API, 당근. 이것만 맥미니/윈도우 절전 끄고 돌린다.

## 4. 이번 주말 계획 (토·일 각 3~4시간)
토요일
1. 직원 명단 확정(위 표에서 빼고 더하기) · 보고 채널(슬랙) 만들기
2. 지침서 작성: 아침 브리핑 · 세무 비서 · 플레이스/당근 초안 · 인스타 · 마케팅 기획 · 블로그(기존 스킬 연결)
3. **아침 브리핑 비서 가동**(매일 07:00 Routine → 슬랙)
일요일
4. **세무 비서 가동**(매월 1일 08:00 → 전월 매출·경비·미납·세무사 전달 CSV + 부가세(1·7월)·원천세(매월 10일) 알림)
5. 플레이스/당근 초안 직원(매주 월요일 → 소식글 2개 초안)
6. 인스타: 비즈니스 계정 전환 여부 확인만. 업로드 자동화는 다음 주말.
안 하는 것: 네이버·당근 자동 게시(저품질·계정 정지 위험), 홈택스 자동 신고, 사무실 그림.

## 5. 원장이 정할 것

- 당근 비즈프로필·네이버 플레이스 사업자 계정이 이미 있는지
- 인스타 계정이 비즈니스/크리에이터로 전환돼 있는지
