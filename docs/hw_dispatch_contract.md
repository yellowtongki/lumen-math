## 1. 왜 할 일 보드 위에 짓나 (2026-11-02 조사)

- 보드 계약(`docs/todo_board_contract.md`)은 이미 **카드 = 학생에게 배정된 할 것 하나**, 종류 📺 영상·📗 교재 쪽·📄 학습지·📝 백지·💡 재풀이·🚑 보충·✏️ 기타, 상태 `todo<got<doing<done<ok`, 마감 `due`, 자동 제출(매쓰플랫 채점·영상 완주)까지 갖고 있다.
- 서버 실측(11/2): `todo_courses` 비어 있음 · 카드 1,188장 전부 자동(학습지 1,026 · 영상 126 · 보충 35 · 재풀이 1) · 학생앱 쪽은 `stu_features.todo.on=false` 로 잠김. **채울 것이 없어 안 쓰이던 틀**이다.
- 숙제 한 바퀴를 따로 만들면 학생앱에 「오늘 숙제」와 「이번 할 일」 두 목록, 상태 두 벌, 레이스 점수 두 갈래가 생긴다. 보드 위에 지으면 **숙제 분배가 보드를 채우는 첫 번째 재료**가 되고, 영상 숙제(📺 카드)와 같은 줄에 선다.
- 그래서: **숙제 = `hw:true` 인 할 일 카드.** 「오늘 숙제」 = 그 중 마감이 오늘까지인 것. 보드 전체 공개(`stu_features.todo`)와 별개로 「오늘 숙제」 카드는 `stu_features.hw` 로 학년별 켠다.

### 2-1. 카드(`todo_<코드>.items[]`)에 더하는 칸

```
{ …기존 칸(id, kind, title, ref, due, src, tst, tat, auto)…,
  hw: true,                       // 숙제 카드 표시 (학습지는 태그 HOMEWORK 면 자동 true, 「숙제로 넣기/빼기」로 손 고침 hwMan:true)
  n: 38,                          // 문항 수 (교재: 매쓰플랫 쪽별 문항 합 · 학습지: w.n · 프린트: 적은 값 · 모르면 null)
  book, bookId, from, to,         // 교재 카드 (kind 'book') — 보드 (e) 규칙과 같은 이름
  print: true,                    // 종이 프린트 (kind 'etc')
  thw: { p:100, c:100, w:0, a:0 },// 선생님 4단계 확인 (0/100 · a 는 아하노트, 비면 자동 계산값)
  thwAt: ISO                      // 확인 시각
}
```
- 숙제 카드 id: 교재 `hw:<날짜>:<bookId|제목slug>` · 프린트 `hw:p:<시각>` · 학습지는 기존 `a:ws:<wid>` 그대로.
- `src`: 내주기 화면에서 만든 것은 `'hw'`. 학습지는 `'auto:ws'` 그대로.
- 마감 `due`: 교재·프린트는 적은 날짜. 학습지는 **배정일 뒤 첫 수업일**(`lumen_group_days[반]`, 요일 0=일…6=토). 반을 모르면 배정일+3일.

### 2-2. 학생 셀프 체크(`todo_st_<코드>[카드id]`)에 더하는 칸

```
{ st:'doing', at, …기존…,
  hw: { p:100, c:100, w:0, a:0 },  // 풀이·채점·오답·아하노트 0/100
  hat: ISO }
```
- 한 단계라도 100 → `st` 는 최소 `doing`, 네 단계 다 100 → `done`. (보드 점수 규칙 받음1·하는 중2·제출3 은 그대로.)
- **채점(c) 자동 ✓**: 학습지 카드는 `hw_scores_<코드>.items` 에 `ws_<swId>_…` 기록이 있거나 매쓰플랫 상태가 학습완료면 100, 맞은 수는 `mf_wsq` 의 o/x/q 또는 hw_scores 로 보여 준다. 교재 카드는 `hw_scores` 에 그 쪽(`<pid>_<wpId>`, pid∈카드 쪽) 기록이 있으면 100. 자동 ✓ 는 **저장하지 않고 화면에서 셈**(학원앱도 같은 규칙으로 셈).

## 3. 흐름 (1판)

1. **내주기 (학원앱)** — 할 일 보드 탭의 새 칩 「📚 숙제 내주기」 + 학생 상세 머리 단추. 학생 하나 또는 반 전체.
   - 교재: `mf_swb_<코드>` 교재(없으면 `or_books`) 고르기 → 이번 주 7칸(월~일)에 쪽 from~to 적기(문항 수는 매쓰플랫 쪽별 문항 수로 자동, 없으면 빈칸). 「보내기」 → 날짜마다 교재 카드 1장.
   - 프린트: 이름·문항 수·마감 → `etc` 카드 `print:true`.
   - 학습지 칸: 그 학생의 `a:ws:*` 카드 중 최근 30일 — 태그 「숙제」는 ✓ 자동(마감 표시), 다른 태그는 「숙제로 넣기」, 숙제 태그인데 빼고 싶으면 「빼기」(`hwMan`).
   - 「🔄 학습지·교재 목록 새로고침」 = `mf_swb_req` 쪽지(swbreq129 와 같은 창).
   - 저장은 보드 저장 함수(`tdSave…`) 그대로. 같은 id 는 덮어쓴다(고쳐 보내기).
2. **자동 카드 (학원앱 보드 자동 패스 `tdAutoPass` (a))** — 학습지 카드를 만들 때 `w.tag==='HOMEWORK'` 면 `hw:true, n:w.n, due:다음 수업일`. 이미 있는 카드는 `hw` 가 비어 있을 때만 채운다(원장 손 고침 `hwMan` 보호). 채점되면 `auto.done` 은 지금대로.
3. **학생앱 「📌 오늘 숙제」** (`stu_features.hw` 켜진 학년만) — 홈 「📌 오늘 할 일」 바로 아래. `todo_<코드>` 에서 `hw` 카드 중 `due ≤ 오늘` 이고 선생님 확인(`tst==='ok'`)이 안 된 것 (마감 지난 것은 빨간 「n일 지남」). 카드마다 4칸(풀이·채점·오답·아하노트) 토글 → `todo_st_<코드>[id].hw` 저장(학생앱만 쓰는 키). 채점 칸은 §2-2 규칙으로 자동 ✓ 면 눌러도 안 풀림. 학습지 카드는 「📄 학습지 채점으로 가기」 단추. 단계 누를 때 「+5 XP」 글자(실제 XP 는 학원앱이 셈, §5).
4. **학생앱 📅 계획 탭** — 주간계획표 그 주 날짜에 `hw` 카드를 「선생님」 줄로 **읽기만** 그린다(저장 안 함, 코디·학생 줄과 구분).
5. **2차 확인 (학원앱 숙제체크)** — 지금 화면 그대로. 학생·날짜 칸을 열면(또는 반별 묶음 아래) **그날 마감 숙제 카드 줄**: 왼쪽 학생 셀프(초록) · 오른쪽 선생님(파랑 ✓/빨강 ✗) 4칸 + 문항·맞은 수. 「학생 체크 그대로 ✓」(한 명 / 보이는 반 전부) → `thw = 학생 hw`, `tst='ok'`. 손으로 고치면 그 값. 저장 뒤 **거울**(§4).
6. **학부모앱** — 1판 변경 없음. `lumen_hw[날짜]` 거울값을 지금처럼 읽는다(결정 7). 학습지 줄·맞은 수 표시는 다음 판.

## 4. 거울 규칙 — 카드 확인 → `lumen_hw[날짜]`

선생님이 어느 날짜의 숙제 카드를 확인하면 그 날짜의 `lumen_hw[날짜] = {p,c,w}` 를 **그날 마감 숙제 카드들의 `thw` 평균**(0/30/60/100 중 가까운 값으로 반올림)으로 적고 `lumen_hw_at[날짜]` 도 적는다. 아하노트는 지금처럼 자동(`hwcAhaPct`). 반대로 숙제체크 칸을 예전 방식으로 찍으면 카드는 건드리지 않는다(카드가 없는 날도 많다).

## 5. XP

- 학원앱 `calcXP` 를 부품이 감싼다: `todo_st_<코드>` 의 `hw` 단계 100 하나당 **+5**(카드·단계마다 한 번). 선생님 확인 4단계 XP 는 지금 규칙 그대로(거울값으로 들어간다).
- 학생앱은 숫자를 셈하지 않고 `xp_board` 를 읽는다(지금과 같음).

## 7. 손대지 않는 것
- 보드의 상태 다섯 단계·레이스 점수·자동 제출 규칙 · `student_v1.html`·`parent.html`(원장 지시 때만) · 서버 표 구조 · 시험지 규칙(학습지 문제 그림은 어디에도 안 띄움, 카드엔 제목만).

## 8. 검사
- 학원앱: 가짜 서버로 ① 내주기 → `todo_<코드>` 에 날짜별 교재 카드 ② 숙제 태그 학습지 카드에 `hw:true`·마감(다음 수업일) ③ 2차 확인 → `thw`·`tst:'ok'`·`lumen_hw` 거울 ④ calcXP +5 ⑤ 다른 화면 회귀.
- 학생앱: ① `stu_features.hw` 꺼짐이면 카드 없음 ② 오늘 숙제 목록·마감 지남 ③ 토글 → `todo_st_` 에만 저장, `hw_scores` 있으면 채점 자동 ✓ ④ 계획 탭 「선생님」 줄 ⑤ ES5 문법(중첩 템플릿 금지).
- 커밋 전 실명·열쇠 검사. 서버 색인·잠금 변경 없음(새 키 없음).

## 9. 최소판 (2026-11-03 원장 「우선 학생앱에 숙제체크 버튼만 만들고 나머지 기능을 추가」 · 학부모앱 A안 + 학습지 줄)

카드(숙제 내주기)가 없어도 학생이 **「다음 수업 숙제 다 했나」를 날짜 단위로 스스로 누르는** 길. 선생님 숙제체크(`lumen_hw[수업일]`)가 날짜 단위인 것과 같은 눈금이라 분배 기능 없이 바로 쓰고, 2·3판이 붙어도 그대로 이어진다.

### 9-1. 새 키 (학생앱만 쓴다)
```
hw_self_<코드> = { byDate: { 'YYYY-MM-DD': { p:0|100, c:0|100, w:0|100, a:0|100, at:ISO } }, upd:ISO }
```
- 날짜 = **그 숙제를 확인받는 수업일**(다음 수업일). 반 수업 요일표 `lumen_group_days[반]`(0=일…6=토)과 학생의 반(`studentInfo.group`)으로 구한다. 오늘이 수업일이면 오늘. 요일표가 없는 반은 오늘.
