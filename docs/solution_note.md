# 📒 풀이노트 만들기 (문제집 PDF → 루멘 학원노트)

원장님이 문제집 PDF(쎈·개념원리 등)를 주면 **방안지 학원노트**를 만든다. 2026-10-12~13 채팅에서 만든 도구 모음.
**로컬(원장님 컴퓨터)에서 하면 외장하드 PDF 를 크기 제한 없이 바로 읽는다** — 클라우드 채팅은 드라이브 10MB·인터넷 제한이 있다.

## 한눈에

| 하려는 일 | 도구 |
|---|---|
| 문제집 PDF 에서 문항 그림을 잘라 **학원노트(방안지 2열×3줄, 오른쪽 아래 루멘 로고)** 만들기 | `sync/solution_note_build.py` (설계 JSON 으로 조립) |
| 매쓰플랫에서 쪽·문항번호·단계(A/B/C)·정답 목록 받기 (그림은 못 씀) | `sync/mf_workbook_list.js` |
| 남이 만든 풀이노트 PDF 의 **로고를 루멘 로고로 교체** (표지 포함) | `sync/note_logo_swap.py` |
| 큰 PDF 를 구글 드라이브 → 학원 서버로 옮기기 (클라우드 채팅 전용 다리) | `sync/book_fetch.py` + `book-fetch.yml` |

## 준비 (한 번만, 컴퓨터에서)

```
pip install pypdf pypdfium2 pillow reportlab numpy
npm pack pretendard@1.3.9 && tar xzf pretendard-1.3.9.tgz     # 글꼴 → package/dist/public/static/alternative/Pretendard-*.ttf
```
- 글꼴 폴더는 `--font-dir` 로 알려 준다 (또는 `sync/fonts/` 에 `Pretendard-Regular.ttf`·`SemiBold`·`ExtraBold` 를 둔다 — 저장소에는 올리지 않는다).
- 매쓰플랫 목록을 받으려면 환경변수 `MATHFLAT_ID`, `MATHFLAT_PASSWORD` (비밀번호를 파일·저장소에 적지 않는다).
- 로고 전구 그림은 `assets/logo_bulb.png` (저장소에 있음).

## 학원노트 만드는 순서 (Claude 와 함께)

1. 원장님: 「`/Volumes/외장하드/문제집/쎈 중1-2.pdf` 의 다각형 단원 학원노트 만들어줘」
2. Claude: PDF 쪽을 그림으로 바꿔 **직접 보고** 문항 번호별 그림 자리를 정한다 (스캔본은 글자 위치를 못 믿는다).
3. Claude: 설계 JSON 을 쓰고 `python3 sync/solution_note_build.py 설계.json --font-dir 글꼴폴더 --sheet 확인.png`
   - `style: "grid"`(학원노트) / `"mint"`(옛 민트 칸 2×2), `corner: "중1-2"`(오른쪽 위 학년 표시)
   - 칸마다 `{ "title": "0535 대표문제", "pdf_page": 1, "box": [왼,위,오른,아래] }` (box 는 쪽 크기에 대한 비율 0~1). box 없으면 빈칸.
   - A단계(기본 문제)는 문제 글까지 통째로 자르고, B·C단계는 그림만 자른다 (원장 2026-10-13 「A 스텝은 문제집 그대로」).
4. 원장님이 확인(그림 크기·제목 문구) → 단원 전체로 확대.

문항 번호·순서는 `node sync/mf_workbook_list.js --bid 2129121 --pages 87-120` 로 받으면 정확하다
(쎈 중1-2 2022 개정 = 2129121, 중1-1 = 2119121. 다른 교재는 `--find` 로 찾는다).

## 알아둘 점

- **매쓰플랫 그림은 쓰지 않는다**: 시중 문제집 문항도 «숫자를 바꾼 비슷한 문제»를 보여 준다(쎈 0536: 책 125° ↔ 매쓰플랫 140°). 학생이 책과 비교하다 헷갈린다. 그림은 책 PDF 에서 자른다.
- 스캔 배경(회색·뒷장 비침)은 `whiten()` 이 지우고, 옅은 길이 표시(＝, ∥)는 남긴다. 그림 흰 바탕은 투명하게 해서 방안 무늬가 뒤로 보인다.
- **교재 원본 PDF·잘라낸 그림·완성 노트는 저장소에 올리지 않는다** (저작권). `board/`, `blog/` 처럼 git 밖에 둔다.
- 남의 풀이노트([꽉] 꽉찬수학 등)의 로고를 바꿔 학생에게 나눠 줄 때는 그쪽 사용 조건을 먼저 확인한다.
- `note_logo_swap.py` : `python3 sync/note_logo_swap.py 입력.pdf 출력.pdf --font-dir … --covers 1,117`
  (안쪽 쪽은 오른쪽 아래 로고 그림 명령만 지운다. 표지는 쪽 전체가 한 그림이라 로고 자리를 주변 색으로 메우고 위아래로 쌓은 루멘 로고를 얹는다. `--pages 3-8` 로 미리보기만.)
