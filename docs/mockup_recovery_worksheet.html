리커버리 학습지, 「유형 12문항」에서 「내가 틀린 문제의 쌍둥이」로

2026-10-09 · 지금 학원앱의 🧩 학습지 만들기와 원장님이 원하시는 기능을 나란히 놓고, 학원앱 리커버리 안에 들어갈 「학습지 설계」 팝업을 눌러 볼 수 있게 만든 시안입니다. 아직 코드는 없습니다.

지금 vs 추가하고 싶은 것 비교

항목지금 (v18-65 🧩 학습지 만들기)추가 (설계 → 개별 학습지)
재료주간테스트에서 틀린 유형(concept) 목록만 씀. 어느 문제를 틀렸는지는 안 봄틀린 문항 하나하나(이미 서버에 문항별 O/X·유형·난이도가 있음) + 시험 범위 안에서 교재로 푼 문제 중 오답
문제 고르기그 유형들에서 매쓰플랫이 아무 문제 12개(난이도 하·중 반반) 골라 줌오답 문항마다 쌍둥이 1개(같은 유형·같은 난이도, 그 학생이 안 푼 문제). 교재 오답은 「그대로 다시」 또는 「쌍둥이」를 문항별로 고름. 2번 이상 틀린 유형엔 보강 1문항
설계확인 창 한 번 (「12문항 · 하·중 · 녹색 서식, 진행할까요?」). 구성은 못 봄·못 고침학생마다 설계 팝업: 문항 목록 보고 빼거나 쌍둥이 수를 바꾸고, 문항 수·난이도 규칙을 정한 뒤 만들기. 「확정 전원」은 저장한 규칙으로 자동 설계
만들기요청만 저장 → 5분 워커가 매쓰플랫에 생성·배정 (녹색 「주간 리커버리」 서식, 이론 없음)같은 길 그대로. 요청서에 문항 목록이 들어감. 만든 뒤 매쓰플랫 학습지 번호·문항 수를 리커버리 카드에 표시
결과 보기「✅ 생성됨 · 12문항」까지. 어떤 문제가 들어갔는지는 매쓰플랫에 가야 보임카드에서 「무엇으로 만들었나」(시험 오답 n · 교재 오답 m · 보강 k)가 보이고, 학생앱 리커버리 카드에도 같은 요약이 감
대상초·중등 + 시험 오답 유형이 있는 학생같음. 시험 오답이 없어도 교재 오답만으로 설계 가능

서버에 이미 있는 자료로 설계는 바로 됩니다(주간테스트 문항별 O/X·유형·난이도, 교재 문항별 O/X·쪽·번호). 새로 확인해야 하는 건 매쓰플랫 쪽 두 가지뿐이고, 아래 「만드는 순서」에 적었습니다.

0
매쓰플랫 확인 두 가지 (새벽, 시범 학습지 1장)㉠ 문제은행 문제의 「유사 문제」를 번호로 받는 길 — 기출 쌍둥이에 쓰는 유사 필터는 수학비서 문제(myDb)용이라 문제은행 문제에도 되는지 봐야 합니다. 안 되면 「같은 유형·같은 난이도·이 학생이 안 푼 문제」로 뽑습니다(이미 검증된 필터에 excludePrevious+studentIds 만 켜면 됨). ㉡ 「그대로 다시」 — 문제 번호를 지정해 학습지에 넣는 길(필터의 problemList 칸). 둘 다 반나절이면 결론이 납니다.

미리 말씀드릴 것
  • 쌍둥이의 «진짜» 정도는 매쓰플랫이 주는 유사 문제에 달려 있습니다. ㉠이 안 되면 「같은 유형·같은 난이도」까지입니다(지금 12문항보다 훨씬 정확하지만 숫자만 바뀐 문제는 아닐 수 있음).
  • 교재 오답은 매쓰플랫에서 채점한 것만 잡힙니다. 학생앱으로 채점한 것도 매쓰플랫에 되돌려 쓰고 있으니 같이 잡히지만, 종이로만 채점한 건 빠집니다.
  • 시험 범위는 시험지 문항들의 유형 묶음으로 정합니다. 원장님이 범위를 손으로 넓히거나 좁히는 칸을 팝업에 둘 수 있습니다.
원장님께 여쭐 것
  1. 교재 오답의 기본값을 「쌍둥이」로 할까요, 「그대로 다시」로 할까요? (시안은 쌍둥이)
  2. 한 장 최대 문항 수 — 16으로 둘까요? 시험 오답이 많은 학생은 교재 오답을 자동으로 줄입니다.
  3. 「보강(두 번 이상 틀린 유형에 1문항)」을 넣을까요?
  4. 0단계 매쓰플랫 확인은 새벽에 시범 학습지 1장을 만들었다 지우는 방식입니다. 진행해도 될까요?
