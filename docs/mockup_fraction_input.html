지금 모습 v2-131

정답이 1/6인 문제. 「6」「／분수」「1」 순서로 눌러 보세요. 많은 학생이 이렇게 칩니다.

안 A · 보이는 분수 자판 그대로, 칸만 똑똑하게

자판은 지금과 같되 ① 빗금을 누르는 순간 칸이 위아래로 쌓인 분수로 바뀌고 ② 칸 밑에 「6분의 1」처럼 우리말로 읽어 주고 ③ 「대분수」 키로 정수를 앞에 둘 수 있고 ④ 제출 전에 한 번 물어봅니다. 같은 문제를 다시 쳐 보세요.

좋은 점
  • 고칠 곳이 적어 이번 주 안에 배포 가능
  • 「6분의 1」 읽기로 거꾸로 치는 실수가 바로 보임
  • 문자식(x/2)에도 그대로 적용
아쉬운 점
  • 여전히 분자를 먼저 쳐야 한다는 것을 배워야 함
  • 초등 저학년은 「대분수」 키를 찾는 데 시간이 걸릴 수 있음

안 B · 분수 틀 계산기·매쓰플랫 방식

「분수」 키를 누르면 빈 칸 두 개가 위아래로 생기고 위 칸(분자)부터 채웁니다. 「다음 칸」으로 아래(분모)로 내려가고, 「대분수」를 누르면 앞에 정수 칸이 붙습니다. 정답이 2⅕인 문제로 해 보세요.

좋은 점
  • 종이에 쓰는 모양 그대로라 순서를 생각할 필요가 없음
  • 대분수·가분수·음수 모두 한 틀로 해결
아쉬운 점
  • 칸 속 커서 이동까지 새로 만들어야 해서 손이 가장 많이 감(한 주 이상)
  • 식 속 분수(2/3x+1)는 틀 안팎 이동이 번거로움

안 C · 분수 전용 세 칸 정답이 분수인 문항만

앱은 정답 모양을 이미 압니다. 정답이 숫자 분수이면 처음부터 [정수] [분자]/[분모] 세 칸을 그려 두고, 자판에는 빗금 키가 아예 없습니다. 정수 답이면 분자 칸에만 쓰면 됩니다.

좋은 점
  • 초등 분수 단원에 가장 쉬움(칸 모양이 곧 설명)
  • 지금 앱의 「칸 여러 개」 구조를 그대로 써서 손이 적게 감
아쉬운 점
  • 정답이 분수라는 힌트가 새어 나감. 중등 문항에는 알맞지 않음
  • 문자식 분수에는 못 씀 → 안 A가 어차피 필요
