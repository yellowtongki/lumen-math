# 블로그 자동화 도구 — 어떻게 굴러가는가

**루멘수학 / 클래스바이 스튜디오B**
작성일: 2026-09-08 · 확인한 버전: 껍데기 84

이 문서는 개발을 모르셔도 읽을 수 있게 썼습니다.
전부 실제 설치된 파일을 열어서 확인한 내용이고, 추정한 부분은 따로 표시했습니다.

---

## 1. 한 줄로 말하면

> 원장님이 말로 시키면 → 클로드가 글과 카드 내용을 쓰고 → 도구가 카드를 그림으로 찍어 →
> **크롬을 대신 조종해서 네이버 블로그에 사람처럼 타자를 쳐서 임시저장**합니다.
> **발행 버튼은 원장님이 직접 누릅니다.**

로봇이 대신 글을 올리는 게 아니라, **사람이 하던 손동작을 그대로 흉내내는 방식**입니다.
그래서 8~14분이 걸립니다. 빨리 치면 네이버가 기계로 보기 때문입니다.

## 2. 내 컴퓨터 어디에 무엇이 있나

세 군데에 나뉘어 있습니다. **각각 역할이 다르고, 지워도 되는 것과 안 되는 것이 다릅니다.**

### ① 프로그램 — `C:\Users\시그니엘호텔\.classby-blog-mcp`

도구 본체입니다. 클래스바이에서 받은 파일을 설치한 곳입니다.

| 안에 있는 것 | 무엇인가 |
|---|---|
| `node_modules\` | 프로그램 실물 (아래 표 참고) |
| `versions\`, `active.json` | 버전 관리 — 새 버전을 받으면 여기 쌓입니다 |
| `register-mcp.ps1`, `등록하기.bat` | 클로드에 도구를 다시 연결하는 복구 스크립트 |

**이 폴더는 지워도 됩니다.** 다시 설치하면 됩니다. 원장님 프로필·설정은 여기 없습니다.

### ② 데이터 — `C:\Users\시그니엘호텔\.classby-blog-studio`

**여기가 진짜 중요한 폴더입니다. 지우면 안 됩니다.**

| 파일 | 무엇인가 |
|---|---|
| `profile.json` | **학원 정보 전부** — 학원명, 주소, 강점 8가지, 말투 원문, 블로그 아이디, 톡톡 주소 |
| `profile.json.bak` | 위 파일의 백업 (자동) |
| `out\` | 지금까지 만든 글과 카드가 글마다 폴더로 쌓입니다 |
| `serp-watch.jsonl` | 검색 순위 점검 기록 |
| `installed-build.json`, `auto-update.json` | 버전·자동업데이트 상태 |

### ③ 연결 설정 — `%APPDATA%\Claude\claude_desktop_config.json`

클로드에게 "이 도구를 쓰라"고 알려주는 설정 파일입니다. 여기에
**실행할 프로그램 위치**와 **설치 키(STUDIOB_KEY)** 가 들어 있습니다.

> ⚠️ **주의**: 클로드 앱이 켜져 있는 동안 이 파일을 고치면, 앱이 자기 설정을 다시 쓰면서
> 고친 내용을 덮어쓸 수 있습니다. 실제로 한 번 겪었습니다.
> 고쳐야 하면 **클로드를 완전히 끄고** `등록하기.bat` 을 더블클릭하세요.

## 3. 프로그램은 무엇으로 만들어졌나

설치된 프로그램이 남에게서 빌려 쓰는 부품은 **딱 3개**입니다.

| 부품 | 역할 |
|---|---|
| `@modelcontextprotocol/sdk` | 클로드와 대화하는 통로 |
| `playwright-core` | **크롬을 대신 조종하는 리모컨** |
| `zod` | 잘못된 값이 들어오면 걸러내는 검사기 |

**여기서 중요한 사실 하나 —**

> ### 카드는 AI가 그리는 게 아닙니다.
>
> 그림 생성 AI(달리, 미드저니 같은 것)가 **하나도 안 들어 있습니다.**
> 카드는 **웹페이지를 만들어서 그것을 사진 찍듯 캡처**하는 방식입니다.
> 실제로 카드 폴더에 `rendered.html`(캡처 전의 웹페이지)이 그대로 남아 있습니다.

그래서 카드 디자인이 **무한하지 않고 17종으로 정해져** 있고, 글자가 칸에 안 들어가면
**폰트를 줄여서** 맞춥니다("글자가 줄었습니다" 경고가 그것입니다).

### 주요 부품 (참고용)

| 파일 | 하는 일 |
|---|---|
| `naver.mjs` (59KB) | 네이버 블로그 조종 — 로그인, 타자, 지도 넣기, 저장 |
| `carousel-variants.mjs` (76KB) | 카드 디자인 17종 + 어떤 걸 쓸지 점수 계산 |
| `cards.mjs` (39KB) | 카드 한 장을 웹페이지로 만드는 부분 |
| `qa.mjs` (35KB) | 검색 질문(Q&A) 검사 |
| `gate.mjs` (18KB) | **저장 전 최종 검사 — 규격 미달이면 막습니다** |
| `serp-watch.mjs` (52KB) | 검색 순위 점검 |
| `safety.mjs` | 금지 표현 걸러내기 |
| `update.mjs` | 자동 업데이트 |

> 프로그램 코드는 **난독화**(일부러 읽기 어렵게 만듦)되어 있습니다.
> 배포본에 그렇게 적혀 있고, 무단 수정은 라이선스 위반이라고 명시돼 있습니다.

## 4. 글 한 편이 만들어지는 순서

실제로 진행되는 8단계입니다.

### 1단계 — 상태 확인
오늘 몇 개 쓸 수 있는지, 네이버 로그인이 살아 있는지, 프로필이 채워졌는지 봅니다.

### 2단계 — 네이버 로그인 (처음 한 번만)
로그인 창이 뜨고 **원장님이 직접** 아이디·비밀번호를 넣습니다.
**도구도 클로드도 비밀번호를 보지 않습니다.** "로그인 상태 유지"를 켜두면 계속 유지됩니다.

### 3단계 — 프로필 설정 (처음 한 번만)
학원 정보와 **말투**를 저장합니다. 말투는 원장님이 쓰신 글 원문을 그대로 저장해두고,
앞으로 글을 쓸 때 그 문장 리듬을 따라갑니다.

### 4단계 — 주제 고르기
지금이 시험 몇 주 전인지에 따라 주제 10개를 뽑아 보여드립니다.

### 5단계 — 카드 만들기 (한도 안 씀)
클로드가 카드에 들어갈 글을 쓰고, 도구가 **디자인 3안(A/B/C)** 을 만들어 보여줍니다.
마음에 안 들면 17종 중 다른 것으로 얼마든지 다시 뽑습니다.

### 6단계 — 미리 검사 (한도 안 씀) ★
실제로 저장하기 **전에** 규격에 맞는지 검사합니다. 여기서 걸리면 저장이 막힙니다.

| 검사 항목 | 기준 |
|---|---|
| 카드 | 제목 배경 1장 + 본문 5장 |
| 실사진 자리 | 3곳 이상 |
| 지도 | 1개 이상 (학원 지도 필수) |
| 해시태그 | 8개 이상 |
| 본문 글자수 | 1,050자 이상 (목표 1,500자) |
| **검색 질문** | **정해진 문구 그대로 2개 이상** |
| **Q&A 카드** | **카드에 있는 질문이 본문에도 글자로 있어야 함** |

> 💡 **실제로 겪은 함정 두 가지**
>
> **하나.** 검색 질문은 **글자 하나까지 똑같아야** 인식됩니다.
> 도구가 주는 문구가 `"옥길중 내신 수학는"`(맞춤법이 틀림)인데,
> 이걸 `"수학은"`으로 고쳐 쓰면 **인식이 안 돼서 저장이 막힙니다.**
>
> **둘.** **카드에 넣은 질문은 본문에도 똑같이 있어야** 합니다.
> 카드는 그림이라 검색엔진이 글자를 못 읽기 때문입니다.

### 7단계 — 실제 저장 (여기서 하루 1개 차감)
전용 크롬 창이 열리고 **8~14분** 동안 사람 타자 속도로 입력됩니다.

> 🚫 **이 시간에 그 창을 닫거나 마우스로 건드리면 안 됩니다.**

제목·본문·표지·카드·지도가 전부 확인돼야 저장됩니다.
하나라도 안 들어가면 **아예 저장을 안 합니다** (반쪽짜리 글이 남지 않게).

### 8단계 — 발행 (원장님이 직접)
도구는 **임시저장까지만** 합니다.
원장님이 네이버 임시저장함에서 확인하고 **직접 발행 버튼을 누르십니다.**

| 로그인 | 네이버 계정 (원장님이 직접 입력, 도구는 비밀번호 안 봄) |
| 지도 | 네이버 플레이스 — **"루멘수학교습소"** 로 검색해서 삽입 |

> 블로그에 쓰는 학원 이름은 **"루멘수학"**, 지도 검색에 쓰는 이름은 **"루멘수학교습소"** 로
> 따로 저장돼 있습니다. 플레이스 등록명이 달라서 그렇습니다.

### 왜 발행까지 안 하는가

네이버는 기계가 자동으로 글을 쏟아내는 블로그를 **저품질로 떨어뜨립니다.**
사람이 최종 확인하고 누르는 구조가 블로그를 지키는 방법입니다.

**하루 1개 제한**도 같은 이유입니다. 그리고 이 한도는
**네이버에 임시저장하는 순간에만** 셉니다 — 글을 다시 쓰거나 미리 보는 건 **무제한 무료**입니다.

## 6. 이미지는 어떻게 들어가나

글 하나에 이미지가 **4종류** 들어갑니다. 넣는 방식이 각각 다릅니다.

### ① 제목 배경 (1장)
제목 뒤에 깔리는 배경 그림입니다. 글자는 네이버가 그 위에 얹습니다.

### ② 카드 (5장)
**웹페이지를 만들어 캡처**합니다. AI가 그리는 게 아닙니다.

- 크기: 1080×1350 (세로형) 또는 1080×1080 (정사각)
- 색: 108종 중 선택 (지금은 **진남색·아이보리**로 통일)
- 구조: 17종 중 글 내용에 맞는 것을 점수로 계산해 3개 추천

카드 종류는 정해져 있습니다 — 표지 / 수치 / 비교 / 인용 / 단계 / 질문답변 / 마무리.

> ⚠️ **카드 속 글자와 주소는 클릭이 안 됩니다.** 그림이니까요.
> 그래서 눌리는 연락 버튼은 **본문에 따로** 톡톡 버튼으로 넣습니다.

### ③ 실사진 (3장 이상) — 원장님 사진
글 속에 `[실사진: 설명]` 자리가 만들어집니다.

- **사진을 주시면**: 그 자리에 순서대로 자동으로 들어갑니다
- **안 주시면**: 자리만 표시되고 비어 있습니다 → **네이버 임시저장함에서 직접 끼워넣으시면 됩니다**

### ④ 동영상 (1개, 맨 아래)
**카드와 실사진을 이어붙인 소리 없는 슬라이드쇼**를 자동으로 만들어 글 맨 아래에 넣습니다.
네이버가 동영상 있는 글을 더 잘 노출시키기 때문입니다.
동영상만 실패하면 저장은 그대로 진행되고, 빠졌다고 알려줍니다.

### 그 외 — 지도
`[지도: 루멘수학교습소]` 라고 쓰면 네이버 지도에서 찾아 넣습니다.
이름이 안 맞으면 저장이 막힙니다.

## 7. 알아두면 좋은 것들

### 업데이트
- 백그라운드에서 **자동으로** 새 버전을 받습니다
- 받는 도중에 클로드를 꺼도 괜찮습니다 (지금 버전이 그대로 작동)
- 다 받은 뒤 **클로드를 완전히 껐다 켜야** 새 버전이 적용됩니다
- ⚠️ **새 대화만 여는 건 안 됩니다** — 앱 자체를 껐다 켜야 합니다

### 사실 확인은 사람 몫
도구는 **원장님이 말씀하신 것을 사실로 믿습니다.** 실제로 이런 것들이 걸렸습니다:

- "작년에 자격증을 땄다" → 글 날짜와 안 맞음 → **연도를 빼고 저장**
- "IB 서술형 수능 도입" → 확인해보니 **아직 확정 아님**(2027년 3월 확정 예정) → 표현 수정
- "신규생 안 받는다" → 그런데 글은 **모집용으로 짜여 있었음** → 정보글로 전환

> **확인 안 된 숫자는 지어내지 않고 `{{미확정:이름}}` 으로 비워둡니다.**
> 나중에 원장님이 채우시면 됩니다.

### 학원법 (v84부터 알림)
원생 모집 목적의 블로그 글에는 **교습비·등록번호·학원명·교습과목**을 표시해야 합니다.
(학원법 제15조제3항 / 미표시 과태료 300만원 이하)

프로필에 등록번호와 교습비를 한 번 넣어두면 앞으로 글 하단에 자동으로 들어갑니다.

> ⚠️ 여기서 말하는 교습비는 **교육청에 등록한 금액이 아니라
> 학생이 실제로 내는 금전 일체**입니다 (교재비 등 포함).

## 8. 문제가 생기면

| 증상 | 해보실 것 |
|---|---|
| 클로드에서 도구가 안 보임 | 클로드 완전 종료 → `등록하기.bat` 더블클릭 → 다시 실행 |
| 저장이 자꾸 막힘 | 미리 검사에서 뭐가 걸렸는지 클로드에게 물어보세요 |
| 네이버 로그인이 풀림 | "네이버 로그인할게" 라고 말씀하시면 창이 뜹니다 |
| 버전이 낮음 | "업데이트해줘" → 끝나면 앱 껐다 켜기 |
| 프로필이 틀림 | 그 항목만 고쳐달라고 하세요 (처음부터 다시 하지 마세요) |

**같은 시도를 반복해도 안 되면** 클래스바이에 상황(껍데기버전 + 오류 문구)을 전하세요.

## 9. 지금까지 확인된 개선 요청거리

클래스바이에 문의하실 때 참고하실 내용입니다.

1. **검색 질문 문구에 맞춤법 오류** — `"옥길중 내신 수학는"` (`수학은`이 맞음).
   고쳐 쓰면 인식이 안 되어, 통과시키려면 틀린 표기를 그대로 써야 합니다.

2. **"대비 박스" 디자인이 순서형 내용을 망칩니다** — 4주 계획을 넣었더니
   1~2주차를 "이렇게 알고 계셨다면"(=잘못된 통념), 3~4주차를 "실제로는 이렇습니다"로
   나눠버려서 뜻이 뒤집혔습니다.

3. **비교 카드에 항목이 2개면 여백이 큽니다** — 카드 위아래가 비어 보입니다.
   항목을 3개 이상 넣으면 해결됩니다.
