# 떨어진 순간부터 메워지는 순간까지 — 루멘수학 리커버리 시스템

"이번 주에 누가 흔들렸는지"를 사람이 성적표를 넘겨보며 찾아내는 학원과,
시스템이 매주 자동으로 찾아내는 학원은 다릅니다. 루멘수학의 리커버리는
후자입니다. 대상을 찾는 것부터 학습지를 인쇄하고, 학부모님께 안내하고,
끝난 뒤 실제로 메워졌는지 확인하는 것까지 — 한 아이가 흔들린 순간부터
다시 채워지는 순간까지 전 과정이 이어집니다.

---

## 1단계 · 자동 선발 — 두 기준 중 하나라도 걸리면

매주, 두 가지 기록을 자동으로 대조합니다.

- **주간테스트 점수** — 기준(기본 80점) 미만
- **교재 단원 정답률** — 최근 3주(또는 원장님이 지정한 기간) 안에, 특정
  단원 정답률이 기준(기본 60%) 미만

**둘 중 하나만 걸려도** 예상 명단에 오릅니다. **둘 다 걸리면** 🔥 1순위로
따로 표시됩니다. 기준 점수·기간은 원장님이 화면에서 직접 조정할 수
있어서, 학원 상황에 맞게 느슨하게도 빡빡하게도 운영할 수 있습니다.

## 2단계 · 원인 진단 — 같은 오답도 다르게 읽습니다

명단에 오른 학생의 시험 오답 단원을, 같은 단원의 교재 정답률과 맞대어
봅니다. 그러면 세 가지로 갈립니다.

| 판정 | 의미 | 처방 |
|---|---|---|
| 🔴 **진짜 구멍** | 시험도, 교재도 그 단원이 약함 | 개념부터 다시 |
| 🟡 **실전만 약함** | 교재는 괜찮은데 시험에서만 흔들림 | 실전 유형 위주 |
| 🔵 **예전 내용** | 지금 범위가 아닌 예전 단원 | 가벼운 개념 복습 |

"오답이니까 무조건 다시 풀리기"가 아니라, 왜 틀렸는지에 따라 처방이
갈라진다는 게 핵심입니다.

## 3단계 · 학생별 맞춤 학습지 — 한 명당 한 장

리커버리 당일, 학생마다 다른 학습지가 인쇄됩니다. 어떤 단원을, 어떤
판정(🔴🟡🔵)으로, 왜 다시 풀어야 하는지가 학습지 위에 그대로 찍혀
나옵니다. 선생님도 학생도 "오늘 뭘 봐야 하지"를 따로 확인할 필요가
없습니다.

## 4단계 · 학부모 안내 — 자동 발송이 아니라, 원장님이 검토 후 보냄

대상자가 확정되면 학부모님께 안내 문자 초안이 만들어집니다. **시스템이
알아서 보내는 게 아니라, 원장님이 내용을 확인·수정한 뒤 직접
복사해서 보내는 방식**입니다. 원할 경우 AI가 학생의 점수·약점 단원을
반영해 초안을 다듬어 주는데, 이때도 원칙은 하나입니다.

> "아이를 탓하지 않고, 함께 다져놓겠다는 어조로."

성적이 안 좋았다는 사실을 전달하는 게 목적이 아니라, 무엇을 어떻게
채워줄지를 전달하는 게 목적이기 때문입니다.

## 5단계 · 학생앱에도 알림 — 원장님이 눌러야만 공개

원장님이 최종 확정 후 버튼을 누르면, 학생앱 홈 화면에 "🚑 이번 주
리커버리" 카드가 뜹니다. 학생 본인도 언제, 어떤 부분을 보충하는지 미리
알고 옵니다. 이 역시 자동 공개가 아니라 원장님의 최종 확인을 거칩니다.

## 6단계 · 완료 처리 → 출결에 자동 반영

수업이 끝나고 "완료 처리"를 누르면, 그 기록이 학생 출결에 자동으로
남습니다. 리커버리 참석 여부를 이중으로 기록할 필요 없이, 출결
캘린더·통계에 그대로 합산됩니다.

## 7단계 · 사후 추적 — 메워졌는지 끝까지 확인

한 번 보충했다고 끝나지 않습니다. 이후 같은 단원을 다시 풀었을 때
정답률이 기준을 넘었는지 시스템이 계속 지켜봅니다.

- ✅ **메워짐** — 기준을 넘음
- 🔁 **재보충 필요** — 아직 기준 미만 → 다음 주 명단에 다시 오름
- ⏳ **확인 중** — 아직 그 단원을 다시 풀지 않아 데이터 없음

## 8단계 · 운영 장부 — 전체 흐름이 기록으로 남습니다

지금까지 몇 회차를 진행했는지, 학생별로 몇 번 불렀는지, 그중 몇 명이
실제로 메워졌는지가 장부로 쌓입니다. "그때그때 처리하고 끝"이 아니라,
누적된 기록으로 리커버리 제도 자체가 잘 작동하고 있는지도 확인할 수
있습니다.

---

## 정리하면

| 단계 | 내용 |
|---|---|
| ① 자동 선발 | 주간테스트 80점 미만 OR 단원 정답률 60% 미만 (둘 다면 🔥1순위) |
| ② 원인 진단 | 🔴 진짜 구멍 · 🟡 실전만 약함 · 🔵 예전 내용 |
| ③ 맞춤 학습지 | 학생별 1장, 판정·단원 근거까지 인쇄 |
| ④ 학부모 안내 | 원장님 검토 후 직접 발송 (자동 발송 아님) — "탓하지 않는" 어조 |
| ⑤ 학생앱 알림 | 원장님 확정 후에만 공개 |
| ⑥ 완료 처리 | 출결 기록에 자동 반영 |
| ⑦ 사후 추적 | 메워짐 / 재보충 필요 / 확인 중 |
| ⑧ 운영 장부 | 회차·학생별 누적·메워짐 비율 기록 |

느낌이 아니라 데이터로 찾고, 원인까지 구분해서 처방하고, 메워졌는지
끝까지 확인하는 것. 그리고 그 모든 순간에 사람(원장님)의 최종 확인이
빠지지 않는 것 — 이것이 루멘수학이 아이 한 명 한 명을 놓치지 않는
방식입니다.
