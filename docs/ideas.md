## 🌱 1. 학생별 개별 진도표 → 주간계획표 숙제 배분

**등록일**: 2026-08-20 · **제안**: 원장님

### 원문
> 학생별 개별 진도표가 필요하다. 하루에 어떤 문제집을 몇 문제씩 풀지 학생 개별앱에
> 캘린더 형식의 주간계획표에 넣어서 숙제 배분하기. 수학뿐만 아니라 다른 숙제도
> 학생이 넣을 수 있게. 주간계획표 작성과 연동 또는 합치고 싶다.

### 한 줄 요약
선생님이 "이 학생은 이번 주에 쎈 82~89쪽, 하루 15문제" 식으로 배분하면
→ 학생앱 주간계획표 달력에 날짜별로 자동으로 꽂히고
→ 학생은 거기에 자기 숙제(영어 단어, 학교 수행평가 등)를 직접 얹는다.

### 지금 앱에 이미 있는 것 (2026-08-20 확인)
| 조각 | 위치 | 상태 |
|------|------|------|

| 플래너 안의 주간계획표 탭 | 학생앱 플래너 화면 `pl2-t2` | 🚧 "주간계획표 준비중" 안내만 뜸 |

즉 **주간계획표가 두 군데에 흩어진 채 미완성**이라, "연동 또는 합치고 싶다"는
원장님 말씀이 정확하다. 이 아이디어는 사실상 *주간계획표를 완성시키는 일*이다.

### 결정이 필요한 것 (개발 전에 원장님 판단)
1. **누가 배분하나?**
   - (A) 선생님이 학원앱에서 배분 → 학생은 보기만 (통제 강함)
   - (B) 선생님은 "이번 주 범위"만 주고 학생이 요일에 나눔 (자기주도 훈련)
   - (C) 선생님이 자동 배분해두고 학생이 옮길 수 있음 ← 아마 이게 현실적
2. **배분 단위**: 문항 수(15문제)? 페이지 수(3쪽)? 둘 다?
3. **비수학 숙제**: 과목 자유입력? 아니면 영어/국어/과학… 고정 목록?
4. **완료 체크**: 학생이 체크만? 플래너 사진 제출과 자동 연결? XP 지급?
5. **밀린 숙제**: 못 한 분량을 다음 날로 자동 이월할지

### 예상 데이터 구조 (초안)
```
lumen_store 키: weekplan_<학생코드>_<주차>   예: weekplan_A3F9K2_2026-W34
{
  goal: "이번 주 각오",
  days: {
    "2026-08-24": [
      { type:"math", book:"쎈 중2-1", from:82, to:85, count:15, done:false, by:"teacher" },
      { type:"etc",  subject:"영어", title:"단어 100개", done:true,  by:"student" }
    ]
  }
}
```
- `by`로 선생님 배분(수정 불가)과 학생 추가(자유 편집)를 구분
- 수학 항목은 `bookprog_<code>`·매쓰플랫 정오답과 연결 여지 있음

### 연결되는 다른 계획
- 매쓰플랫 정오답 자동 연동 → **에빙하우스 복습 스케줄러**가 만드는 "오늘의 복습"도
  결국 이 주간계획표 달력에 꽂혀야 자연스럽다. 두 기능은 같은 달력을 써야 함.
- 학부모앱에 "이번 주 우리 아이 계획/실행률" 노출 가능

### 규모 감
학생앱 한 화면을 제대로 만들고 + 학원앱에 배분 화면을 새로 만드는 작업이라
**작은 수정이 아니라 하나의 프로젝트**. 매쓰플랫 연동이 어느 정도 자리 잡은 뒤
착수하는 편이 좋아 보임 (복습 카드까지 같은 달력에 얹으려면).
