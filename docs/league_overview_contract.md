# 🏆 리그 한눈에 · 아하 채점(폰) · 채점 현황 — 계약서

원장 결정 2026-09-19: **시안(https://claude.ai/artifact/BPQc8bEa1uaB7Ke12nkMTH) 그대로 진행**.

## 0. 왜 만드는가 (원장님 말씀)

| 원장님 지시 | 지금 무엇이 불편한가 |
|---|---|
| 「진도레이스를 포함한 **모든 리그** 한번에 보기 편하게」 | 리그가 **네 곳에 흩어져** 있다. 폰에서는 진도 레이스 하나만 보인다 |
| 「아하노트 **AI 점수 매기기** 편하게」 | 폰에서는 「해결」 단추만 있고 **점수를 못 매긴다**. PC 작업대까지 가야 한다 |
| 「학습지뿐 아니라 **교재 채점도** 확인 가능하게, **학생별로** 편해야」 | 폰은 **학습지별**로만 보인다. 교재는 PC에만 있고, 학생 한 명을 보려면 여러 화면을 오간다 |

## 1. 새로 만드는 것은 **화면뿐**이다

점수 규칙·저장소·집계는 **하나도 새로 만들지 않는다.** 이미 있는 것을 그대로 읽어 모아 보여 줄 뿐이다.

| 리그 | 읽는 곳 | 한 줄의 값 |
|---|---|---|
| 🏁 진도 레이스 | `RACE.board` (`race_board`) | `code · nm · pts · rank · n · rate · days · tier` |
| 💡 아하노트 리그 | `iblBoard()` (아하노트 + 채점 기록에서 그때그때 셈) | `code · name · league · qcnt · rank · tier` |
| 📔 플래너 랭킹 | `students[].lumen_planner[날짜]` | 기간 평균 점수 · 올린 날 수 |
| 📝 주간테스트 | `WK.tests`(type `WEEKLY`) + `_wkSidByName()` | 최근 점수 · 학년별 1등 |

**학생을 잇는 열쇠**는 `lumen_rec_code`다. 주간테스트만 이름→`sid` 로 잇는다(`_wkSidByName`, 동명이인은 제외됨).

## 2. 학원앱 PC — 「🏆 리그 한눈에」 탭 (새로)

`진도·리포트` 그룹, **「진도 레이스」 바로 위**에 새 탭 하나. 기존 「진도 레이스」·「리그」 탭은 **그대로 둔다**(설정·시상은 거기서).

- **위: 네 리그 카드** — 리그마다 이름·기간·D-day·인원·1·2·3위 + **「지금 신경 쓸 것」 한 줄**
  (채점 대기 n건 · 확인 필요 n명 · 발표 안 됨). 카드를 누르면 그 리그 탭으로 간다.
- **아래: 학생 × 리그 순위표** — 한 줄에 학생 한 명, 네 리그의 **등수와 값**.
  - 기본 차례: **네 리그 등수의 합이 작은 순**. 참여하지 않은 리그는 **꼴찌+1** 로 센다.
  - 열 머리를 누르면 그 리그 순서로 다시 세운다.
  - 맨 오른쪽 **「눈여겨볼 것」** — 플래너 미제출 연속 · 정답률 급락 · 채점 끊김 (있을 때만).
  - 학년 칩(전체·중1·중2·고1…)으로 좁힌다. 이름을 누르면 그 학생 한 명의 네 리그 상세.
- 퇴원생은 나오지 않는다.

## 3. 학원앱 폰 — 화면 세 개 + 홈·아래탭 정리

### 3-1. 홈 타일
「진도 레이스」→ **「🏆 리그 한눈에」**, 「학습지 채점」→ **「📗 채점 현황」**(교재+학습지),
「아하노트」→ **「💡 아하노트 채점」**(대기 건수 배지). 나머지 타일은 그대로.
아래 탭: `홈 · 피드백 · 🏆 리그 · 💡 아하 · 📗 채점` (발행·학생은 홈 타일로 간다).

### 3-2. 🏆 리그 한눈에 (`MOB.view='lga'`)
- 위 칩: `한눈에 · 진도 · 아하 · 플래너 · 주간`
- **한눈에**: 네 리그 카드(각 1·2·3위 + 신경 쓸 것) → **한 학생의 모든 리그**(이름 칩으로 학생 고르기,
  네 리그 등수 네 칸 + 이번 주 한 줄 + 눈여겨볼 것) → **오늘 할 일**
- **진도**: 지금 `mobRace()` 그대로 (손대지 않는다)
- **아하·플래너·주간**: 순위표만 간단히 (설정·발행은 PC)

### 3-3. 💡 아하노트 채점 (`MOB.view='ahag'`)
지금의 「아하노트(해결만)」 화면을 **채점 화면으로 바꾼다.** 점수 규칙·저장은 PC 작업대와 **똑같은 함수**를 쓴다.
- 맨 위: **「🤖 AI 초안 전부 만들기 (n건)」**(`ibqBulkDraft`) + 「📷 사진 읽기 n건」 + 진행 막대(확정 n/전체)
- 거르개 칩: `AI 초안 있음 · 사진만 · 확정됨`
- 카드 한 장 = 노트 하나: 학생·출처·사진 → **L·A·M·P·AHA 다섯 칸(0·1·2)** → 보너스 칩 →
  합계(노트 n/10 + 보너스 = 리그 n) → 코치 두 줄 → **「✓ 확정 → 다음」**
- 쓰는 함수: `ibqNote · ibqOf · ibqBlank · ibqSet · ibqSetPath · ibqToggleFlag · ibqApplyBonus ·
  ibqPaperOff/Apply · ibqSaveScores · ibqBulkDraft · ibqDoReadPhoto · ahaResolve`
- **PC 작업대(`wbMain`)는 손대지 않는다.** 폰은 같은 값을 다른 모양으로 보여 줄 뿐이다.

### 3-4. 📗 채점 현황 (`MOB.view='grd'`)
- 갈래 칩: `학생별(기본) · 학습지별 · 교재별`
- 기간 칩: `최근 7일 · 이번 달 · 확인 필요만` · 이름 검색
- **학생별 목록**: 정답률 · ◯✗? · **확인 필요 n**(자기채점) · 반영 대기 n · 다시 도전 2·3차 배지.
  채점이 **끊긴 학생**은 맨 아래에 흐리게 + 「n일째 없음」
- **학생 한 명**: 맨 위 **「확인 필요」**(학생 풀이 사진 ↔ 정답 그림 나란히 → ◯/✗/그대로) →
  **교재별·쪽별** 문항 칩 → **학습지별**(두 점수 비교 + 1·2·3차 막대 + 못 맞힌 번호)
- **학습지별**은 지금 `mobWsg()` 그대로 쓴다.
- 자료: `hwbModel()`(교재+학습지 자기채점) · `wsgModel()`(학습지) — **둘 다 이미 있는 것**
- 고치기 저장 경로도 기존 그대로(`hw_scores` 에 `by:'T'` + `hw_sync` 대기열 → 워커가 5분마다 매쓰플랫 반영)

## 4. 손대지 않는 것

- 점수 규칙·티어·상금·집계 방식
- PC 「진도 레이스」·「리그」·「채점 작업대」·「교재 채점(자기채점 훑어보기)」 화면
- 학생앱·학부모앱, 서버 표 구조
- **시험지 규칙** — 학습지 문제 그림은 어디에도 띄우지 않는다

## 5. 확인 방법

실브라우저로 PC·폰 두 화면을 열어
① 네 리그 카드의 숫자가 각 리그 화면의 숫자와 **같은지**,
② 학생 한 명의 네 리그 등수가 각 순위표의 등수와 **같은지**,
③ 폰 아하 채점에서 확정한 점수가 **PC 작업대에도 그대로** 보이는지,
④ 채점 현황의 ◯✗ 고치기가 기존 경로로 저장되는지,
⑤ 기존 화면이 그대로인지(회귀).
