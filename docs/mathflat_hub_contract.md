# 📊 매쓰플랫 현황 — 한 탭으로 합치기 · 계약서

원장 결정 2026-09-19: **시안(https://claude.ai/artifact/PMKc6ZJtx4M3cBtKvhSD1h) 그대로 진행**.
학원앱 **v19-24** 한 버전에 담는다.

## 0. 왜 합치는가 (원장님 말씀)

> 「교재 상황판과 학습지 채점이 2개 다 매쓰플랫에서 오는 DB인데 분리되어 있다. 통합해서 하는 방향으로 하자.」

같은 곳에서 온 자료가 **네 군데**에 흩어져 있었다.

| 화면 | 있던 자리 | 읽던 것 |
|---|---|---|
| 📗 교재 상황판 (v19-23) | 진도·리포트 | `book_dash` |
| 📄 학습지 채점 | 오늘의 확인 | `WSG` (`mf_wsq_*` · `hw_scores_*`) |
| 📗 교재 채점 (자기채점 훑어보기) | 숙제체크 안 작은 탭 | `HWB` |
| 📗 채점 현황 (폰) | 폰 아래탭 | 위 셋을 이미 한 화면에 |

**폰은 이미 한 화면인데 PC만 흩어져 있었다.**

## 1. 새 탭은 만들지 않는다

**「📗 교재 상황판」 탭의 이름만 「📊 매쓰플랫 현황」으로 바꾸고, 그 안에 칩 네 개**를 둔다.
탭 값(`VIEW='bookdash'`)은 그대로 두어 기존 바로가기가 깨지지 않게 한다.

```
📊 매쓰플랫 현황
  ├ 한눈에   (새로 — 열면 먼저 보이는 화면)
  ├ 📗 교재별  (v19-23 화면 그대로)
  ├ 📄 학습지별 (「학습지 채점」이 통째로 옮겨옴)
  └ 👤 학생별  (새로 — 교재 + 학습지를 학생 하나로)
```

**탭은 하나 줄어든다** — 「오늘의 확인 → 📄 학습지 채점」 탭을 뺀다.
다만 `VIEW='wsgrade'` 로 오는 옛 바로가기는 **매쓰플랫 현황의 「학습지별」로 넘겨** 준다(끊기지 않게).

## 2. 새로 세는 것은 없다

세 모델을 **그대로 읽어 학생코드(`lumen_rec_code`)로 합칠 뿐**이다.

| 무엇 | 어디서 | 쓰는 값 |
|---|---|---|
| 교재 | `BD.data` (`book_dash`) | `books[].{title,rate,delta,prog,last,gone,state,stus[]}` |
| 학습지 | `wsgModel()` | `sheets[].{title,assigned,solved,avg,mfAvg,pend,last,rows[]}` |
| 확인 필요 · 반영 대기 | `hwbModel()` | `{code,selfRows,pend,wsPend,lastSync,rt2,rt3}` |
| 반영 대기 합계 | `FLUSH` | `pend · last` (⏩ 지금 반영 단추도 그대로) |

**학생을 잇는 열쇠는 `lumen_rec_code`** 다. 퇴원생은 나오지 않는다(세 모델 모두 이미 걸러 준다).

## 3. 화면

### 3-1. 한눈에 (기본)

- **요약 여섯 칸** — 오늘 푼 문항(교재/학습지 나눠서) · 이번 주 문항(지난주 대비) ·
  평균 정답률(교재/학습지) · **⚠️ 확인 필요 n건** · **⏩ 반영 대기 n건** · **🔴 멈춘 교재 n권**
- **✅ 오늘 할 일** 카드 셋 — ① 확인 필요(누르면 그 화면) ② ⏩ 지금 반영(기존 `flushNow`)
  ③ 채점 끊긴 학생(누르면 학생별)
- **📈 최근 7일** — 교재(진한 칸) + 학습지(연한 칸)를 한 막대에 쌓는다
- **👀 지금 눈에 띄는 것** — 교재·학습지·학생을 섞어 한 줄씩(정답률 급락, 여러 명이 막힌 문항,
  곧 끝나는 교재, 다시 도전 성공). 누르면 그 자리로 간다

### 3-2. 📗 교재별 — v19-23 그대로

`rBookDash()` 의 본문을 그대로 쓴다. 머리글과 칩 줄만 공용으로 뺀다.

### 3-3. 📄 학습지별 — 옮겨오기만

`rWsGrade()` 를 **그대로 호출**한다. 내용·저장 경로·되돌려쓰기 모두 손대지 않는다.

### 3-4. 👤 학생별 — 새로 만드는 유일한 화면

- 한 줄 = 학생 한 명: **📗 교재**(진도 막대 · 권수 · 정답률) · **📄 학습지**(최근 n장 · 루멘 평균 ↔ 매쓰플랫 평균) ·
  **⚠️ 확인 필요** · **⏩ 반영 대기** · **마지막 채점일**
- 줄을 누르면 **교재와 학습지가 나란히** 펼쳐진다(교재별 진도·정답률·오답 / 학습지별 점수·못 맞힌 번호·다시 도전)
- 거르개: 전체 · 오늘 수업 반 · 중등 · 고등 · ⚠️ 확인 필요만 · 🔴 채점 끊김 · 이름 검색
- 기본 정렬: **신경 쓸 것 많은 순**(확인 필요 + 반영 대기 + 채점 끊긴 날수)

### 3-5. 폰

지금 「📗 채점 현황」의 칩을 **네 개로 맞춘다**: `한눈에 · 📗 교재별 · 📄 학습지별 · 👤 학생별`.
(지금의 「학생별」은 확인 필요 중심 화면이라 **그대로 「학습지별」 옆에 두고**, 새 「학생별」이 그 자리를 대신한다 —
기존 `mobGrdListHtml`·`mobGrdDetail` 은 **확인 필요 고치기** 경로로 그대로 살려 둔다.)
아래탭 이름은 **「📊 매쓰플랫」**으로 바꾼다.

## 4. 손대지 않는 것

- 매쓰플랫 수집기·되돌려쓰기(`hw_sync`)·워커·`book_dash` 집계 엔진
- 학습지 채점 화면의 내용과 저장 경로, ⏩ 지금 반영
- 숙제체크 안의 「교재 채점(자기채점 훑어보기)」·「📚 진도 현황」·로드맵·진도 레이스
- 학생앱·학부모앱, 서버 표 구조 (새 표도 새 칸도 만들지 않는다)
- **시험지 규칙** — 학습지 문제 그림은 어디에도 띄우지 않는다

## 5. 확인 방법

실브라우저로 실제 자료를 띄워
① 「한눈에」의 숫자가 각 칩 화면의 숫자와 **같은지**,
② 학생별 한 줄의 교재·학습지 값이 교재별·학습지별 화면의 값과 **같은지**,
③ 「학습지별」이 옛 화면과 **글자 그대로 같은지**,
④ 옛 바로가기(`VIEW='wsgrade'`)가 학습지별로 **넘어가는지**,
⑤ 기존 화면이 그대로인지(회귀) — 교재 상황판·진도 현황·숙제체크·폰 확인 필요 고치기.
