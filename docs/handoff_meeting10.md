# 인수인계: 🗣 10분 면담 + 면담 설문 — 학원앱·학생앱 세션용

> 2026-11-22 루멘이사회 세션 작성. 근거 결정: `board/decisions/2026-11-22-학생-10분면담.md`
> 이미 만든 것: **v19-202 이탈 방지**(`sync/appbuild/modules/churn202_teacher.js` · `docs/handoff_churn_guard.md`)
> 이번 건은 그 **4번째 조각**이다. 위험 신호·브리핑 화면에 면담을 붙인다.

## 왜
- 원장이 학생과 대화할 시간이 없다. 기록(점수·분량)만으로는 **왜 막히는지**가 안 나온다
- 실제 사례: 신규생 한 명이 문자 답을 전부 "네"로만 했고, 같은 기간 플래너 점수가 7~9 → 4~5로 떨어지고 제출이 끊겼다. **말수 적은 학생은 문자·면담만으로 안 걸러진다 → 글로 받는 통로가 필요**

## 운영 방식 (앱이 맞춰야 할 현실)
- **텐투텐(자율학습) 시간에** 원장이 한 명씩 불러 **10분**. 따로 시간을 내지 않는다
- 월 1회 전원 1바퀴. 텐투텐에 안 오는 학생은 수업 시작 10분 전
- 학생이 **설문을 먼저 2~3분 적고** → 그걸 보며 대화 → 원장이 **2줄 메모**

## 만들 것 A — 학원앱 «🗣 면담» (위험 신호 화면의 새 탭)
`churn202_teacher.js` 의 탭(🚨 위험 신호 · 🎉 성과 알림) 옆에 **🗣 면담** 탭을 더한다.
1. **이번 달 순번표**: 아직 면담 안 한 학생 목록. 정렬 = ① 위험 신호 걸린 학생 ② 신규생(등록 8주 이내) ③ 나머지. 각 줄에 «마지막 면담 n일 전»
2. **면담 창**: 학생 누르면
   - 왼쪽: 그 학생이 낸 **이번 달 설문 답**(없으면 «설문 미작성» + 종이 인쇄 버튼)
   - 오른쪽: 기존 **📞 브리핑** 내용 그대로(레이스·플래너·주간테스트·학교시험 + «하면 안 되는 말»)
   - 아래: **메모 2줄** 입력 → 저장
   - 지난달 메모 1개를 접힌 줄로 함께 보여준다
3. **월말 확인 줄**: «이번 달 면담 안 한 학생 n명»

## 만들 것 B — 학생앱 «면담 설문» (월 1회) + «이번 주 한 줄» (주 1회)
### B-1 면담 설문 8문항 (2~3분)
1. 요즘 수학, 할 만한가요? ①어렵다 ②조금 어렵다 ③보통 ④할 만하다 ⑤쉽다
2. 모르는 게 생기면? ①혼자 더 본다 ②답지를 본다 ③그냥 넘어간다 ④선생님께 묻는다 ⑤친구에게 묻는다
3. 수업 중 질문해 봤나요? ①자주 ②가끔 ③거의 없다
4. 가장 귀찮은 것 하나: ①플래너 ②과제 ③오답 정리 ④아하노트 ⑤풀이 녹음
5. (서술) 그게 왜 귀찮은지 한 줄로
6. 학원에 있는 시간이 편한가요? ①불편 ②조금 불편 ③보통 ④편하다 ⑤아주 편하다
7. 집에서 수학 공부 하루 평균 ___분
8. (서술) 학원에서 하나 바꿀 수 있다면? / (선택) 선생님께 하고 싶은 말
### B-2 이번 주 한 줄 (주 1회, 30초)
«이번 주 제일 막혔던 것»: 플래너 / 과제 / 수업 내용 / 친구 관계 / 없음 + 한 줄

## 원장이 읽는 규칙 (화면에 그대로 표시할 것)
- **6번이 ①②면 🔴 적응 신호등.** 성적·분량이 좋아도 면담 우선순위로 올린다
- **2번 ②③ + 3번 ③** 이면 «아하노트가 안 도는 학생» 딱지
- **«이번 주 한 줄»이 «없음»만 3주 연속** → 면담 우선순위로 올린다
- 5·8번 서술이 진짜 정보다. 객관식은 거드는 것
- 같은 문항을 매달 쓰므로 **지난달과 달라진 칸을 표시**해 준다(↑↓)

## 저장 설계 (제안)
- `counsel_meet_<학생코드>` : { "2026-12": { survey:{q1..q8}, memo:"", at:"" }, ... }
- 주간 한 줄은 `counsel_week_<학생코드>` : { "2026-W48": { tag:"플래너", text:"" } }
- 기존 `counsel_log`(상담 기록)와 **섞지 않는다**. 상담 리포트(v19-161)·상담 기록(v19-162)과 용도가 다르다
- 학생앱이 쓰고 학원앱이 읽는다. **union-merge** 규칙 주의(삭제 전파 안 됨)

## 하지 말 것
- 설문 결과를 **학부모에게 그대로 보여주지 않는다.** 아이가 솔직히 못 쓴다
- **가정사·정서를 캐묻는 문항을 넣지 않는다.** 6번 한 문항이면 충분하다 (학원 범위를 넘지 않는다)
- 설문 점수로 심리 상담 대상을 **자동 지정하지 않는다.** 면담에서 듣고 원장이 권유한다
- 미작성 학생에게 **독촉 알림을 보내지 않는다.** 특히 신규생에게 제재성 문구(«재등록 안 돼요» 등)는 금지 (이사회 결정 12번)
- 자동 문자 금지. 원장 전용 화면이다

## 참고
- 설문 종이 인쇄본도 필요하다(앱 미작성자용). A4 1장, 글씨 크게
- 심리 상담(TLP) 연계는 **아직 미정 안건** — 이 기능에 넣지 않는다
