# 수학비서 → 매쓰플랫: 나눠 올라간 학습지를 한 장으로

원장님 지시 (2026-09-17): **「108문제가 그대로 들어가야 한다. 번호 순서를 맞추려면 나누면 안 된다.」**

## 왜 나뉘었나

매쓰플랫의 문서 인식(`document-processing-flow`)이 **한 번에 10쪽까지만** 받는다.
「[비상] 중등수학 1-2 중간 (위치,작도)」 108문항은 A4 2단으로 짜면 **17쪽**(85%로 줄여도 14쪽)이라
10쪽 안에 들어가지 않아 PDF 를 54 + 54 두 장으로 나눠 올렸고, **학습지도 두 장**이 되었다.
두 번째 장은 매쓰플랫 번호가 1부터 다시 시작해 원본 프린트의 번호와 어긋난다.

## 알아낸 것 (실측 2026-09-17)

- 학습지의 «나의 DB 원본» 번호는 문항마다 붙어 있지 않고 **`worksheet.filter.myDbProblemDetailIds`** 에 모여 있다
  (`problems[].myDbProblemDetailId` 는 `null`).
- **서로 다른 원본(paper) 두 개에서 나온 문항을 한 학습지에 담을 수 있다.**
  `POST /worksheet` 에 `problemList`(순서)와 `myDbProblemDetailIds`(두 원본의 번호를 합친 목록)를 함께 주면 된다.
  → 10쪽 제한은 **PDF 올리기에만** 걸리고, 학습지에는 걸리지 않는다.

## 고친 것

### ① 이미 나뉘어 올라간 것을 합치는 도구 — `sync/mf_merge_worksheets.js` (새로 만듦)

이미 올라간 학습지의 문항은 문제은행에 복사가 끝나 있으므로 **PDF 를 다시 올리지 않는다.**

```
node sync/mf_merge_worksheets.js --ws 82224846,82225520 \
     --title "[비상] 중등수학 1-2 중간 (위치,작도)" --mylist 수학비서 [--dry] [--delete-old]
```

- 순서대로 이어 붙여 새 학습지 한 장을 만들고, 문항 수·번호 순서·정답을 **다시 읽어 확인**한 뒤 마이리스트에 담는다.
- 확인이 어긋나면 옛 학습지를 건드리지 않고 멈춘다. `--delete-old` 를 줄 때만 옛 학습지를 지운다.

**실행 결과**: 학습지 **82557472** 「[비상] 중등수학 1-2 중간 (위치,작도)」 — 108문항 · 번호순서 일치 · 정답 108/108 · 자동채점 29.
옛 학습지 82224846(1~54) · 82225520(55~108)은 **지우지 않고 남겨 두었다**(원장님 판단 대기).

### ② 앞으로는 처음부터 한 장 — `sync/mypaper_to_mathflat.js`

- PDF 는 지금처럼 10쪽 제한에 맞춰 나눠 올리되, **학습지는 마지막에 한 장으로** 만든다.
  나눈 장들은 문제은행 복사까지만 하고(`part.defer`), `makeOneWorksheet()` 가 전부 이어 붙인다.
- 학습지 제목에 `(1/2) 1~54` 꼬리를 붙이지 않는다. 그 꼬리는 «나의 DB 원본»(paper) 이름에만 남는다.
- 합치기가 실패하면 **이미 올린 것을 다시 올리지 않고** 장마다 학습지만 만들어 옛 방식으로 물러난다.
- 옛 방식으로 강제하려면 `--split-worksheets`.

## 자동채점 학습지 (2026-09-17 확인)

원장님 목표: **「자동채점 학습지로 만드는 것이 목표였다」**. 왜 안 됐는지 실험으로 확인했다.

### 매쓰플랫의 규칙 (전부 실측)

| 확인한 것 | 결과 |
|---|---|
| 학습지의 `autoScorableFlag` 를 만들 때 지정할 수 있나 | **없다.** `true` 로 보내도 매쓰플랫이 스스로 다시 정한다 |
| 언제 참이 되나 | **모든 문항이 자동채점 가능할 때만.** 객관식 3개 → 참 / 객관식 2 + 단답 1 → 거짓 |
| 단답형은 자동채점되나 | **안 된다.** 답이 숫자 하나(`"8"`)여도 `autoScoredType: IMPOSSIBLE` |
| `autoScoredType` 을 직접 넣으면 | `POSSIBLE`·`POSSIBLE_PLUS` 를 보내도 **200 OK 지만 무시**되고 그대로 `IMPOSSIBLE` |
| `problemType: 'NUMBER'` 같은 다른 유형 | 400 (그런 유형 없음) |
| 매쓰플랫 자체 교재 문항은 | 단답·서술 전부 `IMPOSSIBLE` (객관식도 교재 쪽은 IMPOSSIBLE) |

→ **매쓰플랫 자동채점 = 객관식(SINGLE_CHOICE·MULTIPLE_CHOICE) 뿐이다.**

### 이 문제지(108문항)의 한계

수학비서 원본 기준: 객관식 31 (단일 26 · 복수 4 · 섞임 1), 나머지 77은 단답·서술·참거짓·빈칸 채우기.
→ **매쓰플랫에서 자동채점될 수 있는 최대치가 31/108**이고, 그래서 이 학습지는 영영 「자동채점 학습지」가 되지 못한다.

### 고친 것 — 객관식을 놓치지 않게

매쓰플랫 OCR 이 보기를 흐리게 읽으면 **객관식을 단답으로 잘못 판정**한다(실측: 33번 — 수학비서는 `single_choice`, 매쓰플랫은 `SHORT_ANSWER`).
이제 **수학비서의 유형을 따른다**(`msPureChoice`). 답이 «전부» 객관식일 때만 바꾸고,
「서술 + 보기 고르기」처럼 섞인 문항은 손대지 않는다(보기 번호만 남기면 나머지 답이 사라지므로).
실행 로그에 `✎ 수학비서 유형대로 객관식으로 바로잡음` 과 `자동채점 학습지: 예/아니오` 가 찍힌다.

### 진짜 해법 후보 — 루멘 앱이 채점한다

수학비서 정답 108개를 우리가 이미 갖고 있고, 루멘 채점 엔진(`sync/hw_grade_engine.js`)에 넣어 보면
**94/108 문항을 기계가 채점할 수 있다**(모양별: 숫자 35 · 단위 25 · 기호 16 · 도형 9 · 식 6 · 말 3, 자기채점으로 넘길 것 14).
매쓰플랫 학습지 채점 되돌려쓰기(`PATCH student-worksheet/assign/{id}/scoring`)는 이미 실측돼 있으므로
(`docs/worksheet_score_contract.md`), **학생 답을 읽어 루멘이 채점하고 결과를 매쓰플랫에 써 넣는** 길이 열려 있다.
원장님 결정이 필요하다.

## 2026-09-19 — 매쓰플랫이 만든 학습지(내신대비)도 합칠 수 있게 넓혔다

원장님 질문: **「보이는 학습지를 통합해서 하나로 만들어서 줄 수 있나?」**
(화면: 중1 「[중1-2] 기본 도형-비상1~4」, 「[중1-1] 좌표평면과 그래프-비상3~4」 — 교과서 비상 기준 내신대비 학습지)

### 알아낸 것 (실측)

- 이 학습지들은 **매쓰플랫이 만든 것**이고, 갈래 `SCHOOL_PREPARE`(내신대비) ·
  필터 **`type: 'CONCEPT'`**(유형으로 고른 것)이다. 「나의 DB 원본」과 구조가 다르다.
- 문항은 이미 매쓰플랫 문제은행에 있으므로 **번호(problem id)만 순서대로 이어 붙이면 된다.**
  필터는 `POST /worksheet/filter/concept` 에 **두 학습지의 유형 번호를 합쳐서** 만들고,
  `POST /worksheet` 의 `problemList: [{id, tagTop}]` 로 문항을 못 박는다.
- `tagTop`(「교과서 - 비상, 161p 중단원 학습 점검 1」)이 문항마다 그대로 따라오므로,
  합친 뒤에도 **어느 교과서 몇 쪽에서 온 문제인지** 남는다.
- 갈래는 원본 갈래(`SCHOOL_PREPARE`)로 그대로 만들어졌다(거절되면 `ETC`로 물러난다).

### 고친 것 — `sync/mf_merge_worksheets.js`

- 「나의 DB 원본」만 받던 것을 **「유형(CONCEPT)」 학습지도** 받도록 넓혔다. 종류가 섞이면 멈춘다.
- 겹치는 문항이 있을 때 `--drop-dup` 을 주면 뒤에 나온 중복을 빼고 합친다(기본은 그대로 멈춤).
- 인쇄 서식(`layoutType`·`partitionType` 등)은 첫 학습지 것을 따라간다.
  「유형」 학습지도 `conceptIdList: []` 로 보내 **이론(개념) 박스가 인쇄되지 않게** 한다.

```
node sync/mf_merge_worksheets.js \
  --ws 53383888,55271463,58439590,58439591,58439592,58439598 \
  --title "[비상] 중1 내신대비 통합 (좌표평면,기본도형)" --mylist "" [--dry] [--delete-old] [--drop-dup]
```

### 실행 결과

**학습지 82688172 「[비상] 중1 내신대비 통합 (좌표평면,기본도형)」 — 86문항 · 22쪽**
(좌표평면 비상3 1~16 · 비상4 17~31 · 기본도형 비상1 32~47 · 비상2 48~58 · 비상3 59~72 · 비상4 73~86)
번호 순서 일치 · 정답 65/65 · 겹치는 문항 없음 · 옛 학습지 6장은 그대로 둠.

자동채점 학습지는 **안 된다** — 86문항 중 63문항만 객관식이라 자동채점 가능이고,
매쓰플랫은 **전 문항이 객관식일 때만** 자동채점 학습지로 인정한다(위 2026-09-17 실측과 같음).
