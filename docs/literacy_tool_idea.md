# 📖 문해력 개발 도구 — 아이디어·의견 (2026-10-13, 상의 전 초안)

원장 요청: 학생들이 문제를 "못 푸는" 게 아니라 "못 읽는" 경우가 많다. 수학 문제집 지문, 국어·사회 교과서 지문으로 객관식 문제를 만들어
제한시간 세트 / 문항별 측정 두 방식으로 풀게 하고, 학생 보고서·학부모 보고서까지 나오는 기능.
순서: 아이디어 → 상의 → 미리보기(시안 html) → 코딩.

---

## 1. 무엇을 재는가 — "문해력"을 수학학원답게 좁히기

일반 독해력(국어)과 수학 문장 읽기는 다르다. 루멘은 수학학원이므로 **1차는 "수학 문제 읽기 능력"** 으로 좁히는 걸 권한다.
학생이 문장제를 틀리는 지점은 거의 다섯 가지다. 문항 유형도 여기서 나온다.

| 유형 | 학생이 못 하는 것 | 객관식 문항 예 |
|---|---|---|
| ① 조건 찾기 | 주어진 조건을 빠뜨림 | "이 문제에 **주어지지 않은** 조건은?" / "조건은 모두 몇 개?" |
| ② 묻는 것 찾기 | x를 구해놓고 끝냄 (구하라는 건 둘레인데) | "이 문제가 **최종적으로 구하라는 것**은?" |
| ③ 수학 어휘 | 이상/초과, 배/분, 몫/나머지, 증가율, 둘레/넓이 | "'x의 3배보다 5만큼 작은 수'를 식으로 쓰면?" / "'이상'에 7은 포함되나?" |
| ④ 식으로 옮기기 | 문장 → 식 변환에서 순서·부호 뒤집힘 | "다음 문장을 바르게 식으로 옮긴 것은?" (선택지 4개 중 부호·순서만 다름) |
| ⑤ 필요 없는 정보 걸러내기 | 잉여 정보에 끌려감 / 핵심 문장 못 찾음 | "풀이에 **쓰이지 않는** 문장은?" / "핵심 문장은?" |

여기에 2차로 넣을 만한 것:
- ⑥ 풀이 순서 재배열(풀이 단계를 섞어 주고 순서 고르기)
- ⑦ 표·그림 대조(문장에 맞는 그림/표 고르기 — 도형·함수 문제)
- ⑧ 바꿔 말하기(같은 뜻의 문장 고르기 — 서술형 답안 읽기 훈련으로 이어짐)
- 사회·과학 교과서 지문: 중심 문장 / 사실·의견 / 원인·결과 / 단어 뜻 문맥 추론 — **설명문 읽기**라서 수학 문장제와 가깝다. 국어 교과서(문학)는 뺀다.

**의견**: 국어·사회 지문을 같이 넣으면 "수학학원에서 왜 국어를?"이라는 학부모 질문이 나온다.
"수학 문장 읽기 훈련 → 범위를 설명문까지" 순서가 설득이 쉽고, 문항 만드는 것도 수학이 훨씬 수월하다(정답이 분명하다).

## 2. 지문 출처와 저작권 — 미리 정해야 할 것

- 문제집 문장·교과서 본문을 **그대로** 앱에 저장해 학생 기기로 보내는 건 저작권 문제가 있다. 이미 저장소 규칙으로 「학습지·시험지 그림은 학생앱에 띄우지 않는다」가 있다.
- 권하는 방식: **AI로 새로 쓴다.** 원장이 원본 지문(사진/글)을 넣으면 → 같은 구조·같은 수학 개념의 **새 상황·새 숫자**로 지문을 다시 쓰고 → 문항 5개 초안 → 원장 ✓/✗/수정 → 문항 은행.
  - 수학 문장제는 "숫자·상황 변형"이 이미 적중 분석에서 쓰는 개념(숫자변형·유사유형)이라 자연스럽다.
  - 사회·과학은 교과서 단원 주제만 따오고 설명문을 새로 쓴다(공공누리 자료·공공 통계 활용 가능).
- 가장 루멘다운 출처: **매쓰플랫에서 수집한 그 학생의 오답 문장제**. "네가 지난주 틀린 그 문제, 계산이 아니라 읽기에서 틀렸다"를 데이터로 보여준다. 리커버리 학습지(`rc_ws`)와 같은 뿌리에서 가지를 치면 된다.

## 3. 측정 방식 — 두 모드 다 하되 역할을 나눈다

| | 진단 세트(제한시간) | 매일 훈련(문항별 측정) |
|---|---|---|
| 언제 | 처음 1회 + 3개월마다 같은 세트 (사전·사후 비교) | 수업 시작 5분 또는 텐투텐 시작 때, 하루 3문항 |
| 양 | 20문항 / 12분 | 3문항 / 약 4분 |
| 재는 것 | 전체 정확도, 유형별 정답률, 속도 | 아래 세부 지표 |
| 보고서 | 학부모 보고서의 뼈대 | 학생앱 스트릭·XP, 주간 요약 |

문항별 측정에서 잴 수 있는 것(객관식이라 AI 없이 전부 앱 안에서 계산 → **채점 비용 0원**):
1. **읽기 시간 / 답 시간 분리** — 지문만 먼저 보여주고 「다 읽었어요」를 누르면 문제가 나온다. 읽기 속도(글자/분)와 이해 정확도를 따로 본다.
2. **다시 보기 횟수** — 문제 화면에서 지문을 접어 두고, 펼칠 때마다 센다. "한 번 읽고 기억하는가"를 본다.
3. **서두름 지수** — 또래 평균보다 빨리 읽고 틀린 비율. 원장이 현장에서 가장 많이 보는 "휙 읽고 틀림"을 숫자로.
4. **유형별 정답률** — ①~⑤ 레이더.
5. **오답 사유** — 틀린 뒤 학생이 한 줄 고르기(「조건을 못 봤다 / 단어 뜻을 몰랐다 / 급했다 / 식을 반대로 세웠다」). 아하노트의 "틀린 이유 태그"와 같은 방식.
6. 이탈 감지 — 탭 전환·화면 꺼짐이면 그 문항 시간은 무효 처리(태블릿 놔두고 딴짓 방지).

기준선은 처음엔 **학원 내 같은 학년 평균**뿐이다. 전국 기준은 없다는 걸 학부모 보고서에도 솔직히 쓴다("루멘 중2 평균 대비").

## 4. 보고서

**학생 보고서(학생앱, 매일·매주)**
- 오늘 3문항 결과, 읽기 속도, 스트릭🔥, XP(기존 레벨 체계에 "읽기" 항목 추가)
- 주간: 유형 레이더 + "이번 주 약한 유형 한 줄" + 다음 주 훈련은 그 유형 비중↑ (자동)

**학부모 보고서(월 1회, 1쪽 인쇄 + 학부모앱 카드)**
- 첫 문단 프레임: "문제를 못 푸는 게 아니라 못 읽는 것 — 어디서 막히는지 봤습니다"
- 정확도·읽기 속도·서두름 지수의 3개월 추이(진단 세트 사전·사후)
- 실제 사례 1개: 틀린 문장제 1문항 + 어느 문장에서 막혔는지
- 집에서 할 것 **딱 1가지** (예: 문제 읽고 "구하라는 게 뭐야?" 한 번 묻기)
- Ultra Feedback 문단에 한 줄 자동 삽입 가능("이번 주 읽기 훈련 3/3, 조건 찾기 유형이 약함")
- 인쇄 틀은 진학 나침반 3쪽 리포트 방식을 재사용

## 5. 앱 배치와 데이터

- **학생앱**: 새 탭 「📖 읽기 훈련」 — 오늘 3문항 / 진단 세트 / 내 기록. ES5·단일 HTML 규칙 그대로.
- **학원앱**: 「문해력」 메뉴 — 문항 은행(검수 ✓/✗/수정), 세트 배정, 학생별 결과·학년 평균, 학부모 보고서 인쇄. 조립 부품 `modules/lit_teacher.js`.
- **학부모앱**: 월 보고서 카드.
- **서버(Supabase)**: 새 표 2개 — `lit_items`(문항 은행: 지문·문항·선택지·정답·유형·학년·출처 메모), `lit_attempts`(학생코드·문항·답·정오·읽기ms·답ms·재읽기 횟수·오답 사유·세트 id). 표 만들기·색인은 규칙대로 새벽에.
- **AI 비용**: 문항 생성만 AI(원장 키로 학원앱에서, 또는 채팅에서 내가 초안). 학생 채점·지표·보고서 수치는 AI 없음. 학부모 보고서 문장만 월 1회 AI(Ultra Feedback 과 같은 새벽 작업에 얹기).

## 6. 무너질 수 있는 지점 (독설가 관점)

1. **학생이 안 한다** — 집 숙제로 주면 플래너처럼 "내는 척"이 된다. → 수업 시작 5분 루틴으로 묶고, 학원 태블릿에서 한다. 집은 선택.
2. **문항 품질** — AI가 만든 선택지는 너무 쉽거나 두 개가 다 맞는 경우가 흔하다. → 원장 검수 없이는 은행에 안 들어간다. 처음엔 주 10문항씩 소량. 학생 정답률 95%↑ 문항은 자동으로 "너무 쉬움" 표시.
3. **향상을 증명 못 한다** — 매일 점수는 문항 난도에 흔들린다. → 사전·사후 **같은 진단 세트** 로만 향상을 말한다.
4. **시간 측정 왜곡** — 딴짓, 친구와 상의. → 이탈 감지 + 읽기 시간 상한(예: 3분) + 수업 중 실시.
5. **원장 시간** — 검수에 매주 30분이 든다. 그만한 가치가 있는지는 한 달 해보고 판단.

## 7. 1차 범위 제안 (MVP)

- 대상: 중등 (고등은 2차)
- 지문: 수학 문장제만, 유형 ①~⑤
- 문항 은행 시드: 채팅에서 내가 **중1~중3 각 40문항 = 120문항 초안** → 원장 검수 → 서버 적재 (앱 안 AI 생성 단추는 2차)
- 진단 세트 20문항(12분) 1개 + 매일 3문항
- 학생앱 탭 1개, 학원앱 결과·검수 화면 1개, 학부모 보고서 1쪽
- 매쓰플랫 오답 연동·사회 지문·풀이 순서 재배열은 2차

## 8. 상의할 것 (시안 그리기 전에)

1. 대상 학년: 중등만? 고등도 처음부터?
2. 지문 범위: 수학만으로 시작하는 데 동의하시는지, 아니면 사회 지문도 1차부터?
3. 하는 때: 수업 시작 5분(학원 태블릿) vs 집 숙제 vs 둘 다
4. 지문 원문 사용 여부: AI로 새로 쓰는 방식에 동의하시는지
5. 오답 사유 고르기 단계를 넣을지(한 단계 늘어남 — 학생 귀찮음 vs 데이터 가치)
6. 학부모 보고서 주기: 월 1회 별도 1쪽 vs Ultra Feedback 안에 한 줄

답을 주시면 → `docs/mockup_literacy.html` 로 학생앱 화면(지문→문제→결과)·학원앱 검수 화면·학부모 보고서 1쪽 시안을 그린다.
