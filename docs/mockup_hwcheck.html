📋 숙제체크 — 한 번 눌러 완료, 미흡만 단계·%까지

지금 쓰시는 숙제체크 그리드(빠른 입력)는 그대로 두고, 「미흡」을 누르는 그 순간에만 작은 창이 떠서 「어디까지 했는지 · 몇 %인지」를 한 번 더 클릭으로 받는 방식입니다.
아래 그리드는 실제로 눌러볼 수 있습니다 — 직접 클릭해 보세요.

① 왜 2번째 화면(빠른입력 상세)은 안 쓰게 됐을까
고칠 방향을 정하려면 원인부터 정확히 봐야 합니다
📚
교재별로 따로 적어야 한다

학생 한 명이 교재를 3~4권 쓰면, 한 명당 입력 칸이 3~4세트입니다. 25명이면 80~100세트. 그런데 원장님이 실제로 알고 싶은 건 “오늘 이 학생이 숙제를 해왔나” 하나입니다.

👆
완료인 학생도 클릭을 4~8번 해야 한다

단계 버튼 1번 + 퍼센트 버튼 1번 = 교재당 2클릭. 대부분의 학생이 그냥 다 해온 상태인데도 똑같이 손이 갑니다. 잘한 학생에게 시간이 더 드는 구조입니다.

📜
학생 카드가 세로로 길어 스크롤이 끝없다

한 화면에 3명씩만 보이니, 25명을 보려면 8번 스크롤. 반 전체를 훑어보는 감각이 사라집니다.

✅
반대로 1번째 화면(그리드)이 좋은 이유

① 한 화면에 반 전체 × 한 달이 다 보인다 ② 1클릭이면 끝난다 ③ 빠진 학생이 눈에 바로 띈다. → 이 장점은 절대 건드리지 않는 것이 이번 설계의 첫 번째 원칙입니다.

② 설계 원칙 3가지
“쉽게 입력”을 실제로 만드는 규칙
원칙 1 — 잘한 학생에겐 손이 덜 가야 한다.
숙제를 다 해온 학생은 1클릭(🟢)으로 끝. 풀이·채점·오답·아하노트 모두 완료 + 100%가 자동 기록됩니다.

원칙 2 — 세부 입력은 「미흡」일 때만, 그것도 자동으로 뜬다.
🔴 미흡을 누르면 추가 동작 없이 그 자리에 작은 창이 뜹니다. 길게 누르기·우클릭 같은 걸 새로 배울 필요가 없습니다.

원칙 3 — 그 창을 무시해도 지금과 똑같이 동작한다.
창이 떴는데 그냥 다른 데를 누르면 그대로 「미흡」으로 저장됩니다. 지금보다 나빠지는 경우가 없습니다.
③ 직접 눌러보세요 실제 동작
칸을 클릭하면 빈칸 → 🟢완료 → 🔴미흡(창 뜸) → 지움 순으로 돕니다
클릭 순환: 🟢 완료 → 🔴 미흡 → 지움 날짜 아래 [전원✅] 를 눌러보세요 — 반 전체 한 번에 완료
🟢 완료 (100%) 풀 풀이까지 채 채점까지 오 오답까지 🔴 아예 안 해옴 미체크
· 칸 오른쪽 아래 작은 숫자가 퍼센트입니다 (100%는 숫자를 감춰 화면을 깔끔하게)
· 칸에 마우스를 올리면 「풀이까지 · 30% · 오답/아하노트 미완료」처럼 말로 풀어서 보여줍니다
④ 실제 수업날 입력 순서 — 25명이 약 40초
클릭 수를 실제로 세어 본 결과입니다
1
날짜 아래 [전원✅] 을 반마다 한 번씩 누른다 신규

그 반 학생 전원이 🟢 완료로 채워집니다. 반이 8개면 8클릭.

2
안 해온 학생 칸만 두 번 더 눌러 🔴 로 바꾼다

보통 반당 0~2명입니다. 3명이면 6클릭.

3
자동으로 뜬 창에서 「어디까지」 한 칸만 누른다

[풀이] [채점] [오답] 중 하나. 퍼센트는 자동 추천값이 이미 눌려 있어 대부분 그냥 닫으면 됩니다. 다르면 그때만 %를 한 번 더. 3~6클릭.

합계 — 약 17~20클릭 / 25명. 지금 그리드(25클릭, 단계·% 없음)보다도 적으면서 정보는 훨씬 많아집니다.
2번째 화면(빠른입력 상세)으로 같은 일을 하면 160~200클릭 + 스크롤 8번입니다.
⑤ 퍼센트를 매번 안 눌러도 되는 이유
단계를 고르면 퍼센트가 알아서 따라옵니다 — 다를 때만 고치면 됩니다
어디까지 했나자동 퍼센트미완료로 기록되는 단계
🟢 완료 (1클릭)100%없음 — 풀이·채점·오답·아하노트 모두 완료
오 오답까지80%아하노트 미완료
채 채점까지60%오답 · 아하노트 미완료
풀 풀이까지30%채점 · 오답 · 아하노트 미완료
🔴 아예 안 해옴0%풀이 · 채점 · 오답 · 아하노트 전부 미완료
“어디까지 했다”만 고르면 무엇이 미완료인지는 자동으로 정해집니다. 풀이를 안 했는데 오답을 했을 수는 없으니, 네 개를 각각 체크할 필요가 없는 것입니다.
※ 순서를 건너뛴 특이한 경우(예: 채점은 했는데 풀이 안 함)는 실제로 거의 없어, 그 경우엔 창 아래 「단계별로 따로 적기」를 눌러 네 개를 직접 체크할 수 있게 둡니다.
⑥ 이렇게 모은 정보가 어디에 쓰이나
입력이 늘어난 만큼 돌려받는 것
1. 학부모 리포트 문구가 구체적으로 바뀝니다
지금: “숙제가 미흡했습니다.” → 앞으로: “풀이는 해왔으나 채점·오답 정리를 못 했습니다(30%).”

2. 어느 단계에서 막히는지가 학생별로 보입니다
“이 학생은 늘 채점까지만 하고 오답을 안 한다” → 지도 포인트가 명확해집니다.

3. 아하노트 미완료가 쌓이면 자동으로 눈에 띕니다
아하노트 단계는 이미 학생앱과 연결되어 있어, 미완료가 3회 쌓이면 경고로 띄울 수 있습니다.

4. 이번 달 요약이 숫자로 나옵니다
오른쪽 「이번달」 칸이 완료 8 · 미흡 3 · 평균 78% 처럼 바뀝니다.
⑦ 다른 방법도 검토했습니다
왜 이 방식을 추천드리는지
방법설명판단

D안
매쓰플랫 자동		 매쓰플랫 채점 기록으로 「채점까지」를 자동 추정 🔷 C안 위에 얹을 것 — 자동으로 옅게 채워두고 원장님이 확인만. 정오답 자동 수집이 끝난 뒤 단계
⑧ 구현 시 확인 사항
승인해 주시면 이 범위로 만들겠습니다
· 그리드 화면만 바뀝니다. 2번째 화면(빠른입력 상세)은 그대로 둡니다 — 교재별로 따로 적고 싶을 때를 위해 남겨둡니다.
· 기존에 찍어 두신 🟢🔴 기록은 그대로 유지됩니다. 단계·%가 없는 옛 기록은 「완료 / 미흡」으로만 표시됩니다.
· 리포트 경고등 연동은 지금과 똑같이 유지됩니다. 🟢은 완료, 나머지는 미흡으로 리포트에 반영되고, 문구만 더 구체적으로 나갑니다.
· 아이패드에서 창이 화면 밖으로 나가지 않게 위치를 자동으로 맞춥니다(오른쪽 끝 학생은 왼쪽에 뜸).
· 저장은 지금처럼 날짜별 합집합 동기화라 PC·아이패드 어느 쪽에서 찍어도 서로 반영됩니다.
