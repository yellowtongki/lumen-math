# blog/ — 블로그 글 한 편이 사는 곳

글 한 편 = 폴더 하나. `blog/<날짜-주제>/` 안에 본문·카드 문구·카드 PNG·실사진이 같이 있다.
GitHub Pages로 서비스되므로 **카드 PNG는 인터넷 주소로 열린다** (인스타 업로드에 그대로 쓴다).

```
blog/2026-09-20-banten/
  post.md            본문 (머리말 + 마크다운). 네이버에 붙여넣는 원고
  cards.json         카드 문구 (type: cover / qa / stat / compare / list / closing / photo / solve)
  bg_*.jpg           카드 배경으로 쓸 사진 (AI로 만든 배경이나 실사진)
  cards/01_cover.png … 06_closing.png   생성된 카드 (1080×1350)
  photo_01_*.jpg     원장님 실사진 (학생 얼굴·이름 없는 것만)
```

## 한 편 만드는 순서

| 단계 | 누가 | 명령 / 할 일 |
|---|---|---|
| ① 글감 | 도구 | `node sync/blog_topics.js --days 7 --topic "오늘 있었던 일"` → `docs/blog_topics_latest.md` |
| ② 본문·카드 문구 | Claude | `docs/lumen_blog_profile.md` 말투로 `post.md` + `cards.json` 작성 |
| ③ 카드 | 도구 | `node sync/card_render.js blog/<폴더>` → PNG 6장 |
| ④ 검사 | 도구 | `node sync/post_check.js blog/<폴더>` → 전부 ✅ 여야 다음으로 |
| ⑤ 네이버 | **원장님** (당분간) | 제목·본문 붙여넣기 → 카드 6장 → 실사진 자리 3곳에 사진 → 지도 → 톡톡 → 해시태그 → **발행** |
| ⑥ 인스타 | 도구 (5단계에서 만듦) | 같은 카드 6장을 캐러셀로 |

## 올린 뒤 — 검색에 뜨는지 점검

```
node sync/serp_check.js        # 맥미니·학원 컴퓨터에서만. 클라우드에서는 캡차가 뜬다
```

검색어 10개를 휴대폰 네이버에 쳐 보고 첫 화면에 우리 글이 있는지 세어 `docs/serp_latest.html` 을 만든다.
점검할 때마다 `docs/serp_history/` 에 쌓여서 **지난번과 비교**된다. 검색어는 `sync/serp_keywords.json` 에서 고친다.

보고서에는 «이 동네에서 이기고 있는 블로그»가 같이 나온다. **그 제목들이 다음 글감**이다.

## 검색어 고르기 — 감이 아니라 숫자로

```
node sync/keyword_volume.js     # 네이버 검색광고 API (공식·무료). 키 3개 필요
```

낱말별 **월간 검색수**를 `docs/keyword_volume.md` 로 뽑는다. 블랙위키 같은 사이트가 보여주는 그 숫자의 원본이다.
제목·소제목·해시태그를 이걸 보고 고른다. 검색수가 큰 낱말은 경쟁이 세니 **지역이 붙은 낱말**을 노린다.

카드가 마음에 안 들면 `cards.json` 문구만 고치고 `--only N` 으로 그 장만 다시 만든다.

### 폴더를 안 적으면 어느 글이 잡히나 (2026-10-18)

`blog` 를 폴더 없이 돌리면 **날짜가 가장 늦은 글**로 간다. 같은 날짜 폴더가 둘이면
**`post.md` 를 마지막에 고친 쪽**이다 (하루에 두 편 쓰는 날이 있어서 고쳤다).

그래도 엉뚱한 글이 잡히면 **폴더를 직접 적는 것이 확실하다.**

```
blog blog/2026-10-18-jungan-results
```

## 규칙 (짧게)
- 실사진은 **3곳 이상**이 기본이다. 카드만 쓰는 홍보·안내 글은 머리말에 `photos: 1` 처럼 적어 낮춘다
- 학생 이름·개별 점수·얼굴은 넣지 않는다. 이 폴더는 공개다
- **외부 서비스 이름**(매쓰플랫·수학비서·클래스바이 …)을 본문·카드·해시태그에 쓰지 않는다
  → 「루멘수학 시험대비자료」, 「학원 학습 기록」으로 바꿔 말한다
- **학교 기출**을 드러내지 않는다 (학교 규정). 검사기가 본문과 카드 문구를 둘 다 본다.
  단 **PNG 그림 속에 박힌 글자는 검사기가 못 읽는다** — 사람이 봐야 한다
- 확인 안 된 숫자는 지어내지 않는다. 검사기가 `❏` 가 남아 있으면 막는다
- 교습비·등록번호는 별도 안내 글에만 (`recruit: true`)


## 카드 종류 8가지

| type | 쓰임 |
|---|---|
| `cover` | 표지 (진남색 단색) |
| `photo` | **표지 — 사진 배경 위에 큰 글자** |
| `qa` | 질문 하나 + 답 |
| `stat` | 큰 숫자 하나 |
| `compare` | 둘을 나란히 |
| `list` | ①②③ 나열 |
| `solve` | **문제 → 풀이 → 답안 3단 (수식 들어감)** |
| `closing` | 마무리 + 연락 |
| `external` | **학원앱에서 받은 PNG를 그대로 쓸 때** |
| `award` | **시험 결과 축하 카드** (1등급·100점 등). 미리캔버스 대신 |

### 학원앱 카드를 그대로 쓸 때 (`external`)

학원앱 「적중 분석·카드뉴스」가 만든 PNG는 **다시 그리지 않고 그대로 쓴다.**
PNG를 `<글 폴더>/cards/` 에 넣고 `cards.json` 에 순서대로 적으면 된다.

```json
{ "type": "external", "file": "01_cover.png", "note": "표지" }
```

- `card_render.js` 는 이 카드를 **건너뛴다**(`⏭️` 표시). 파일이 없으면 멈추고 알려준다
- `note` 와 `_` 로 시작하는 칸은 **내부 메모**다. 검사기가 읽지 않으니 편히 적어도 된다
- 엔진 카드와 **섞어 써도 된다**. 네이버·인스타에 들어가는 순서는 `cards.json` 배열 순서다

### 수상 카드 (`award`) — 2026-10-18 추가

미리캔버스로 만들던 축하 이미지를 우리 엔진으로 옮긴 것이다. **워터마크가 없고**, 글자만
바꾸면 다시 뽑힌다. 브랜드 색(붉은 바탕 + 전구 노랑)에 맞춰져 있다.

```json
{ "type": "award",
  "exam": "2026년 2학기 중간고사",
  "who":  "소사고등학교 1학년",
  "big":  "1등급",
  "sub":  "노력으로 이뤄낸 결과를 축하합니다" }
```

- `who` 에 **이름을 넣을지 말지**가 쓰임새를 가른다
  - **학원 벽·학부모 문자·명예의 전당** → 「소사고등학교 1학년 유OO」 처럼 성만
  - **블로그·인스타** → **학교·학년까지만.** 한 학교에 학생이 한둘이면 성만 써도 누구인지 좁혀진다
- `big` 은 「1등급」 「100점」 「전교 1등」 무엇이든 들어간다. 길면 자동으로 줄어든다

### 사진 배경 카드 (`photo` · `solve`)

```json
{ "type": "photo",
  "bg": "bg_room.jpg",
  "kicker": "루멘수학 · 옥길중 2학기 중간",
  "headline": "**정답**을 아는 것과\n__끝까지 쓰는 것__은\n다릅니다",
  "sub": "한 줄 설명" }
```

- `bg` — 글 폴더 안의 사진 파일 이름. 어두운 막을 자동으로 덮어 글자가 읽히게 한다
- 큰 제목의 **색 강조**: `**주황**` · `__하늘__` · `~~금색~~`
- 줄바꿈은 `\n`

> 🎨 **배경 사진은 어디서 오나**
> ① 원장님이 찍은 실사진 ② GPT 등으로 만든 **글자 없는** 배경 그림.
> **글자는 절대 AI로 만들지 않는다** — 한글이 깨진다. 글자는 늘 이 도구가 얹는다.
> 학원 내부·수업 장면을 AI로 지어내지 않는다 (허위 광고). 배경은 분위기용 그림까지만.

### 배경 그림을 GPT로 만들기

```bash
node sync/image_gen.js blog/<폴더> --dry     # 🔑 키 없이 — 프롬프트만 뽑아 ChatGPT에 붙여넣기
node sync/image_gen.js blog/<폴더>           # 키가 있으면 바로 생성 (맥미니)
```

`cards.json` 의 카드에 이렇게 적어 둔다.

```json
{ "type": "photo",
  "bgPreset": "desk_night",
  "bgPrompt": "시험을 앞둔 늦은 밤, 문제집 위에 놓인 연필",
  "headline": "**정답**을 아는 것과 ..." }
```

프리셋: `desk` · `desk_night` · `night` · `paper` · `window` · `abstract` · `gradient`
`bgPrompt` 는 한국어로 자유롭게 써도 된다. 둘 다 쓰면 합쳐진다.

프롬프트에는 **브랜드 색(진남색+금색), 왼쪽 위를 비워 달라는 구도 지시, 글자 금지**가 자동으로 붙는다.
왼쪽 위를 비우는 이유는 **거기에 큰 제목이 얹히기 때문**이다.

> ⚠️ **AI는 배경만 만든다.** 글자·수식은 늘 카드 생성기가 HTML로 얹는다 (한글이 깨지므로).
> 학원 내부·수업 장면·사람 얼굴은 만들지 않는다 (허위 광고).

### 문제 풀이 카드 (`solve`)

```json
{ "type": "solve", "bg": "bg_room.jpg",
  "kicker": "서술형은 과정에서 점수가 갈립니다",
  "headline": "머리로 푼 것과 ~~답안지에 남은 것~~",
  "panels": [
    { "name": "문제",       "lines": ["이차함수 $y = x^2 - 4ax + 3$ 의", "..."] },
    { "name": "머릿속 풀이", "lines": ["$\\alpha+\\beta = 4a$", "..."] },
    { "name": "답안지에 쓸 것", "highlight": true, "lines": ["..."] }
  ] }
```

- **수식은 `$ ... $` 안에** 넣는다 (LaTeX). `$y = x^2 - 4ax + 3$`, `$\\alpha`, `$\\pm\\sqrt{3}$`
- JSON 안에서 역슬래시는 **두 번** 쓴다: `\\alpha`, `\\sqrt{3}`
- `highlight: true` 를 준 패널은 금색 테두리로 강조된다
- 줄이 길면 글자가 자동으로 작아진다. 너무 작아지면 `lines` 를 나눠 주면 된다


## 당근 소식 자동화 (2026-10-18)

네이버와 같은 규칙이다 — **글·제목·사진을 넣고 「임시 저장」까지.**
**「다음」과 발행은 원장님이** 직접 하신다 (당근은 광고 톤 반복 게시에 네이버보다 엄격하다).

```
node sync/danggeun_draft.js --login            처음 한 번만 — 창에서 직접 로그인
node sync/danggeun_draft.js blog/<폴더> --dry   무엇이 들어갈지만 보기
node sync/danggeun_draft.js blog/<폴더>         넣고 임시 저장
node sync/danggeun_draft.js --peek             막혔을 때 — 화면의 칸·단추를 찍어 본다
```

글 폴더에 **`danggeun.md`** 가 있어야 한다. 머리말이 필요하다.

```
---
title: 여섯 주 만에 수학 51점이 79점이 됐습니다
photos: 01_표지.png, 02_stat.png, 06_closing.png     ← cards/ 안의 파일, 최대 10장
---
본문 (당근 소식은 글 중간에 사진이 안 들어간다. 사진은 맨 위에 모여 올라간다)
```

- 로그인 상태는 `sync/_daangn_profile/` 에만 남는다 (gitignore). 비밀번호는 저장소가 모른다
- **맥미니·학원 컴퓨터에서만** 돌린다
- 당근 본문에는 **모집·가격 문구를 넣지 않는다**
