## 3. 🚫 절대 규칙

1. **플래너 관리 시스템의 세부 메커니즘 공개 금지**
   → 허용 표현: "자체 개발 관리 시스템", "계획→실천→피드백(PAF) 흐름 운영",
   "세부 방법은 상담에서 안내"
2. **하브루타 녹음** — 학부모가 음성을 듣는다고 쓰지 않는다.
   제출 빈도·꾸준함만 언급하고 "아이 중심 설계"로 프레이밍
3. **자체 개발 기능의 내부 규칙·계산 방식 공개 금지** (경쟁사 복제 우려)
   - 학부모앱 로드맵 화면 UI 묘사·노출 금지
   - **진도 레이스**: 배점표·정답 가산 방식·설계 원리·리그 구간·상 선정
     기준·순위 재계산 주기 — 전부 비공개
   - 판단 기준: **"이 글만 보고 다른 학원이 같은 것을 만들 수 있는가?"**
     만들 수 있으면 뺀다. 학부모님이 알아야 할 것은 계산식이 아니라
     **무엇을 왜 하는지**다
   - ⚠️ **앱 화면 캡처도 같은 기준으로 검토**한다. 글에서 뺀 수치가
     사진으로 노출되는 일이 자주 생긴다
   - 가려야 할 게 있으면 **모자이크가 아니라 크롭**. 모자이크는 "여기 중요한
     게 있다"고 알려주고 홍보글 인상도 탁해진다. 크롭은 애초에 없었던 것처럼
     된다. 그보다 **카드뉴스 이미지나 현장 사진**이 대개 더 낫다
     (현장 사진은 얼굴 나오면 초상권 동의 필요 → 뒷모습·손·책상 위주)
   - (2026-08-26 원장님 지적으로 규칙 확대 — 진도 레이스 초안이 설계도
     수준으로 자세했음)
4. **자체 교재명 마스킹** (예: Lumen Spark M1-1 → ○○교재)
5. **경쟁 학원 비교·언급 금지** — "다른 학원은", "대부분의 학원은" 같은
   간접 비교도 하지 않는다
6. **학생 이름 익명화** — 가운데 글자를 ○ (유현준 → 유○준)
7. **이벤트 글에 구체적 참여 인원수 쓰지 않음** → "한정 수량"
8. **내부 vs 공개 구분 — 가장 자주 실수하는 규칙**
   - 점수 커트라인, 오답률·정답률 기준, 표본 기준 등 **운영 수치**
     → 카톡 채널(내부)만 OK
   - **네이버 블로그(공개)에는 쓰지 않는다.** "기준선 아래", "기준을 넘으면"
     처럼 수치 없이 표현
9. **프로그램 개설 전/수강생 없을 때**는 솔직하게 쓰고 "개설 준비 완료"로 표현
10. **가상 학생 사례**는 반드시 `[가상사례]` 표시하고, 실제 사례로 교체할지
    원장님께 확인

## 4. 문체 규칙

> ⭐ **글을 쓰기 전에 반드시 `blog/reference/문체샘플/2026_TLP상담_실제발행본.md`를
> 먼저 읽는다.** 원장님이 직접 쓰신 실제 발행 글이고, 이 블로그의 문체
> 기준이다. 상세 분석은 같은 폴더의 `README.md`에 있다.

기본 원칙

- 공적·전문적·신뢰감 있는 톤, 정수쌤의 따뜻하고 성실한 분위기
- 과장 표현 금지 — "최고", "1등", "압도적"
- 데이터 기반·사실 기반 표현

**원장님 문체의 핵심 (정본에서 관찰 — 반드시 지킬 것)**

1. **문단을 짧게 끊는다.** 1~3문장이 기본이고 한 문장짜리 문단도 자주 쓴다.
   → Claude가 가장 자주 어기는 항목. 4~6문장을 한 문단에 몰아넣지 말 것
2. **자문(自問)을 독립된 줄로 배치한다** — `"도대체 무엇이 문제일까?"`
3. **블로그 본문에 이모지를 쓰지 않는다.** 소제목은 `■`, 항목은 `①②③④`
   (카드뉴스·카톡본에는 사용 가능. 🔴🟡🔵도 본문에는 넣지 않는다)
4. 소제목 뒤 부연은 대시로 — `① 학습동기 — 왜 공부하는가`
5. **짧은 단문으로 문단을 닫는다.** 체언 종결도 쓴다
   — "성적표 뒤에 있는 이야기들입니다." / "결과지를 함께 들여다보는 시간."
6. **1인칭 "저는·제가"를 쓴다.** "루멘수학은"으로만 쓰지 않는다
7. **자랑하지 않고 자기 한계를 인정한다** — "제가 미처 보지 못했던 것들이
   보였습니다". 이 겸손함이 이 블로그의 신뢰를 만든다
8. 사진 자리에는 설명이 아니라 **감상 한 문장**을 캡션으로
9. 지역·학원명 키워드는 흩뿌리지 말고 **도입 한 번 + 마무리 문단**에
10. 마무리는 다짐 한 문장 + 그 이유. 느낌표·호객 문구 없이 담백하게

**AI 티 나는 문장 금지**
- "~할 수 있습니다" 남발
- 과한 대구(對句) — 같은 구조 문장을 연달아 세 번 이상
- 이모지 나열

## 5. SEO 규칙

- 메인 키워드 1~2개 / 서브 키워드 3~7개
- 본문 **1500~3000자**(공백 제외)
- 제목에 핵심 키워드 포함, **제목 형식 = 지역 - 학원명 - 주제**
- 서론 3문단 안에 키워드 1회 자연 배치
- 본문 전체에 키워드 3~5회
- H2/H3 소제목 적극 사용

## 6. 기본 5단 구성

1. **Intro** — 문제의식·니즈 환기
2. **Story** — 실제 사례·상황 설명 (가상이면 `[가상사례]`)
3. **System** — 루멘수학의 방법·프로세스
4. **Result** — 기대효과·데이터·사례
5. **Closing** — 문의 유도·전달 메시지

## 7. 상황별 템플릿

### 템플릿 A — 학부모 안내글 / 시스템 소개
```
[서론] 문제 상황·학부모 니즈 / 루멘수학 시스템이 필요한 배경
[본론] 1. 현재 아이의 학습 상태 분석
       2. 루멘수학이 어떻게 지도하는지 구체적 절차
       3. LAMP · 아하노트 · 플래너 · 리커버리 관리 연동 방식
[결론] 앞으로의 학습 방향 / 집에서 도와주실 부분 / 상담 가능 시간
```

### 템플릿 B — 시험 분석(기출 분석)
```
[Intro]   학교명 + 시험 난이도 평가 / 대단원·출제 범위 요약
[Story]   문항 난이도 분포 설명 / 단원별 출제 의도 분석
[System]  LAMP 사고 구조 기반 분석 / 유형별 접근법 요약
[Result]  틀리기 쉬운 요소 / 대비 전략 3가지
[Closing] 학년·학교 맞춤 대비 안내
```

### 템플릿 C — 이벤트 / 공지 / 프로그램 홍보
```
[서론] 이벤트 필요성 또는 기획 배경
[본문] 1. 프로그램 목적
       2. 참여 대상 / 일정 / 장소
       3. 진행 방식 (플래너 인증, 텐투텐 등)
       4. 혜택 / 준비물 / 주의사항  ※인원수 대신 "한정 수량"
[마무리] 문의 안내 / 참여 유도
```

### 템플릿 D — 후기 / 사례 / 성공 스토리
```
[서론] 해당 학생의 초기 상황 (이름 익명화 유○준)
[본문] 1. 어떤 이유로 변화가 필요했는지
       2. 어떤 지도 방식이 적용되었는지
       3. 플래너·아하노트·리커버리 관리·주간테스트 개선 포인트
[결론] 학습 변화 / 태도 변화 / 성취도 향상 / 학부모 반응
```

- 그 밖에 자동 로그인 반복에 따른 계정 제한, 약관상 자동화 접근 금지
- 안전한 대안: **네이버 공식 예약발행** 기능 + 썸네일·카드뉴스 **이미지 자동 생성**
