# 문체 샘플

새 글을 쓸 때 루피오가 이 폴더의 글을 먼저 읽고 문체를 맞춥니다.
**지침 100줄보다 실제 글 3편이 문체를 훨씬 정확히 잡아줍니다.**

## 현재 들어 있는 글

| 파일 | 원래 제목 | 성격 | 확인 필요 |
|---|---|---|---|
| `2026_리커버리수업_소개.md` | 80점 밑으로 떨어지면, 우리는 압니다 | 시스템 소개 | ⚠️ 실제 발행본인지 |
| `2026_학부모앱_업데이트.md` | 루멘수학 학부모앱, 이렇게 달라졌습니다 | 신기능 소개 | ⚠️ 실제 발행본인지 |

⚠️ 위 두 편은 **Claude가 쓴 초안**입니다. 실제로 발행하신 글인지 확인이
필요하고, 지금 지침 기준으로는 위반 사항도 있습니다.

- `2026_리커버리수업_소개.md` → 제목과 본문에 **운영 수치(80점·60%)**가 그대로
  들어가 있습니다. 공개 블로그 기준으로는 규칙 8 위반입니다.
- 두 편 모두 용어가 「리커버리 **수업**」으로 되어 있습니다 (현재 표기는
  「리커버리 **관리**」).

**참고용으로만 두고, 문체 기준은 원장님이 직접 발행하신 글로 교체하는 것이
좋습니다.**

## 📌 원장님께 요청

지금까지 발행한 글 중 **가장 마음에 들었던 3~5편**을 이 폴더에 넣어 주세요.

- 형식은 `.md`가 가장 좋지만, 네이버 블로그에서 복사해 텍스트로 붙여 주셔도
  됩니다. 제가 정리해서 저장하겠습니다.
- 파일명은 `YYYY_주제.md` 형태로 맞추겠습니다.
- 함께 `blog/reference/발행목록.md`에 날짜·제목을 채워 주시면 주제 중복을
  막고 새 글에서 이전 글로 내부 링크를 걸 수 있습니다.
