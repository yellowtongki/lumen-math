> `blog/reference/프로그램설명.md`를 우선 참고할 것.** 이 문서는 그 이전에
> 작성된 배경 메모라 아래 내용 중 다음이 실제와 다르다:

> - 선발되면 **재시험** + 학습지 (이 문서엔 학습지만 언급)

>   발송 방식이 아님)
> - 용어는 "리커버리 **수업**"이 아니라 "리커버리 **관리**"
>
> 이 문서 자체는 역사 기록으로 남겨두고 고치지 않는다.

## 리커버리 수업 — 코드로 확인된 실제 기준

학원앱 `성적·분석 → 리커버리` 탭의 자동 선발 로직 (`RC.cfg`, lumen_v18-61.html 약 9280줄):

```
minScore: 80   // 주간테스트 80점 미만
minUnit:  60   // 교재 단원 정답률 60% 미만
weeks:    3    // 최근 3주 기준 (또는 원장님이 기간 직접 지정 가능)
```

- 두 기준 **중 하나만** 걸려도 선발 대상
- **둘 다** 걸리면 🔥 1순위로 표시
- 원장님이 화면에서 기준값(80점/60%)과 기간을 직접 바꿀 수 있음 → 실제 발송 전에
  현재 설정값이 그대로인지 앱에서 재확인 필요

**별도 지표 — 숙제 완료 상태 (`hwStatus`)**:
- `done`(🟢 완료) / `weak`(🔴 미흡) / 빈 값(표시 안 함)
- 위 리커버리 자동 선발(주간테스트+단원 정답률)과는 **다른 데이터**임에 주의.
  원장님이 원하시는 "주간테스트 미흡 + 숙제 미흡"은 리커버리 보드의 공식 두 기준과
  다른 조합이므로, 실제 글을 쓰기 전에 **어느 기준으로 대상을 정할지 먼저 확정**해야 함.

## 오늘 논의된 작업 — 리커버리 호출 블로그 + 학부모 안내문

**배경**: 주간테스트 미흡 + 숙제 미흡 학생을 주말 리커버리 수업에 부르려고 함.
문서 두 개가 필요:

1. **블로그 글** (공개) — 리커버리 수업 정책/취지를 일반 학부모에게 소개
2. **학부모 안내문** (비공개) — 실제 호출 대상이 된 학생의 학부모에게 개별 발송.
   "우리 아이가 부족하다"를 알리는 민감한 내용이라 톤을 특히 조심해야 함
   (상처 주지 않으면서도 필요성은 분명히 전달)

## 미해결 질문 (새 채팅에서 먼저 확인할 것)

1. **선발 기준**: 리커버리 보드의 기존 자동 기준(주간테스트 80점 미만 OR 단원 정답률
   60% 미만)을 그대로 쓸지, 아니면 "주간테스트 미흡 + 숙제 미흡"을 새 기준으로 쓸지?
   → 후자라면 실제 대상 학생을 앱에서 뽑아 몇 명인지 먼저 확인 필요
2. **블로그와 안내문이 같은 회차(이번 주말 대상자)를 다루는지**, 아니면 블로그는
   상시 소개용이고 안내문만 그때그때 개별 발송하는 건지?
3. 이번 리커버리 일정(날짜·시간대)과 장소가 정해졌는지 — `RC.cfg.slots` 기본값은
   `['10:00','11:00','13:00']`
