# 학원앱 조립 도구

설명서는 `docs/handoff.md` §2~4.

- `build_app.py` — 학원앱 조립 (`python3 sync/appbuild/build_app.py v19-NN`, 저장소 맨 위에서)
- `modules/` — 기능별 부품 · `memos/` — 버전 메모(memo_19NN.txt)
- `syntax.js` — html 안 스크립트 문법 검사
- `app_latest.js` — 배포 뒤 최신본 기록
- `build_student_example.py` — 학생앱 새 버전 만드는 예시
- `tests/` — 브라우저 검사 예시 (실서버는 읽기만)

학생 실명·점수·열쇠를 이 폴더에 넣지 않는다(공개 저장소).
