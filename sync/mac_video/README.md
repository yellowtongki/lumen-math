# 강의영상 파일명 정리 도구 (맥미니 전용)

맥미니 내부 저장소에 있는 강의영상 파일들의 **이름을 한 번에 바꾸는** 도구입니다.
원장님이 맥미니에서 직접 실행하십니다. (Claude는 클라우드에 있어서 맥미니 파일에 직접 접근할 수 없습니다)

## 지금 상황 (2026-07-30 확인)

영상 파일명이 전부 `IMG_9562.MOV` 처럼 **아이폰이 붙인 번호**라서, 이름만 봐서는
어떤 강의인지 전혀 알 수 없는 상태입니다.

다행히 **파인더 "수정일" 칸에 촬영 시각이 그대로 남아 있습니다.**
(에어드랍은 촬영 시각을 보존합니다) → 이 도구는 그 시각을 파일 이름으로 끌어올립니다.

### 폴더 흐름

| 폴더 | 내용 |
|---|---|
| `~/Downloads` (다운로드) | 아이폰에서 **에어드랍으로 막 받은 원본** — 아직 편집 전 |
| `/Users/강의영상원본` | 캡컷 편집이 **끝난 것들의 원본** — 보관용 |
| `/Users/강의편집` | **캡컷으로 편집된 결과물** — 실제로 쓰는 강의 영상 |

(파인더의 "사용자" 폴더가 `/Users` 입니다)

> 세 폴더 모두 같은 방법으로 정리할 수 있습니다.
> 원본과 편집본의 이름에 **같은 `IMG_번호`를 남겨두면** 나중에 "이 편집본의 원본이
> 어느 것인지" 바로 찾을 수 있어서, 기본 설정이 번호를 남기도록 되어 있습니다.

## 준비 (처음 한 번만)

1. 이 저장소를 맥미니로 내려받거나, 아래 파일들을 맥미니 **같은 폴더**(예: 바탕화면)에
   저장합니다. `timetable.txt` 는 `3_autoname.command` 와 **반드시 같은 폴더**에 있어야 합니다.

   | 파일 | 역할 |
   |---|---|
   | `1_scan.command` | 영상 목록 CSV 만들기 |
   | `3_autoname.command` | 날짜 + 시간표로 이름 자동 생성 |
   | `4_matchedit.command` | 강의편집 폴더 이름 가져오기 (단원명) |
   | `2_rename.command` | 실제 이름 변경 / 되돌리기 |
   | `timetable.txt` | **강의 시간표** — 반 이름의 근거 |
2. **처음 실행할 때** 맥이 "확인되지 않은 개발자" 라며 막을 수 있습니다.
   그럴 땐 파일을 **오른쪽 클릭 → 열기 → "열기"** 를 누르면 됩니다. (이후에는 그냥 더블클릭)
3. 혹시 "권한이 없습니다" 라고 나오면 터미널에 아래를 한 번 붙여넣으세요.
   (파일을 바탕화면에 뒀을 경우)

   ```
   chmod +x ~/Desktop/*.command
   ```

## 사용 순서

### 1단계 · 영상 목록 만들기 — `1_scan.command`

더블클릭 → 검은 창이 뜨면 **영상 폴더를 창 안으로 끌어다 놓고** 엔터.

- 하위 폴더까지 전부 뒤져서 영상 파일을 찾습니다
- 파일을 **고치거나 옮기지 않습니다. 읽기만 합니다** (안전)
- 결과: 그 폴더 안에 `_강의영상_목록.csv` 파일이 생깁니다

CSV에는 이런 정보가 들어갑니다 — 이름을 정할 때 참고하시라고 넣었습니다.

| 칸 | 내용 |
|---|---|
| 현재파일명 | 지금 이름 (`IMG_9562.MOV`) |
| **새파일명(여기에 입력)** | ← **여기에 원하는 이름을 적습니다** |
| 폴더 | 어느 하위 폴더에 있는지 |
| 크기MB | 파일 크기 |
| **녹화일시** | ★ **실제 촬영 시각** (파인더 "수정일"과 같은 값) |
| 맥에추가된날 | 에어드랍으로 맥에 받은 시각 (촬영 시각이 아님) |
| 영상메타촬영일 | 영상 안에 기록된 촬영 시각 (대조용) |
| 길이 | 재생 시간 (분:초) — 어떤 강의인지 가늠할 때 유용 |
| 전체경로(수정금지) | 프로그램이 쓰는 칸. **건드리지 마세요** |

### 2단계 · 새 이름 적기 — 두 가지 방법

#### 방법 ①(추천) 자동으로 채우기 — `3_autoname.command`

더블클릭 → CSV를 끌어다 놓고 → 방식을 고르면
**녹화일시 + 시간표(`timetable.txt`)로 반 이름까지 자동 생성**합니다.

| 방식 | 결과 예시 |
|---|---|
| 1) 날짜 + 반 + 그 반의 순번 + 원본번호 | `2026-07-27_미적분1_01강_IMG_9556.MOV` |
| 2) 날짜 + 반 + 시각 + 원본번호 | `2026-07-27_미적분1_0932_IMG_9556.MOV` |
| 3) 반 없이 · 날짜 + 시각 + 원본번호 | `2026-07-27_0932_IMG_9556.MOV` |

**반 이름은 어떻게 알아내나요?**
`timetable.txt` 에 적힌 요일·시간대를 보고 판단합니다.
예를 들어 2026-07-27은 **월요일**이고 09:32에 찍었으니 → `미적분1`.

실제 데이터로 확인한 결과입니다.

| 녹화 | 요일 | 자동 판정 |
|---|---|---|
| 07-27 09:32 / 09:53 / 10:17 | 월 | 미적분1 01강 / 02강 / 03강 |
| 07-27 11:01 / 11:14 / 11:38 / 11:41 | 월 | 공수2 01강 ~ 04강 |
| 07-24 10:19 | 금 | 미적분1 01강 |
| 07-25 09:15 | 토 | 중3-2 01강 |
| 07-23 14:29 | 목 | 중1-2기출특강 01강 |

> **시간표가 바뀌면 `timetable.txt` 만 고치면 됩니다.** (메모장으로 열어 수정)
> 시간표에 없는 시각에 찍은 영상은 반 이름 없이 날짜·시각만 붙습니다.

#### 방법 ①-2 단원명까지 — `4_matchedit.command`

`강의편집` 폴더 이름(`공수2 부분집합 260727`)을 읽어 같은 날 원본에 붙여 줍니다.
→ `공수2 부분집합 260727_IMG_9560.MOV`

- 같은 날짜끼리 **시간 순서대로 1:1** 로 맞춥니다
- 그날 원본 개수와 강의 폴더 개수가 **다르면 자동으로 채우지 않습니다** (잘못 붙는 것 방지)
- CSV 맨 오른쪽 `그날_강의목록(참고)` 칸에 후보를 적어 두니, **「길이」 칸과 견주어 확인**하세요

> ⚠️ 편집본 폴더 이름의 날짜(`260726`)가 **실제 녹화일과 다를 수 있습니다.**
> 그런 경우 자동 매칭이 되지 않으니 직접 적어 주세요.

- 이미 손으로 적어둔 이름은 **덮어쓰지 않습니다**
- 원본 CSV를 `_백업_날짜.csv` 로 남깁니다
- **파일 이름을 실제로 바꾸지는 않습니다.** CSV만 채웁니다

자동으로 채운 뒤 CSV를 열어 **단원명 등을 덧붙여 다듬으시면 됩니다.**

#### 방법 ② 직접 적기

`_강의영상_목록.csv` 를 **넘버스(Numbers)나 엑셀**로 열어
「새파일명」 칸을 채우고 **저장**합니다.

- **비워두면 그 영상은 이름을 바꾸지 않습니다** (안 바꿀 건 그냥 비워두세요)
- 확장자(`.MOV`, `.mp4`)는 **안 적어도 됩니다** — 원래 확장자를 알아서 붙입니다
- 맥에서 파일명에 쓸 수 없는 `/` 와 `:` 는 자동으로 `-` 로 바뀝니다

> 넘버스로 열었다면 저장할 때 **파일 → 내보내기 → CSV** 로 내보내야 합니다.

### 3단계 · 이름 바꾸기 — `2_rename.command`

더블클릭 → `1` 선택 → 방금 저장한 **CSV 파일을 창에 끌어다 놓고** 엔터.

1. 먼저 **"이렇게 바꿉니다" 목록을 보여줍니다** (이 시점엔 아직 아무것도 안 바뀜)
2. 확인하고 `y` 를 입력해야 실제로 바뀝니다
3. 끝나면 `_이름변경기록_날짜시각.tsv` 라는 **되돌리기 기록**이 생깁니다

---

## 되돌리고 싶을 때

`2_rename.command` 더블클릭 → `2` 선택 → `_이름변경기록_....tsv` 파일을 끌어다 놓고 엔터.
→ 모든 파일이 **원래 이름으로 복구**됩니다.

## 안전장치 (중요)

이 도구는 영상 원본을 다루므로 아래 보호장치를 넣었습니다.

- **파일을 삭제하거나 다른 폴더로 옮기지 않습니다.** 오직 이름만 바꿉니다
- 바꾸기 전에 **전체 목록을 미리 보여주고**, `y` 를 눌러야만 진행합니다
- 바꾸려는 이름이 **이미 있으면 건너뜁니다** (덮어쓰기로 파일이 사라지는 사고 방지)
- CSV에 적힌 파일이 없으면 건너뛰고 알려 줍니다
- **되돌리기 기록**을 남겨 언제든 원상복구할 수 있습니다

> 그래도 처음에는 **영상 몇 개만 든 연습용 폴더**를 하나 만들어
> 한번 시험해 보신 뒤 전체에 적용하시길 권합니다.

## 이름 규칙 제안

나중에 학원앱 강의실(🎬)에 올릴 때 찾기 쉬우려면, 정렬했을 때 순서가 맞는 이름이 좋습니다.

```
2026-07-27_07강_고1미적_IMG_9562.MOV
```

- **날짜를 앞에** 두면 파일 목록이 자동으로 시간순 정렬됩니다
- 회차는 `01, 02` 처럼 **두 자리**로 (안 그러면 10강이 2강보다 앞에 옵니다)
- 띄어쓰기 대신 `_` 를 쓰면 나중에 자동화하기 편합니다
- **`IMG_번호`를 뒤에 남겨두면** 원본(강의영상원본)과 편집본(강의편집)을 짝지어 찾을 수 있습니다
