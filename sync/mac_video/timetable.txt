#  "이건 어느 반 강의다" 를 자동으로 알아냅니다.
#
#  시간표가 바뀌면 이 파일만 고치면 됩니다.

#  적는 방법:   요일  시작시각-끝시각  반이름
#               ↑ 월 화 수 목 금 토 일
#
#  · # 으로 시작하는 줄은 설명이라 무시됩니다
#  · 시각은 24시간제 (오후 1시 = 13:00)
#  · 시간대가 겹치면 안 됩니다. 겹치면 먼저 적힌 것이 이깁니다
#  · 시간표에 없는 시각에 찍은 영상은 반 이름 없이 날짜·시각만 붙습니다

수 11:00-13:30 공수2

금 09:30-11:00 미적분1
금 11:00-13:30 공수2

# ── 화 · 목 ─────────────────────────────────────
화 10:00-11:30 중3-2판서
화 11:30-13:00 중2-2
화 13:00-15:00 중1-2기출특강

목 10:00-11:30 중3-2판서
목 11:30-13:00 중2-2
목 13:00-15:00 중1-2기출특강

# ── 토 ──────────────────────────────────────────

#  확인이 필요한 부분 (원장님이 실제 시간에 맞게 고쳐 주세요)
#
#  1) 월·수·금의 미적분1 / 공수2 경계를 11:00 으로 잡았습니다.
#     달력에는 미적분1이 9:30~11:30 으로 되어 있지만,
#     7/27(월) 실제 녹화가 09:32 / 09:53 / 10:17 (미적분1 3편) →
#     11:01 / 11:14 / 11:38 / 11:41 (공수2) 로 나뉘어서
#     11:00 을 경계로 잡으니 강의편집 폴더 개수와 딱 맞았습니다.
#     실제로는 다르다면 위 숫자를 고치세요.
#
#  2) 화·목의 중3-2판서(10:00~12:00)와 중2-2(11:30~)가 달력에서 겹칩니다.
#     겹치면 안 되므로 11:30 을 경계로 잘라 두었습니다.
#
#  3) 토요일 '시시단 수업', 월요일 '리슈슈', 수·금 오전의
