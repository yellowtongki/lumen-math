# blog — 루멘수학 블로그 글 한 편 만들기 (글감 → 본문 → 카드 → 검수)

원장님이 "오늘 이런 일이 있었어" 한 마디를 하면 **블로그 한 편과 카드 6장이 나오는** 흐름.
명령을 따로 외울 필요가 없다. 이 레시피대로 끝까지 간다.

## 0. 먼저 읽을 것 (매번)

1. `docs/lumen_blog_profile.md` — ⭐ **말투·규격의 원본.** 안 읽고 쓰면 톤이 틀어진다
2. `blog/2026-09-20-banten/post_published.md` — 원장님이 고쳐 발행한 글. **말투 0순위 기준**
3. `blog/README.md` — 카드 8종 사용법

## 1. 글감 (원장님이 소재를 주셨으면 건너뛴다)

```bash
node sync/blog_topics.js --days 7 --topic "원장님이 말씀하신 소재"
```
→ `docs/blog_topics_latest.md` (매쓰플랫 오답 유형·아하노트 질문 통계. **익명·집계만**)

## 2. 폴더와 본문

`blog/<YYYY-MM-DD>-<짧은영문>/post.md` 를 만든다. 머리말 형식:

**제목 형식** (검색을 노리는 글 — 시험 분석 등):
`연도 + 학교·학년·시험 + , + 궁금해지는 한 마디` · **35자 안팎** · **학원명 넣지 않음**
예: `26년 옥길중 1학년 2학기 중간 수학, 등급은 17번 하나에서 갈렸습니다`
학원 이야기·철학 글은 옛 형식(`"따옴표 말" — 루멘수학 ○○`)을 쓴다. 자세한 것은 profile 4-2.

```
---
title: 26년 옥길중 1학년 2학기 중간 수학, 등급은 17번 하나에서 갈렸습니다
date: 2026-09-20
recruit: false
hashtags: #옥길동수학학원 #부천수학학원 ... (8개 이상)
---
```

**본문 쓸 때 반드시 지킬 것** (원장님이 초안을 고친 자리에서 나온 규칙 — profile 4-5):

- 도입은 **날짜·요일**로 시작. 「오늘」로 뭉개지 않는다
- **■ 는 첫 소제목 하나만.** 나머지 소제목은 기호 없이. 짧은 이야기엔 소제목을 안 붙인다
- ①②③ 나열 — **셋을 억지로 채우지 않는다.** 둘로 충분하면 둘
- 결론은 첫째/둘째/셋째
- **확인 안 된 숫자·시점은 넣지 않는다** (「이틀 전」 같은 것)
- 본문에 **이모지를 쓰지 않는다**
- 맨 끝에 **주소 한 줄** → `경기도 부천시 소사구 옥길로 116 6층 618호`
- 그 아래 `[지도: 루멘수학교습소]`, `[톡톡: 상담 문의 https://talk.naver.com/w9d7umc]`
- 사진 자리 `[실사진 N: 설명]` **3곳 이상**
- 「A가 아니라 B입니다」 대비 구문을 최소 2번
- 「옥길동 … 루멘수학」을 본문에 2회 이상

## 3. 카드 문구 (`cards.json`)

같은 폴더에 6장. 종류는 `cover`/`photo`/`qa`/`stat`/`compare`/`list`/`solve`/`closing`.
**`qa` 카드에 넣은 질문은 본문에도 똑같은 글자로** 있어야 한다 (카드는 그림이라 검색엔진이 못 읽음).

배경 그림을 만드는 길은 셋이다. **상황에 맞는 것을 고른다.**

| 길 | 언제 | 어떻게 |
|---|---|---|
| **MCP** (제일 좋음) | 질을 높이고 싶을 때 | `make_card_background` 도구를 부른다. **만든 그림이 바로 보이니 보고 판단해서 다시 부른다.** 맥미니 + 키 필요 |
| 스크립트 | 여러 장 한 번에 | `node sync/image_gen.js blog/<폴더>` · 카드에 `bgPreset`/`bgPrompt` 를 미리 적어 둔다 |
| 손으로 | 키가 없을 때 | `node sync/image_gen.js blog/<폴더> --dry` → 프롬프트를 ChatGPT에 붙여넣고 받은 그림을 폴더에 저장 |

**MCP 를 쓸 때의 요령** — 한 번에 끝내려 하지 말 것:
1. `quality: "low"` 로 시안을 먼저 본다 (싸다)
2. **그림을 눈으로 본다.** 제목이 놓일 자리(왼쪽 위)가 복잡하면 글자가 안 읽힌다
3. 장면 설명을 고쳐 다시 부른다
4. 마음에 들면 `quality: "high"` + `save_to: "blog/<폴더>/bg_01.png"` 로 저장
5. `cards.json` 의 그 카드에 `"bg": "bg_01.png"` 를 적는다

> AI는 **배경만** 만든다. 글자·수식은 늘 카드 생성기가 HTML로 얹는다 (한글이 깨지므로).
> 학원 내부·수업 장면·사람 얼굴은 만들지 않는다 (허위 광고).

## 4. 카드 만들기

```bash
node sync/card_render.js blog/<폴더>            # 전부
node sync/card_render.js blog/<폴더> --only 3   # 3번만 다시
```

**만든 뒤 반드시 Read 로 PNG를 직접 본다.** 글자가 잘렸는지, 배경과 글자가 겹쳐 안 읽히는지는
눈으로만 확인된다. 이상하면 문구를 줄이고 `--only N` 으로 다시.

## 5. 검수

```bash
node sync/post_check.js blog/<폴더>
```

17항목. **❌ 가 하나라도 있으면 끝난 게 아니다.** ⚠️ 는 통과이되 참고.
글자수가 모자라면 **억지로 늘리지 말고** 내용을 더할 거리가 있는지 먼저 본다.

## 6. 원장님께 넘기기

`naver_paste.txt` 를 만들어 드린다 (제목·본문·사진 자리·카드 순서·해시태그).
만드는 법은 이전 글의 것을 본뜬다. 네이버 붙여넣기는 **원장님이 직접** 하신다.

## 8. 발행본을 받으면 ⭐

원장님이 **고쳐서 발행한 글**을 주시면 `post_published.md` 로 저장하고,
**고친 자리를 `docs/lumen_blog_profile.md` 4-5 표에 규칙으로 추가**한다.
이게 말투가 점점 정확해지는 유일한 길이다. 빠뜨리지 말 것.
